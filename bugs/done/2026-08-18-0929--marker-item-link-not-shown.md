## Резолюция (2026-08-18, /autopilot grill→code)
**Root cause:** `page.tsx` — ДВА билдера `editorialMarkers`. Ветка B (синканные карты) резолвит `linkedItem`, а ветка A (`config.editorial` static/tile-карты — Labs, factory-hd) хардкодила `linkedItem: null` («подтянем позже», стр.185). Карточка (`EditorialMarkerCard`, стр.1149) уже умеет показывать чип связанного предмета — не хватало серверного резолва.

**Grill-решение V4DYA:** хирургичный патч ветки A (не дедуп двух билдеров — оставлен как долг, помечен TODO).

**Фикс:**
- расширил ленивую загрузку каталога/цен: `needCatalog = hasLootItem || hasItemLink` (`hasItemLink` = есть маркер `linkKind==='item'` с `linkId`);
- заменил `linkedItem: null` на резолв `{ id, name: catById?.get(id)?.name ?? id, slug: priceIndex?.get(id)?.normalizedName, bg: priceIndex?.get(id)?.backgroundColor }` — зеркало ветки B.
