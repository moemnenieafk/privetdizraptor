## Резолюция (2026-08-18, /autopilot grill→code)
**Root cause:** реальный гейт — не лут, а обязательное поле **«название»** (`titleOk`) на шаге 3 (`EditorialMarkerCard.tsx:1030`). Для лута название автозаполнялось из имени предмета, поэтому без выбора лута оно оставалось пустым → застревание, воспринятое как «блок на шаге лута».

**Grill-решение V4DYA:** название остаётся обязательным, но **умнее** — автоподстановка «лучшей метки» при входе на шаг 3, если поле пусто. Блок остаётся только когда юзер сам стёр название.

**Фикс:** эффект в `EditorialMarkerCard` на смену шага — при `curStep==='details'` и пустом `draft.title` подставляет `markerCategoryLabel(draft, lootLabel)` (лут→имя предмета, босс→имя, подтип выхода→метка, иначе→метка категории). Гейт не тронут; логика шагов/сохранения не тронута.
