# Карты: после добавления маркера пропадает подложка (невидимый этаж)

- **Раздел:** Карты — `/eft/maps`
- **Компонент:** редактор маркеров / переключение этажей `~вывод`
- **Что не так:** при добавлении маркера на этаже после сохранения маркер добавляется, но пропадает видимость подложки карты — как переключение на «невидимый этаж».
- **Повтор:** открыть карту с этажами → добавить маркер на этаже → сохранить → подложка исчезает. URL вида `?z=4.1000000000000005&cx=378.10&cy=524.24&floor=2`.
- **Ожидалось:** подложка нужного этажа остаётся видимой после сохранения маркера.
- **Обход:** вручную переключить этаж (лечит). Обновление страницы с тем же URL — НЕ лечит.
- **Гипотеза автора:** принудительный редирект/ресинк на нужный этаж после сохранения.

> исходное сообщение (as-is):

## Резолюция (2026-08-18, /autopilot grill→code→live-verify)
**Root cause (подтверждён инструментально в браузере):** `MapViewerClient` static-floor-эффект грузит SVG через `loadImage(floors[activeFloor].image)`. У single-SVG мульти-этажных карт (the-lab: один `the-lab.svg` с `<g>`-группами `floor-1/floor--1/floor-2`) `.image` есть ТОЛЬКО у наземного этажа (`buildMapFloors`, стр.492/499). При заходе сразу на верхний этаж (`?floor=2` из URL после `reloadWithOverlay` при сохранении маркера) эффект видел `activeFloor=2`, `img=null` → **базовый SVG не грузился вовсе** → `applyFloor` крутился с `groups=null` → подложка пустая. Ручное переключение чинило, потому что SVG к тому моменту уже был загружен (заходили через floor 0). Дебаг-лог в браузере: `static-floor-effect activeFloor=2 img=null`, `applyFloor idx=2 groups=false` (loadImage ни разу).

**Grill-решение V4DYA:** робастный фикс + verify после (продукт-развилки нет).

**Фикс (`MapViewerClient.tsx`):**
1. **Fallback-загрузка базового SVG:** если у активного этажа нет своего `.image`, но SVG ещё не загружен (`!svgGroupsRef.current`) — грузим `floors[0].image` один раз. Дальше переключение этажей — `applyFloor` (затемнение групп), без перезагрузки.
2. **State-driven ре-apply этажа:** ввёл `svgReadyTick`; `loadImage` после парса групп бампает тик вместо ref-вызова `applyFloorRef.current(activeFloorRef.current)`; эффект `applyFloor(activeFloor)` получил `svgReadyTick` в зависимости → как только группы готовы, применяется АКТУАЛЬНЫЙ этаж (снимает гонку порядка).

**Live-verify (браузер, dev):** `/eft/maps/the-lab?floor=2` при полном reload → подложка 2-го уровня видима (была пустая); переключение этажей 2→1 работает; консоль: `loadImage the-lab.svg`, финальный `applyFloor idx=2 groups=true size=3`. Общий фикс для всех single-SVG static-карт (shoreline/reserve/…).
