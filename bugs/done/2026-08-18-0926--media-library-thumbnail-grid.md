# Медиа-библиотека: миниатюры вытянуты вертикально — переделать под сетку 16:9

- **Раздел:** CMS — Медиа-библиотека (модалка загрузки материалов)

- **Что не так:** миниатюры отрисованы узкими вертикальными карточками — материалы неудобно просматривать и выбирать. Проблема вёрстки + юзабилити.
- **Хотелка:** переделать дизайн сетки под **миниатюры 16:9**.

## Резолюция (2026-08-18, /autopilot grill→code→live-verify)
**Root cause:** `MediaLibrary` (общий компонент страницы `/admin/media` + модалки `MediaPicker`) рендерил миниатюру фикс-высотой `h-32 w-full object-cover` → в узком контейнере (модалка-пикер) ячейка становилась вертикальной.

**Grill-решение V4DYA:** передумал на **1×1 (квадрат) + кроп** (не 16:9).

**Фикс (`MediaLibrary.tsx`):** миниатюра-кнопка `h-32` → `aspect-square`; скелетон загрузки `h-32` → `aspect-square`. Сетка колонок и кнопки копировать/удалить не тронуты.

**Live-verify (dev, `/admin/media`):** ячейки квадратные, кроп, ровная сетка. Чинит и модалку-пикер (общий компонент).
