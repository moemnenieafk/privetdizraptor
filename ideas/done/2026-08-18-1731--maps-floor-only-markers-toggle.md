# Карты: тоггл «показывать только маркеры этого этажа»

- **Раздел:** Карты — `/eft/maps` (мульти-этажные карты)
- **Компонент:** слой маркеров + переключатель этажей (`MapFloorSwitcher` / floor-видимость в `MapViewerClient`) `~вывод`
- **Идея (QoL):** кнопка-переключатель «показывать только маркеры этого этажа». Игрок знает, на каком он этаже → включает тоггл → видит только метки активного этажа, ищет нужный маркер/предмет.
- **Зачем / польза:** в рейде важно точно ориентироваться по этажу; метки чужих этажей мешают быстро найти нужную.
- **Ожидаемый результат:** тоггл ВКЛ → метки чужих этажей скрыты, видны только текущего; ВЫКЛ → как сейчас.
