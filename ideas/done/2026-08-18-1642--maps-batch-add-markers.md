# Карты: батч-добавление однотипных маркеров кликами по карте

- **Раздел:** Карты — `/eft/maps` (редактор маркеров)
- **Компонент:** визард/редактор маркеров + правый drawer `~вывод`
- **Идея:** массово ставить маркеры ОДНОГО типа (условие — привязка к одному типу предмета) в несколько точек/этажей за один заход. Справа открывается drawer, каждый клик по карте выставляет метку, внизу кнопка «Добавить маркеры» — применяет ко всем разом.
- **Зачем / польза:** быстро наставить много однотипных меток (напр. «Пользовательская документация» по этажу) без прохождения визарда на каждую.
- **Как видит автор:** drawer справа → клики по карте копят метки → кнопка «Добавить маркеры».
- **Ожидаемый результат:** одним заходом расставлены N меток одного типа с общими полями.
- **Открытый вопрос автора:** целесообразно ли вообще; можно ли при этом массово редактировать описания нескольких меток («не можем массово редактировать… или можем — надо бы узнать»).

> исходное сообщение (as-is):

К примеру надо  добавить пользовательскую документацию на одном этаже - справа открывается drawer по каждому  клику на карте выставляется метка - внизу кнопка "Добавить маркеры". Не  знаю целесообразно ли добавлять подобное. Ведь мы не можем массово  редактировать несколько описаний или можем. Надо бы узнать.

**Заметка (`~вывод`, на ответ автору):** батч-**редактирование** уже есть — drawer «Батч-правка» в `MapViewerClient` применяет поля ко всем выбранным маркерам (`onBatchSave`). Нового тут — батч-**создание** (расстановка новых меток одного типа кликами), которого сейчас нет. Т.е. массово править описания уже можно; не хватает именно массовой постановки.
