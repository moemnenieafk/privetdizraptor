# Предметы/Убежище: «воронка» оптимальной добычи предмета (рекурсивно бартер→крафт→инпуты) + топливо-тумблеры калькулятора биткоин-фермы

- **Раздел:** страница предмета `/eft/items/item/[slug]` (движок) + калькулятор биткоин-фермы (первое применение — топливо) `~вывод`
- **Идея:** рекурсивный движок **«как выгоднее всего получить предмет ПРЯМО СЕЙЧАС»**. От **константы** (покупка у торговца — статична, ни от чего не зависит; напр. металлическая канистра у Егеря 238 944 ₽) сравнивает пути: барахолка (купить/продать), бартеры по уровням лояльности торговцев, крафты. Для КАЖДОГО инпута бартера/крафта **рекурсивно спускается** («воронка»): а этот инпут можно получить дешевле — бартером/крафтом/покупкой? — пока не упрётся в предмет, который только «найти в рейде / купить на барахолке» (не бартерится, не крафтится, не у торговца). Итог — оптимальный путь получения + цвет-маркеры выгоды (купить/продать/бартер).
- **Зачем / польза:** новичок видит, что «+несколько кликов = экономия кучи денег»; наглядная воронка вместо простого «есть бартер / есть крафт». Ядро миссии-агрегатора «где выгоднее».
- **Как видит автор (пример металлической канистры):** константа 238 944 (Егерь) → флиа 330к (продать выгодно, купить нет) → бартер Прапор LL1 (8 спичек+5 охотничьих ≈ 250к, невыгодно) → Прапор LL2 (2 пропана+2 присадки ≈ 175к, выгода 71к; но пропан/присадка НЕ бартерятся/крафтятся → воронка стоп) → Лыжник LL3 (6 пивка ≈ 210к, выгода ~30к; пивко крафтится на Кухне LL3, а его инпут «сухарики ржаные» бартерится у Терапевта из Емеля-сухариков дешевле на 20к/шт → воронка глубже). Цены — из зеркала tarkov.dev.
- **Топливо-тумблеры (первое применение):** в калькуляторе биткоин-фермы добавить переключатели доп-инфы про 2 расходника — GPU и **топливо** (2 вида канистр: экспедиционная / металлическая), каждый — с оптимальной воронкой добычи (крафт санузел / бартеры Терапевт LL2, Реф, Прапор LL2, Лыжник LL3 / покупка Егерь / барахолка).
- **Ожидаемый результат:** на карточке предмета — блок «выгоднее всего получить так» с развёрнутой воронкой и маркерами; в калькуляторе фермы — тумблеры топлива с реальной стоимостью канистры по оптимальному пути.
