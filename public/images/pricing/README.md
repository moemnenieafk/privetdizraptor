# Арт плиток тарифов

Файл на тариф: `<slug>.webp` — слаг берётся из таблицы `tiers` (`free`, `operative`, `veteran`, …).

- Пропорция ~2:1, ширина ~700px. В плитке рисуется высотой 96px по центру герой-блока.
- Фон прозрачный: под артом уже лежит радиальное свечение в тон тарифа.

Файл **опционален**. Тиры динамические — админ заводит новый формой в `/admin/billing`,
без деплоя, и арта под него взяться неоткуда. Если файла нет, плитка рисует глиф допуска
(`icon-account_prostatus_icon` у платных, `icon-account_profile_icon` у бесплатного) — это
штатное поведение, а не ошибка.

Наличие файла проверяет сервер (`src/lib/gating/showcase.ts` → `artUrl`) и мемоизирует
на процесс: **после добавления нового файла нужен перезапуск dev-сервера или новый деплой.**
