# SPRINT (план, фоновая оценка): автономный рендер-пайплайн иконок EFT

> Статус: **EVALUATION / BACKLOG** — оцениваем потихоньку в фоне, не активный спринт.
> Заведён 2026-06-24. Контекст и доказательная база: `!future-requests/tarkov-dev-512px-icons-research.md`, авто-память `[[eft-asset-extraction]]`, `[[autonomy-prices-research]]`.

## Зачем

Полная автономия по иконкам предметов: уметь получать 512px-иконки EFT **без tarkov.dev** и **без боевого клиента**. Сейчас закрыто гибридом (синк-крон зеркалит готовые 512px tarkov.dev — `src/db/icons.ts`). Этот пайплайн нужен ТОЛЬКО если независимость от tarkov.dev станет жёстким требованием (или чтобы закрывать самые свежие предметы быстрее, чем их рисует tarkov.dev).

## Что уже установлено (выводы ресёрча — не переоткрывать)

- **Готовых 2D-иконок в бандлах EFT НЕТ.** Иконка рождается рантайм-рендером 3D-префаба (меш + материалы + скрипт `PreviewPivot` = ракурс камеры) через render-to-texture. Значит «распаковать спрайт» нельзя — только «отрендерить самим».
- **IL2CPP-реверс боевого клиента заблокирован:** `global-metadata.dat` зашифрован (`cd66…`, не `af1bb1fa`), BattlEye активен → рантайм-дамп памяти рискован/банабелен.
- **Хеш Icon Cache в текущем EFT (Unity 2022.3) не вскрыт** стандартным криптоанализом (287 достоверных пар, 8 алгоритмов × XOR/разность — 0 совпадений). Перцептивный матч известных иконок РАБОТАЕТ (для эталонных пар), но недостающие предметы матчить не с чем.
- **Офлайн-извлечение из ФАЙЛОВ бандлов — BattlEye-safe** (работа с файлами, не с памятью). AssetRipper/AssetStudio дают меши + материалы/текстуры + PreviewPivot.
- **Истинное разрешение иконки — сеточное:** `(ячейки*63)+1`; «8x» = ×8 (1×1 → 512px). Открытый `create512Image` (the-hideout) даунскейлит hi-res в 512 webp lossless — финальный шаг можно переиспользовать as-is.

## Целевой пайплайн (черновик, 4 фазы)

1. **Офлайн-экстракт (BattlEye-safe).** AssetRipper/AssetStudio из инсталла EFT (игра выключена): для каждого предмета — меш, материалы/текстуры, данные `PreviewPivot` (позиция/ротация камеры), освещение.
2. **Маппинг asset ↔ template-id.** Связать извлечённый префаб/ассет с 24-hex BSG id. Кандидаты: имена ассетов/бандлов, item-таблицы из бандлов, или сверка с нашим каталогом.
3. **Render-to-texture харнесс (главная инженерия).** Headless Unity (или Blender), воспроизводящий preview-камеру BSG: загрузить модель → выставить ракурс из `PreviewPivot` → освещение → рендер в 512×512 (или выше → даунскейл) на прозрачный фон.
4. **Пост и заливка.** PNG → открытый `create512Image` → webp → залить в `cta-media/items/eft/{id}.webp` (переиспользовать service-role-заливку из `src/db/icons.ts`).

## Открытые вопросы / спайки (оценивать по одному в фоне)

- [ ] **Камера.** Насколько точно `PreviewPivot` извлекается AssetRipper'ом и воспроизводит ли он кадрирование BSG 1:1? (главный риск фиделити)
- [ ] **Материалы/шейдеры.** Корректно ли тянутся PBR-материалы EFT; нужны ли кастомные шейдеры для совпадения вида.
- [ ] **Оружие/пресеты.** Иконка оружия = собранный дефолт-пресет (меш из множества деталей). Как собирать сцену пресета? (самое сложное; броня/одежда/барахло — проще, одиночный меш.)
- [ ] **Маппинг id.** Есть ли в бандлах надёжная связь ассет→template-id без хеша кэша.
- [ ] **Инструмент рендера.** Headless Unity (точнее к движку BSG, тяжелее в сетапе) vs Blender (проще, но дальше от оригинала).
- [ ] **Версия движка.** Конфигурировать экстракторы под Unity **2022.3.43f1**.
- [ ] **Объём.** Реалистичная оценка времени на 5044 предмета (батч-рендер) + поддержка раз в вайп.

## Риски

- **Фиделити кадрирования под BSG трудно повторить точь-в-точь** (особенно оружие). Возможен «похоже, но не идентично» — приемлемо ли для UI?
- **Поддержка каждый патч/вайп** (новые модели, смена форматов бандлов).
- **Юридически:** держим как ВНУТРЕННИЙ дериватив (рендер для своего сайта), не раздаём паки ассетов. Дисклеймер в футере. (См. риск-секцию `[[eft-asset-extraction]]`.)

## Решение / гейты

- **Гейт 1:** спайк камеры+материалов на 5–10 простых предметах (броня/барахло). Если рендер визуально совпадает с tarkov.dev 512px — идём дальше; если нет — пайплайн нежизнеспособен, остаёмся на гибриде.
- **Гейт 2:** маппинг id без хеша. Если нерешаемо — пайплайн бесполезен (нечем именовать выход).
- **Гейт 3:** оружие/пресеты. Если слишком дорого — ограничить пайплайн НЕ-оружием, оружие оставить на tarkov.dev-гибриде.

- Карты/геометрия уровней (дорого, ручной reverse-art — см. ресёрч).
