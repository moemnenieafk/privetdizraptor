## ✅ Готово и в проде
- **Карты** — near-fullscreen, интерактив Tier-1 (Замок→Ключ, требования выходов, лут-фильтр, Отряд-шаринг Realtime), heatmap денег, изоляция маркеров, **пообъектные пины цели**.
- **Меченые/цветные комнаты** — бэкенд + страница (лут/экономика/вердикт) + оверлей + комьюнити-трекер v1/v2.
- **Бартер** — фильтры/аналитика/избранное + кросс-линки Item↔Barter↔Quest.
- **Карта заданий** — раскладка «по УЛ-полкам» + десктоп-шелл + **мобилка** + страницы квестов.
- **Задания** — фидбэк-форма+модерация, События, побочки-drawer+УЛ, «Завоз» под drawer; срезы A (email-autofill) · B (задача↔трекер + авто-закрытие) · C (изоляция маркеров).
- **Прогресс/Убежище/Калькуляторы** — Убежище + калькуляторы (bitcoin/craft-profit/modules), геймификация, путь новобранца, престиж, ачивки.
- **Сборки (Gunsmith) + Трекер предметов**, **Важные предметы** (230 квест-предметов с именами и иконками).
- **Связь (Comlink)**, **Кодекс (Gamesetting)** — блог/мастерклассы/игроки/верификация; боссы/торговцы/апдейты.
- **Данные автономны** — зеркало Supabase, кроны-синки, иконки в R2 (§4.11).
