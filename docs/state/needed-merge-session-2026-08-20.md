## Что реализовано (по областям)

### Данные
- `dump-quests.mjs` параметризован (regular/pve), сохраняет `acceptedItems[]` для any-of. Оба режима свежие из `json.tarkov.dev`.
- Ридер `buildNeededItems(mode)`: single-item + any-of группы + квест-предметы («только рейд») + убежище (зеркало).
- **Консолидация квест-целей** (fix 5ad2c86a): один квест с find+give одного предмета = ОДИН источник, `count = max(сумма отдающих, max находящих)`. find+give → max (те же предметы), plant×N → sum (аддитив). Убрало дубль-чипы и двойной счёт в тоталах.
- FiR per-source (и квесты, и убежище). Убежище синкнуто (regular, 26 станций/68 апгрейдов).

### Раскладка / облик
- Двухколоночный **masonry**-рейл (1,3,5 / 2,4,6), разворот толкает свою колонку.
- **Строка-предмет**: фон `#0D0D0E`, обводка `#242426`. Ячейка 112px (обводка `#141416`), выравнивание по верху. Справа: имя 16px + BSG short-name 12px (гэпы 14px) → мета-бейджи → «Подробнее» 12px.
- **Мета-бейджи** источников (стиль StatusBadge карточки предмета): ЗАДАНИЕ (амбер), УБЕЖИЩЕ (`#9A8866`, токен `--color-hideout`), НАЙДЕНО В РЕЙДЕ (зелёный), «только рейд» у квест-предметов.
- **FiR-маркер**: фрейм 20×20 в низ-лево ячейки, иконка `side-quests.svg` 12×12 в `#BDA550` (`--color-rarity-legendary`), без фона.
- **Прогресс-заливка** — вертикальная в ячейке 112px (амбер в наборе / зелёный готово), НЕ горизонтальная по плашке.
- **Разворот**: чипы-источники = микро-версии квест-нод (квест: цвет/квадрат-аватар трейдера + «УР. N+»; убежище: `--color-hideout` + иконка модуля 28px + «УР. 0N»). На каждом чипе индикатор «нужно» (count) + разделитель перед QtyControl. Снизу «в схроне S · докупить B».
- **Сводка** (верх): иконки + анимированные числа (Всего/Собрано/Осталось/Докупить).
- **Общий прогресс-бар**: 12 делений (полоса `#0D0D0E`, деления `#141416`), %, бегунок-указатель с текущим значением; рядом кнопка **«Сброс»**.
- **Фильтр-бар**: поиск (полширины, скругление 4px) + 5 кнопок равномерно (gap 8px): Скрыть готовые (галочка), Найдено в рейде, Строю Убежище, По заданиям.
- **«Убежище ЧВК»** (`HideoutModulesPanel`): плотная сетка 6-в-ряд, плитка = иконка 28px + уровень «0N» 22px + имя; ЛКМ↑/ПКМ↓ (без +/−); фон панели `#0D0D0E`, плитки `#141416`; пояснение+Сброс в шапке.

### Интерактив
- Ячейка: ЛКМ +1 / ПКМ −1, авто-распределение по источникам (FiR-квесты → не-FiR → убежище) через живой стор.
- **Прямой ввод числа** (решение ×4500 кликов): клик по бейджу X/Y ячейки → инпут → Enter → распределение.
- **Общий сброс** прогресса сбора: кнопка «Сброс» → `NeededResetModal` (ДА/НЕТ). Чистит quest+hideout `itemProgress`, НЕ трогает выполненные квесты / уровни убежища / схрон.

## Пойманные баги (все починены)
1. **Валюта как предметы** — раздувала «Докупить» → `CURRENCY_IDS` фильтр на квест-стороне ридера.
2. **Дубли квест-чипов + двойной счёт** — find+give одного предмета = два источника → консолидация (см. выше).
3. **Декремент «залипал» на быстрых кликах** — `distribute`/QtyControl писали от рендер-значения → перевели на функциональный живой стор (`bump`/`onDelta`).
4. **⭐ RUNAWAY hold-repeat (главный)** — кнопка +/- становится `disabled` на границе (max/0), disabled-элемент НЕ получает `pointerup` → цикл авто-повтора инкремента зависал и вечно писал max; минус декрементил, зависший цикл возвращал max («восполняет в зелёную зону»). **Фикс:** отпускание слушаем на `window`, а не на кнопке. Диагностировано через инструментацию стека `Storage.setItem` (стек показал `useHoldRepeat.tick → bump → max`). Фикс в общем `QtyControl` — чинит везде.
