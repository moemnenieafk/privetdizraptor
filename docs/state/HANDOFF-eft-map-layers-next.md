## ⏭️ Вопрос, на котором остановились

**«Что мы можем рендерить по Улицам Таркова — камни, растительность?»** Не отвечено, работа
не начиналась. Что известно на сейчас:

- **Растительность: 3 492 экземпляра**, JSON в формате `extract-vegetation.py` — рендер
  (`render-objects.py`) читает такой без правок.
  ⚠️ **Но есть дыра:** `veg_prototypes()` ищет меши прототипов ПО ИМЕНИ в файлах, переданных
  флагом `--veg-assets`. Для карт с террейном туда идёт `sharedassetsN` с `TerrainData`.
  У Улиц растительность — объекты сцены, разбросанные по разным `sharedassets`, и мой
  `dump-vegetation-objects.py` **не записывает исходный файл ассетов на экземпляр**.
  Решение (не сделано): дописать в JSON `src` каждого вида (он известен на этапе сбора —
  `mg.collect_meshes` отдаёт `src`), а `run-all` пусть передаёт объединённый список в
  `--veg-assets`. Это ~20 строк в двух местах.
- **Камни: 126 экземпляров** (декор 60, препятствия 49, скалы 17) — рендерить можно
  штатным путём, отдельной работы не требует.
- Проверить после прогона: сколько прототипов «с текстурой» (у Улиц много городской зелени,
  шейдер мха там вряд ли, но словарь свойств материалов расширять по факту — гоча 23).

## Что сделано в этой сессии (кратко)

Собрано **десять карт** вместо двух. Слой 7 переделан в заказанную форму (один слой, рез
1 м от земли по рельефу), затем — **поэтажно** по полосам манифеста. Комнаты тоже поэтажно.
Написан экстрактор растительности из объектов сцены для карт без террейна.

Починено с замерами до/после: швы нарезки рендера · белые камни (шейдер мха) · растительность
Резерва (679 → 18 513) · дороги Маяка (1 285 «сущностей» → 19 настоящих) · слой 7 Резерва ·
дубли сцен Терминала (всё считалось вдвое) · рамка Терминала (лежала мимо карты) ·
высоты Леса (мнимый «другой делитель»).

## Очередь задач

1. **Рендер Улиц** — см. выше, начинать с записи `src` в JSON растительности.
2. **Ground Zero и Ледокол не проверены аудитом** — остальные восемь карт прошли.
3. **Завод (поворот 90°), Лаборатория, Лабиринт (270°)** — рамка умеет только 0 и 180.
   Разворот «на глаз» даёт у Завода **13 % анизотропии** масштаба; привязку надо ВЫВОДИТЬ
   (у Завода есть `worldTransform` в конфиге — 11 опор, невязка 0.7 м), а не гадать.
4. **Классификация по геометрии** вместо веток иерархии: у Развязки, Берега и Маяка ветки
   `BUILDING` нет, и стены сваливаются в `props`. Правило «тонкое + высокое + длинное = стена».
5. **Зона-карман у четырёх карт** — панели границы не замыкаются; заливка берёт случайный
   карман (Лес 2.45 га при карте ~200 га). Гарда есть, лечения нет.
6. **Растр у слоя стен** (сейчас только SVG), тени на землю, рендер зданий.

## Открытые вопросы к V4DYA (решения не приняты)

1. **Расхождение рамки слоёв с калибровкой сайта на Таможне — 7.6 м по X.** Если правы мы,
   синканные маркеры Таможни на сайте смещены. Проверять на живых маркерах.
2. **Терминал: чьи координаты верны** — наши (клиент) или зеркала? Расхождение ~1100 м по X
   и ~900 м по Z. Если наши — карта Терминала на сайте рисует маркеры не там.
3. **Камни Таможни на юго-востоке** смещены влево-вверх на 6–12 м относительно нарисованных,
   при этом заборы и трубы совпадают пиксель в пиксель. Кроп лежит рядом со слоем.
4. **Лес: объекты не совпадают с артом** (~11 м западнее, ~21 м севернее). Арт называется
   `woods-main_0.16` — если `0.16` это версия карты, расхождение ожидаемо.

## Как продолжить руками

```bash
python scripts/eft-map-layers/run-all.py <карта>                     # весь конвейер
python scripts/eft-map-layers/run-all.py <карта> recon               # разведка новой карты
python scripts/eft-map-layers/run-all.py <карта> --only obstacles --force-step obstacles
python scripts/eft-map-layers/dump-vegetation-objects.py <Data> <карта> <manifest> <outdir>
python scripts/eft-terrain/make-manifest.py <карта> D:/Games/raster [--from-rooms <rooms.json>]
python scripts/eft-terrain/check-orientation-gate.py                 # ждём «5 из 5»
```
