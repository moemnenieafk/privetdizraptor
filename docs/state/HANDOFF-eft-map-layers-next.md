## ✅ Вопрос, на котором остановились — ЗАКРЫТ 2026-09-04

**«Что мы можем рендерить по Улицам Таркова — камни, растительность?»** Ответ: и то и другое,
слой `render` собран. Камни 126 экземпляров / 35 прототипов / 0.449 % рамки, растительность
2 960 / 36 / 3.134 %. Разбор с замерами — в чекпоинте, раздел «Улицы Таркова: рендер».

⚠️ **Рецепт из прежней редакции этого файла был неверен.** Предлагалось дописать `src` в JSON
и передавать объединённый список в `--veg-assets`. Это не помогло бы: у Улиц не «дерево лежит
в другом файле ассетов», а `TerrainData` НЕТ НИ ОДНОЙ, и `veg_prototypes()` возвращает пусто
по любому списку файлов. Правильный путь уже был написан рядом — `stone_prototypes()` ищет
узлы в сцене; растительности сделан его двойник `veg_prototypes_scene()`, берущий прототип
по паре (`levelN`, `path_id`) точно, без поиска по имени.

Попутно вскрылись три неправды в собственном выходе (все с замерами, все починены):
выброшенные поворот и масштаб (76 % повёрнуты, у 50 % масштаб не единичный, 752 изгороди
легли бы поперёк улиц) · `leaf` у BSG = СТВОРКА, а не лист (15 % слоя было не растениями) ·
четвёртый случай гочи 23 — шейдер вершинной покраски с индексированными слотами `_MainTex0..2`
(37 камней из 126 были белыми).

## Что сделано в этой сессии (кратко)

Собрано **десять карт** вместо двух. Слой 7 переделан в заказанную форму (один слой, рез
1 м от земли по рельефу), затем — **поэтажно** по полосам манифеста. Комнаты тоже поэтажно.
Написан экстрактор растительности из объектов сцены для карт без террейна.

Починено с замерами до/после: швы нарезки рендера · белые камни (шейдер мха) · растительность
Резерва (679 → 18 513) · дороги Маяка (1 285 «сущностей» → 19 настоящих) · слой 7 Резерва ·
дубли сцен Терминала (всё считалось вдвое) · рамка Терминала (лежала мимо карты) ·
высоты Леса (мнимый «другой делитель»).

## Открытые вопросы к V4DYA (решения не приняты)

1. **Расхождение рамки слоёв с калибровкой сайта на Таможне — 7.6 м по X.** Если правы мы,
   синканные маркеры Таможни на сайте смещены. Проверять на живых маркерах.
2. **Терминал: чьи координаты верны** — наши (клиент) или зеркала? Расхождение ~1100 м по X
   и ~900 м по Z. Если наши — карта Терминала на сайте рисует маркеры не там.
3. **Камни Таможни на юго-востоке** смещены влево-вверх на 6–12 м относительно нарисованных,
   при этом заборы и трубы совпадают пиксель в пиксель. Кроп лежит рядом со слоем.
4. **Лес: объекты не совпадают с артом** (~11 м западнее, ~21 м севернее). Арт называется
   `woods-main_0.16` — если `0.16` это версия карты, расхождение ожидаемо.

5. **Детские качалки в слое камней.** `dump-stones.py` ловит по корню `rock` аттракционы
   из ТЦ (`Rocking_F1`, `rocking_loco`, `mall_rockling_safari`): Улицы 4 из 126, Развязка
   8 из 590, остальные восемь карт чисты. Правка словаря задевает все карты, а перепрогон
   Развязки обесценит её готовый рендер — потому не тронуто.

python scripts/eft-map-layers/run-all.py <карта> --only obstacles --force-step obstacles
python scripts/eft-map-layers/dump-vegetation-objects.py <Data> <карта> <manifest> <outdir>
