# Аудит полноты меню EFT — дорога к финишу

Полистовой статус 6 модулей верхнего меню. Цель: каждый пункт работает «как у других» (tarkov.dev/tarkov-market).

> ⚠️ **Ключевое:** многие динамические роуты (`[slug]`, `[...category]`) **ВЕТВЯТСЯ** — рендерят реальную страницу, если есть данные/контент, иначе «умную заглушку» (`SectionPlaceholder`, строится из дерева меню). Поэтому «роут-заглушка» в грепе ≠ «всё под ним пусто». Аудит — по фактической логике ветвления.

> ⚠️ **Аудит устарел — актуальный срез: [[release-readiness-2026-07]]** (14.07.2026, сверка с кодом).
> Ниже — исходная картина 29.06 + отметки закрытия.

## По модулям

### 1. Предметы `/eft/items` — ✅ эталон
`[...category]` рендерит **реальный** фильтр-каталог (предметы + цены + бартеры + крафты + квест-индикаторы из нашей Supabase) для КАЖДОЙ категории меню (бартер/снаряга/моды/оружие/боеприпасы/провизия/меды/ключи/инфо/спец/квест-предметы). `item/[slug]` — деталка. `loot-rate`, `price-slot` — реальны.
- 🟡 Риск: категории с 0 предметов (пробел маппинга) → **D1 спот-чек**.

### 2. Карты `/eft/maps` — 🟡
`[slug]` → реальный Leaflet-фрейм если есть конфиг в `eft-map-config.ts`, иначе заглушка.
- ✅ Реальны (≈12): the-lab, ground-zero, customs, factory, woods, reserve, lighthouse, shoreline, interchange, terminal, icebreaker.
- 🔴 Нет конфига/арта → заглушка: **Лабиринт** (labyrinth), **Конец пути** (end-of-line).
- ⚠️ **Стритс**: меню `/eft/maps/streets`, конфиг-ключ `streets-of-tarkov` → вероятно не резолвится. **A1 проверить**.
- 🟡 Маркеры: синкаются только 4 типа (extract/spawn/transit/hazard); v2 (loot/boss/lock/switch/quest_zone) — рендер отдельно (**D2**).

### 3. Прогресс `/eft/progress` — 🟡
- ✅ Убежище (модули/крафт-профит/биткоин-профит), Ачивки, Престиж, Трекер, Нужные, Бартер-профит, Карта заданий, Рейтинг, Цена-за-слот.
- 🔴 **Сборки оружия** (Мои/Найти/Создать) — `[action]` **чистая заглушка** → строить (**C2**).
- 🔴 hideout `[metric]` — заглушка (проверить, есть ли живые линки).

### 4. Задания `/eft/quests` — 🟡
`[slug]` ветвится: сюжет→`getStoryQuest`→гайд; трейдер→`QuestTraderList`; иначе заглушка. `task/[id]`→`QuestDetail` (деталка).
- ✅ Трейдеры (11: prapor…btr-driver) → список квестов (реально, из EFT_QUESTS).
- ✅ Деталка задачи `task/[id]`, лендинги lore-quests/side-quests.
- 🟡 Сюжетные (10: Тур/Батя/Билет/…) → реальны ТОЛЬКО для написанных глав; ненаписанные → заглушка. **Контент (B1)**.
- 🔴 События (events) → заглушка.

### 5. Кодекс `/eft/gamesetting` — 🟠
`[slug]` ветвится: `getCodexArticle`→`CodexArticle`; иначе заглушка.
- ✅ Боссы (+деталка), Торговцы (+деталка), Персонажи, Материалы.
- 🟡 Лор-страницы (История мира, Хронология, Фракции, Корпорации, Локации, Аудио, Документы, Теории) → реальны только для написанных статей; остальное заглушка. **Контент (B2)**.

### 6. Видео `/eft/videos` — 🔴
`[category]` — **чистая заглушка** (нет ветвления). Гайды/Советы/Новости/Стримы — все 4 пустые → строить модуль (агрегатор/встройка YouTube/Twitch) (**C1**).

## Метод
Идём группами A→B→C→D или по выбору V4DYA. По каждому пункту: реальная страница / заглушка / мёртвый линк → чиним (строим компонент, подключаем данные/синк, пишем контент, или убираем линк). Отмечаем чекбоксы здесь.
