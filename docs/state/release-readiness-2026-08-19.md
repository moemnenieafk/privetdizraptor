# Срез 19.08.2026 — план коммерческого релиза ЦТА

Снимок состояния + план подготовки/полировки по разделам + фронт работ. Преемствует [[snapshot-2026-08-16]] и [[release-readiness-2026-08-08]]. Основан на живом коде (121 страница / 68 API-роутов) и аудите борда `docs/decisions/`. **Развилки разрешены грилом с V4DYA 19.08** (см. «Решено грилом»).

## Что такое «релиз» (уточнено V4DYA)
Не soft-launch бесплатного ядра, как трактовали прошлые снапшоты, а **полный коммерческий запуск**:
1. Все разделы вылизаны до **«минимум багов / максимум производительности»**.
2. **Аккаунт-центр завершён** (в т.ч. биллинг-вкладка).
3. **Живой биллинг** с монетизацией разделов и фич — 3 уровня подписки.
4. Запуск сразу **на автономном стеке** (Hetzner+Cloudflare), не на Vercel.

## Картина в одну минуту
1. Портал функционально готов; шоу-стопперов нет. Работа релиза = **полировка + монетизация + переезд**, а не стройка нового.
2. Дату задаёт **внешний трек** (рельс оплаты Димы + касса 54-ФЗ), а не код. ИП уже есть → онбординг+фискализация — дни-недели.
3. Всё, что не зависит от рельса (полировка, E4-гейтинг, аккаунт-центр), катаем **сейчас параллельно**; E5 (интеграция оплаты) стыкуем последним.
4. Узкое место прежнее — дизайн-ответы V4DYA, ручной контент (скрины), захват данных.

## Решено грилом (19.08) — фиксировано
1. **Релиз на автономном стеке** (переезд ПЕРЕД публичным запуском; домен `cta.quest`). Флип безболезнен, пока трафика нет.
2. **Биллинг v1 = ЮKassa/РФ**, один регион. Мульти-регион (EU VAT и т.п.) — post-launch, отдельный воркстрим.
3. **ИП есть.** Рельс (решение Димы) + касса 54-ФЗ = **параллельный трек, задаёт дату релиза**. E4-гейтинг + полировка + аккаунт-центр от рельса не зависят → идут сейчас. **E5 (оплата) — последний стык.**
4. **DoD раздела** (чек-лист, проходим по разделам, V4DYA подписывает): P0/P1-багов = 0 (P2/P3 → бэклог) · Core Web Vitals зелёные + прицельный перф · мобилка-смок · NIGHTFALL стиль-долг = 0 · визуальный sign-off. Предусловие — **единый баг-триаж-борд** (свести `bugs-triage-2026-07-19` + `Ревизия MVP 28.07` + новые находки).
5. **Линия free/paid:**
   - **База-6 (бесплатное ядро, строгий баг-бар первым):** Карты · Задания · Предметы · Кодекс · Видео · Связь — **просмотр + базовый поиск/фильтр = FREE** (витрина + SEO).
   - **За пейвол (умные удобства):** облачный синк между устройствами · безлимит избранного/сборок · продвинутая аналитика/агрегация · история цен · выгодный бартер на карточке.
   - **Прогресс = freemium:** дать попробовать удобства → пейвол, 3 тира (Боец free / Оперативник / Ветеран).
   - **Поштучная матрица «фича→тир» НЕ здесь** — это аудит F5 спринта [[feature-gating-entitlements]] (4 открытых решения V4DYA).
6. **Задания:** УЛ-плиточный редизайн **уже сделан V4DYA** → редизайн НЕ блокер. Остаётся: реконсиляция данных 1.1.0.0 (`json.tarkov.dev/tasks`, §4.12) + добить баги (ветка `feat/quests-cluster-fixes`). Полируем текущий вью.
7. **Аккаунт-центр «завершить» = биллинг-вкладка** (тарифы → оплата → управление → чеки 54-ФЗ, приезжает с E5) **+ дотянуть трекинг пары фич** (сейчас часть таб-заглушек `available=false «скоро»`) + QA-проход остальных вкладок.
   - ✅ **06.09:** вкладки «Платежи»/«PRO-статус» и витрина тарифов сделаны — [[account-billing-tier-showcase]] (ветка `feat/billing-tier-showcase`, не запушена). Остаётся оплата (E5), чеки 54-ФЗ и QA прочих вкладок.
8. **Перфоманс:**
   - **Долгая загрузка = латентность (сервер далеко), НЕ джанк** → лечит переезд (Cloudflare CDN раздаёт статику глобально), не оптимизация кода.
   - **Реальный джанк (в перф-DoD):** (1) карты при многих маркерах подвисают → кластеризация/канвас/куллинг; (2) Карта заданий при попытке вместить всех торговцев (частично смягчено гейтингом+фильтрацией); (3) быстрый поиск в хедере предметов не всегда мгновенный → дебаунс/предындекс/асинхрон.
9. **Auth:** кнопки **Twitch и Discord скрыть** (провайдеры остаются настроены, спят). Основной вход — email/пароль.
10. **Переезд Ф1–Ф2 — рано и параллельно** (полируем и тестим уже на целевом стеке Hetzner), флип Ф3 — под конец.
