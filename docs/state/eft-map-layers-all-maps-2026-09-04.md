## 3. ⚠️ Чему верить, а чему нет

Три вещи выглядят собранными, но собранными не являются. Все три ловятся ТОЛЬКО отношением
к рамке, а не счётчиками — счётчики у всех трёх здоровые.

### Зона: у четырёх карт это карман, а не игровая зона

Панели границы не образуют замкнутого кольца, и заливка находит случайный карман внутри карты.
Заведена гарда: доля площади зоны от рамки, поле `plausible` в JSON.

| Карта | Зона | Доля рамки | Верить? |
|---|---|---|---|
| Таможня | 31.29 га | 53.8 % | ✅ |
| Маяк | 66.11 га | 36.2 % | ✅ |
| Ледокол | 0.56 га | 29.6 % | ✅ (корабль и должен быть маленьким) |
| Развязка | 1.23 га | 1.4 % | ❌ карман |
| Лес | 2.45 га | 1.3 % | ❌ карман |
| Берег | 1.62 га | 1.0 % | ❌ карман |
| Резерв | 0.32 га | 1.0 % | ❌ карман |
| Ground Zero, Терминал | — | — | нет корня `*_LevelBorders` в сценах |

**Следствие:** на этих четырёх картах маской зоны НЕЛЬЗЯ клипать соседние слои — отрежет живое.
Флаг `inGameZone` у камней и деление слоя 7 на «в зоне / снаружи» там недостоверны. Сам слой 7
от этого не теряет данные: то, что вне зоны, попадает в группы `*-outside`, а не выбрасывается.

### Дороги: у Резерва и Ground Zero слой пустой

Шаг отработал с кодом 0, а полотна **0 м²**: у обеих карт нет ветки `OO/ROAD` (у Резерва есть
`OO/ROADS` с 421 объектом, дефолтный отбор по ней не идёт). Профиль дорог правится руками
на карту — `recon` даёт числа, решение за глазами.

Реально собраны дороги только у **Таможни** (полотно 36 782 м² после клипа зоной) и **Маяка**
(57 763 м²). У Леса, Берега, Развязки, Терминала и Ледокола дорожной сцены нет в реестре вовсе.

### Терминал лёг мимо рамки

30 188 пересечений, 29 640 контуров, **ноль закрашенных пикселей**: геометрия карты в
px[−29 240, −4 226] при рамке [0, 0, 13 181, 16 384]. Комнаты стоят в X≈195 / Z≈−223, а
синтетический манифест описывает X[−1605, −675] / Z[315, 1471] — то есть `bounds` Терминала
в `EFT_MAP_CONFIG` не соответствуют мировым координатам карты. Гарда `checks.outsideFrame`.

## 4. Не собрано осознанно

| Карта | Почему |
|---|---|
| **Завод** (поворот 90°), **Лаборатория**, **Лабиринт** (270°) | Рамка умеет только 0 и 180. Разворот «на глаз» даёт у Завода **13 % анизотропии** масштаба (118.8 против 104.8 px/м) — квадратное здание легло бы прямоугольником. Привязку надо ВЫВОДИТЬ: у Завода есть `worldTransform` в `EFT_MAP_CONFIG` (11 опор, невязка 0.7 м). |
| **Улицы Таркова** | Нет ни манифеста, ни записи в `EFT_MAP_CONFIG` — рамку строить не из чего. |

## 5. Как воспроизвести

```bash
python scripts/eft-map-layers/run-all.py <карта>              # весь конвейер, 13 шагов
python scripts/eft-map-layers/run-all.py <карта> recon        # разведка, ~15 с
python scripts/eft-map-layers/run-all.py <карта> --only obstacles --force-step obstacles
python scripts/eft-terrain/check-orientation-gate.py          # харнесс гейта, ждём «5 из 5»
```

Шаг с готовым и свежим выходом пропускается сам, поэтому повторный прогон карты дёшев.

## 6. Открытые вопросы

1. **Расхождение с калибровкой сайта на Таможне — НЕ ПРОВЕРЕНО.** `worldTransform` из
   `EFT_MAP_CONFIG` даёт `canvasX = 10803.2 − 15.313·gx`, рамка слоёв — `10687.2 − 15.3112·gx`:
   разница **116 px ≈ 7.6 м по X**. По Y всё сходится (4054 px — это центрирование полосы арта
   в квадратном холсте тайлов). Наши оверлеи ложатся на арт пиксель в пиксель, значит подозрение
   на калибровку сайта; если она врёт, синканные маркеры Таможни смещены на 7.6 м.
   Проверять на живых маркерах.
2. **Камни Таможни на юго-востоке смещены влево-вверх на 6–12 м** относительно нарисованных,
   при этом заборы и трубы совпадают пиксель в пиксель. Кроп для глаз:
   `gen/customs/obstacles/customs-obstacles-stones-offset.jpg`. Решать V4DYA: арт или геометрия.
3. **Классы на картах без ветки `BUILDING`.** У Развязки таких веток ноль, поэтому стены и
   реквизит сваливаются в один класс `props`. Содержимое и силуэты верны, разбивка по классам —
   нет.
4. **Плоский рез на многоуровневой карте без террейна** показывает только уровень основания.
   Ground Zero с его перепадом честнее смотреть слоем стен по этажам.
5. **У стен только SVG, растра нет.** Теней на землю нет, рендер зданий не делался.
