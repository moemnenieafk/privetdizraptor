# NightFall UI — редизайн под 2026 + моушен

**Статус:** ⛔ нет · 📋 **бэклог** (на горизонте, после закрытия стиль-долга)
**Зона:** ui · дизайн-система NIGHTFALL
**Связанные решения:** [[style-debt]] · [[roadmap]]

## Что это
Рефакторинг дизайн-слоя **NIGHTFALL** под визуальные тренды 2026 + добавление анимации/моушена в интерфейс. Инициатива дизайнерская (ведёт V4DYA), не код-долг — это про язык интерфейса, а не про чистку нарушений.

## Как сейчас
- NIGHTFALL: тёмная тактическая тема, токены-цвета, типографика Blender Pro.
- Моушена почти нет: по правилам проекта вместо спиннеров — `animate-pulse` скелетоны; переходов/микроанимаций минимум.
- Перед редизайном логично закрыть [[style-debt]] (сырой HEX, `font-mono`, `rounded-[Npx]`) — иначе тренды лягут на неконсистентную базу.
