# Палитра карт Shebuka (the-hideout) — референс рекраски

Извлечено из `<style>`-блоков served-SVG (Supabase Storage `cta-media/maps/eft/*.svg`)
по 9 Shebuka-картам: customs, woods, shoreline, reserve, interchange, lighthouse,
streets-of-tarkov, ground-zero, terminal. **14 цветов, единая палитра на всех картах.**

**Статус:** перекрашено под NIGHTFALL-палитру (2026-08-15) — колонка «стало».
Рекраска идёт ВСЕГДА от оригинала: `kord-import/_recolor-maps2.mjs` берёт пристинные
бэкапы `kord-import/_backup/*.PRECOLOR.svg` (the-hideout) → маппинг оригинал→новейший →
Storage. Значит палитру можно менять сколько угодно без накопления искажений.

7 карт используют СЕМАНТИЧЕСКИЕ классы (`.water`, `.building`…) → роль слоя однозначна.
Таможня и Развязка — на `.st20…st47` (kord), но HEX те же → рекраска по цвету накрывает и их.

## Каверзы рекраски

- **Count ≠ площадь.** Фон (`.land`, `.water`) — один огромный полигон (мало элементов,
  красит весь экран). `.floor`/`.building` — сотни мелких путей. Визуально доминирует land.
- **Замена по HEX** (не по классу) — одно правило в `<style>` красит все элементы класса.
- **Не Shebuka** (своя палитра, свотчи отдельно): Ледокол, Лабиринт — tarkov-market;
  Лаборатория — kord; Завод — растровые HD-тайлы (палитрой не красится, нужен ре-рендер арта).
