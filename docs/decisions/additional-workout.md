# Роадмап доработок ЦТА (мастер-план)

Распределение «списка с отключённым светом» по эпикам, приоритетам и заметкам-владельцам.
Порядок утверждён V4DYA: быстрые победы → **Монетизация** (№1) → Карты → Mobile-first → CMS.

## Легенда тегов
- **Размер:** `S` (1–2 файла, <½ сессии) · `M` (эпизод, 1 сессия) · `L` (длинный прогон / разбить на под-задачи).
- **🤖 agent** — можно/нужно отдать фоновым агентам (research, контент, извлечение данных): делаем, когда рантайм основной сессии на исходе.
- **⚠ manual** — нужен ручной ОК (БД: db:sql/db:push, ключи/env, пуш в main, платёжка).
- **🔒 dep** — есть зависимость (указана).

## Стратегия под лимиты (утв.: оба подхода)
- **Лимит-устойчивые (S + 🤖):** футер, контент историй, все research-заметки, дешёвая расстановка маркеров, инвентаризация MVP-аудита. Делаем «на остатках» рантайма и фоновыми агентами.
- **Длинные прогоны (L):** paywall-гейтинг, Boosty, mobile-first аудит, CMS-экраны, гейт-чек MVP. Берём в начале свежей сессии, дробим на чекпоинты с промежуточными коммитами.
