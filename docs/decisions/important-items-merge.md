# Объединённая страница «Важные предметы» = слияние двух трекеров

## Цель
Один экран `/eft/progress/needed` «Важные предметы» отвечает на вопрос «что мне налутать/докупить и сколько» по всем источникам сразу (квесты + убежище), с минимумом кликов — заменяет два раздельных трекера («Трекер предметов» `/tracker` + «Важные предметы» `/needed`).

## Границы
- **В scope:** новый UI объединённого трекера (двухколоночный рейл на `TrackCell`); редирект `/tracker`→`/needed`; чистка пункта меню; параметризация `dump-quests.mjs` под `pve`; синк убежища (regular+pve); ридер-индекс «предмет → кому нужен».
- **НЕ трогаем:** квест-карту, Досье, страницу Убежища `/eft/progress/hideout` (только переиспользуем `HideoutLevelsPanel`); `battlepassVisual.tsx` (вынос `TrackCell` в канон — отдельный заход); GraphQL `api.tarkov.dev` (§4.12); buildWeapon/оружейку (вне трекера v1).

## Решения (грил + данные)
**Ось:** единый список ПО ПРЕДМЕТУ (не табы) — одна запись/предмет, агрегирует квесты+убежище.
**Прогресс:** агрегат для показа; **ЛКМ+1/ПКМ−1** льётся в первый незакрытый источник и пишет в родные сторы (синхрон с квест-картой/Досье/убежищем); разворот — точечный редакт по источникам (QtyControl для крупных чисел). **Приоритет авто-распределения:** FiR-квесты → не-FiR квесты → убежище.
**FiR:** «нужно N (⚡M FiR)», **per-source** (и квесты, и убежище — 76 FiR). «В стэше/докупить» гасит только не-FiR остаток.
**Стэш:** в строке чисто «собрано M / нужно N (⚡FiR)»; «в стэше S · докупить B» — в **развороте**.
**Раскладка:** двухколоночный рейл в стиле «ТРЕКЕР ДОКУМЕНТАЦИИ TERRAGROUP». Контент 1100px → 2 колонки span-3 (536px) + гэп 28. Строка: слева **ячейка 112px** (`TrackCell`: иконка+заливка+X/Y), справа имя + собрано/нужно(⚡FiR) + «где найти» → разворот. **Две независимые masonry-колонки** (разворот толкает свою; порядок 1,3,5 / 2,4,6).
**Сортировка:** по прогрессу (незавершённые/почти-готовые вверху) + **снап-порядок** (снапшот замораживает; +/− не переставляет) + «Убрать собранные (N)»; опц. смена сорта.
**Фильтры:** поиск + «скрыть готовые» + «только FiR».
**Убежище:** сворачиваемый `HideoutLevelsPanel` сверху (переиспользуем, свёрнут; пишет `useHideoutStore`).
**Сводка:** MetricCards — Всего / Собрано / Осталось / **Докупить** (не-FiR остаток) + общий прогресс-бар.
**Маршрут:** живёт на `/needed` «Важные предметы»; `/tracker`→redirect; из меню убрать «Трекер предметов»; кросс-ссылки на `/tracker` перенаправить.

### Категории целей (раздельная обработка)
- **single-item** (485 кв + 289 убеж) → ядро per-item списка.
- **any-of** (83) → отдельная **групповая строка** «N из категории» (разворот — принимаемые). **Требует доработки `dump-quests.mjs`:** сохранять `acceptedItems[]` у any-of objective.
- **квест-предметы** (222) → в общем списке, бейдж **«только рейд»**, без «в стэше/докупить».
- **buildWeapon** (30) → вне v1 (оружейка отдельно).
