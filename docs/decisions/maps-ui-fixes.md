## Находка по Терминалу (2026-06-28)
Сверка с авторитетным источником (the-hideout/tarkov-dev `src/data/maps.json`, MIT — откуда портированы ВСЕ карты):
- наш `transform: [0.2,0,0.2,0]`, `coordinateRotation: 180`, `bounds: [[463,-580],[-433,475]]` — **идентичны** значениям tarkov-dev для Terminal;
- наш `terminal.svg` (Supabase) имеет **тот же viewBox** (`887.7×1043.96`), что оригинал `assets.tarkov.dev/maps/svg/Terminal.svg`;
- рендер-путь (`L.imageOverlay(url, svgBounds ?? bounds)`) — generic, общий для всех карт.

**Итог:** конфиг + SVG + рендер у нас совпадают с источником → портировать/калибровать по данным **нечего** (изменение разошлось бы с правильным upstream). «Сдвиг» либо устарел (виден во время сломанной сборки), либо присутствует и в самом upstream (Terminal — новая community-карта, их transform может быть неидеален). Нужен **визуальный re-check** на :3000 (браузер-расширение при разборе было не подключено). Если сдвиг подтвердится — это ручная калибровка с осознанным расхождением от upstream, требует глаз/браузера.
