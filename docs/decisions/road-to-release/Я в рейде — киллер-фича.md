### Что уже в коде (сверка 08.08)
- **Vision-пайплайн через Gemini живой** — `/api/profile-ocr` (Gemini 2.5 Flash, structured output, rate-limit 10/ч). Цепочка «скрин→сервер→JSON» существует (для профиля).
- **Tesseract на шрифте барахолки обучен** — `public/tessdata/eftflea.traineddata` (8000 синт-сэмплов, `scripts/ocr-train/`). Флеа-OCR клиентский (tesseract.js) читает **текст**-список.
- **Тиры есть** — `free / operative(199₽) / veteran(449₽)`: `subscriptions`, `Paywall.tsx`, `useSubscription`, карта `FEATURE_MIN_TIER` (пустой слот `ai_options`). НЕ «free/premium/tier-3» из заметки.
- **rate_limits** — таблица fixed-window, обкатана на логине/регистрации.
- **quest_progress** — прогресс на юзера; `/eft/progress/needed` (важные) и `/eft/progress/tracker` читают одно и то же (`EFT_QUESTS`+`quest_progress`) → «дублирование» не в БД, а два вью одного датасета.
- **5044 иконки предметов 1:1 в Supabase** (извлечены из файлов игры, пиксель-в-пиксель) — ground-truth для матчинга.
- **Companion watch** — `CompanionReader` / `eft-screenshot.ts` уже слушает папку скринов EFT (File System Access API, Chromium).
- **Нет:** биллинга (тиры руками кроном `set-tier`) · Ctrl+V paste (EFT пишет PNG в файл, не в буфер) · lookahead квестов · «OCR на карте» — миф (парсинг координат из имени файла, не картинки).

### 🔑 Инсайт, сменивший движок
Инвентарь = **сетка иконок без подписей**. Барахолочный Tesseract читает текст — в инвентаре текста-названий нет → подход 1:1 не переносится. Опознать предмет можно только (A) vision-моделью «на глаз» или (B) матчингом клетки против 5044 иконок. **Выбран B** → фича становится бесплатной, детерминированной, без датасета и без биллинга ИИ.

### MVP / не-MVP
**В MVP:** скан Tab-экрана → матч иконок → read-only вью (бюджет + нужность по предмету), карточки по образцу [[Бартер.md]]; пейволл-ладдер на существующих тирах; лимит сканов через `rate_limits`; админ тир-превью.
**НЕ в MVP (→ v2):** lookahead «через N квестов» (veteran) · синк с трекером и слияние важные+трекер · буфер «Найдено в рейде» с подтверждением после выхода · оценка собранного оружия · Stripe.

### Инженерный порядок (де-риск первым)
- **Фаза 0 — спайк.** 20 реальных Tab-скринов → прототип матчера (сегментация зон + перцептивный матч, маскируем оверлеи: стак-счётчики / полоски прочности / поворот 90°). **Go/no-go — ДО любого кода фичи.**
- **Фаза 1 — матчер + SPT-гейт** (если спайк жив): прод-матчер, SPT авто-разметчик → точность в %.
- **Фаза 2 — «просто UI»:** роут/страница, watch+upload (переиспользуем `CompanionReader`), вью (джойны `prices`+`EFT_QUESTS`+`hideout`+`quest_progress`), гейт `Paywall`+`useSubscription`, админ-свитч.
- **Фаза 3 — v2:** lookahead, синк-трекер, оценка оружия.

### Открытые точки (в спеку, не блокеры)
- **Где крутится матч:** клиентский hash-индекс (~40 КБ на 5044, мгновенно, без аплоада) vs серверный роут. Прецеденты оба (флеа — клиент, профиль — сервер).
- **Накопление:** каждый скан = свежий снимок vs юнион последовательных сканов (снял разгруз → открыл рюкзак → доснял).
- **Точный лимит free** (в заметке «2/час» — догадка) — тюним.
- **Геометрия под 1.1.0.0** — брать от актуального клиента (патч перекроил карманы), см. [[BSG 1.1.0.0 — влияние на портал.md]].

## Суть
«Я в рейде» — главная киллер-фича портала. Заменяет бесполезные вкладки «Рейтинг предметов» (S/A/B-тиры) и «Цена за слот». Игрок делает скриншот инвентаря → нейросеть/OCR мгновенно распознаёт → сайт выдаёт подсказки по ценности лута и прогрессу квестов.

## Как сейчас
- Есть вкладки «Рейтинг предметов» (S/A/B/C/D/F-тиры, табличный вид, авто-собран) и «Цена за слот».
- OCR-распознавание скриншотов **уже работает** на барахолке и на карте (тот же принцип).
- Механизм обкатан в «Компаньоне»: отдельная кнопка трекинга, авто-подхват папки скриншотов.

## Решения созвона
- **Удалить «Рейтинг предметов»** (S/A/B-тиры) — бесполезно, требует постоянного альт-таба, в рейде результата не даёт.
- **Удалить «Цена за слот»** — создаёт путаницу с «Рейтингом».
- **Заменить обе на «Я в рейде».** Механика: PrintScreen в игре → Alt-Tab → **Ctrl+V** на сайте → распознавание инвентаря. Самый простой путь: только принтскрин, сайт сам подхватывает (стакает и распознаёт текущий скриншот).
- **Что показывает:**
  - Суммарная стоимость залутанного по барахолке (бюджет).
  - Ценность по **текущему и будущему** прогрессу квестов.
  - Тактические подсказки в реальном времени: «оставь 3 печатные платы — нужны через 2 квеста»; «убери Ледикс в подсумок, выброси Ибупрофен, иди на выход»; «Ледикс ты уже сдавал — ценный, но не нужен».
- **Объединить «важные предметы» + «трекер предметов»** в один раздел (решает дублирование в БД). Красивые карточки по образцу [[Бартер.md]]. «Я в рейде» / «Найдено в рейде» / «Твой схрон» синхронизируется с трекером.
- **Paywall (тиры):**
  - **Free:** ограниченное число сканирований в час (напр. 2), только суммарная стоимость инвентаря / по каждому предмету.
  - **Premium:** неограниченно, детальный разбор по каждому предмету, подсказки под текущий прогресс квестов/убежища.
  - **Tier-3 (самый дорогой):** доп-инфа «это на будущее, оставь». Киллер-фичу прятать за самый дорогой paywall (нужен биллинг нейросети).
- **Админ-переключатель ролей:** просмотр сайта от лица Гость / Премиум / Админ (как роли в Discord) — видеть, что закрыто за paywall. Для всех админов.

## Технология распознавания
- Распознавание — **Gemini Flash** (бесплатно, распознаёт лучше остальных; «ничего это не дорого»).
- Под капотом OCR-движок **Tesseract** с обученным датасетом (шрифт цифр барахолки, образы предметов). Для компаньона датасет собирался ~30 мин на Google Colab.
- **Блокер:** сбор датасета под образы/шрифты Tarkov (у барахолки ~8 млн вариаций построения цифр).

### Обход блокера датасета — авто-разметка из SPT (находка 2026-08-02)
Разобрали мод **LootNet** ([forge 2679](https://forge.sp-tarkov.com/mod/2679/lootnet) · [GitHub diemitze/LootNet](https://github.com/diemitze/LootNet), MIT): офлайн SPT-плагин, читает инвентарь напрямую и суммирует ценность рейда. Как **механика** «Я в рейде» — НЕ подходит: прямое чтение памяти = BattlEye-бан на live (фича потому и на скриншот-OCR). Но офлайн-SPT **знает точный состав инвентаря** (ground truth) → это готовый **авто-разметчик датасета**, снимающий блокер выше:
- SPT офлайн, произвольный инвентарь → скрин снаряги (визуально **идентичен live** — тот же клиент/шрифты/иконки) + дамп состава (id) из мода/`profile.json` → пара «изображение ↔ список предметов» **без ручной разметки**.
- Скриптом гоняем сотни/тысячи пар → **обучающая выборка Tesseract + валидационный набор** для замера точности Gemini Flash (тот самый шрифт цифр барахолки и образы предметов).
- LootNet — MIT: паттерн «прочитать лут server-side в SPT» берём как есть; либо читаем `profile.json` напрямую (там весь инвентарь). Нужно, чтобы источник **дампил id в файл**, а не только показывал в UI.
- Переносимость: работает, пока UI/иконки/шрифты SPT совпадают с live (сейчас — да). Это **тулинг сбора данных**, не сама фича — «Я в рейде» всё равно строится на скриншот-OCR.
