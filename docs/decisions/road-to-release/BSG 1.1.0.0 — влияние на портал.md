# ⚠️ BSG 1.1.0.0 — влияние на портал

**Статус:** 🟢 патч вышел 03.08.2026 (сезон **Kord Breach**). Прогноз от 28.07 подтверждён официально; охват — шире квестов, задет весь портал.
**Повод:** V4DYA принёс офиц. патчноут в день релиза, попросил подготовить почву и решить, что делаем с квестами и не только.
**Роль заметки:** хаб-карта последствий по всем фронтам; детали и исполнение — в соседних заметках (ссылки в таблице).

> [!info] Тайминг релиза
> Сервера встали на обновление, установка **6–8 ч**. Дальше цепочка: BSG прогревает сервера → tarkov.dev датамайнит новую базу → наш крон-синк (§4.11) зеркалит. **Всё, что зависит от данных (квесты, цены, предметы, маркеры) — физически ждёт этой цепочки.** В «окно» делаем только то, что от данных не зависит.

## Прогноз подтверждён (квестовое ядро)
Ключевая гипотеза от 28.07 верна — **побочки больше не цепочки**:
- Побочные задания привязаны к **уровню лояльности (УЛ)** торговца, открываются наборами по **2–4**; новый набор — за выполнение нескольких в текущем УЛ или за новый УЛ.
- Основная награда → **деньги, опыт, репутация** (меньше бартер-предметов).
- **Цепочки-исключения остаются** (редкие ТП/рецепты крафта); ключевые награды видны уже при взятии первого квеста цепочки.
- **Каппа/Коллекционер:** ачив «Путь Каппа» со стартом сезона больше не получить → за «Коллекционера» дают новый ачив **«Рассвет новой эпохи»**; старый остаётся в профиле, скрыт из Steam. «Наследник Криса» стал редким.
- **Страховка:** в сезоне выключена; новая у Егеря (быстро+дорого); Прапор/Терапевт — быстрее и чуть дороже; скидки по УЛ.
- **Устранение Диких в побочках:** засчитываются только обычные/снайперы/Дикие-игроки — **боссы, Рейдеры, Отступники больше не идут в зачёт**.

⇒ **Заморозка снята.** Труд по «цепочкам/симметрии графа» больше не выбрасывается, но и **не переносится один-в-один**: старый граф «до/после» заменяется вью **«квесты по УЛ торговца»**. Пересборка ждёт синка данных.

## Что делаем в «окно» установки (не ждёт синка)
1. ✅ **Комиссия флии 3%→5%** — поправил в коде: `src/lib/barter-calc.ts` и `src/lib/eft-indicators.economics.ts` (`Ti/Tr` 0.03→0.05). Влияет на вердикт бартеров, ROI, «Поток сделок». *Константа была продублирована в двух файлах — обе точки закрыты (кандидат на DRY-вынос позже).*
2. ✅ **Эта заметка** переведена из прогноза в релизный хаб (переименована из «…влияние на квесты»).
3. ✅ **Задел по сезонам** — [[Сезоны и Боевой Пропуск.md]].
4. ✅ **Слепок дорелизных бандлов клиента** снят (`scripts/icon-render/snapshots/`) — diff после патча найдёт новый контент автономно. Prep-рунбук рендера иконок: [[assets-1.1.0.0-render-sprint.md]].
5. Планирование пересборки квестовых вью под УЛ — не трогая данные.

## Что ждёт синка (после старта серверов)
- Данные квестов (новые УЛ-наборы, выжившие цепочки, точный список Коллекционера) — §4.11, не сверять вручную.
- Новые цены торговцев (+25% / −20%) — из зеркала автоматически.
- Новые предметы и калибр 5.8×42 → база + иконки. Иконки появятся **сами** через крон-зеркало tarkov.dev; наш self-render (пиксель-точно, автономно) — по рунбуку [[assets-1.1.0.0-render-sprint.md]]. Цельные стволы (QBZ-191, Howa, HK416A5) = Гейт-3, self-render не реализован → на старте зеркало tarkov.dev.
- Маркеры карт: замки-контейнеры, лифты.
- Размеры контейнеров (мед-кейс, кейс магазинов) → сетки вместимости.

## ❓ Открытые вопросы
- **Точный новый список требований Коллекционера** — в офиц. патчноуте только смена ачива; веб-разборы говорят «УЛ4 со всеми + реп Скупщика + мало квестов». Подтвердить после синка.
- **4 выживающие цепочки под Коллекционера** (Chemical / A Shooter Born in Heaven / Tarkov Shooter / Sew It Good) — в офиц. тексте не перечислены, проверить в игре.
- **Сюжетки остаются цепочками?** Rework официально про побочные; сюжетки, вероятно, не тронуты (+добавлен опыт за прохождение сюжетных историй) — подтвердить. Логика «Билета» жива, если это сюжетка.
- **Данные сезона/БП во внешнем API?** Скорее всего нет → потребуется `/game-data-ingest` из файлов игры. Решить в заделе.
