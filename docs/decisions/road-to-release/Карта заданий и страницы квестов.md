# Карта заданий и страницы квестов

**Статус:** 🔵 обсуждено (1-я итерация), крупная — много задач для Клода
**Источник:** голосовые 2026-07-28 · [[audio_2026-07-28_00-08-15]] (34:25) + [[audio_2026-07-28_00-08-19]] (1:39, баг)
**Участники:** V4DYA, Дмитрий

> [!warning] Учесть BSG 1.1.0.0 → [[BSG 1.1.0.0 — влияние на портал.md]]
> BSG переделывает **побочные задания**: большинство перестаёт быть цепочками, привязка к УЛ торговца. **🔴 Заморожено:** линки, двусторонние связи, симметрия графа, сверка цепочек с Wiki. **🟢 Безопасно:** near-fullscreen, страница-карточка квеста, фикс бага «Выполнено». Сюжетки (включая «Билет»), вероятно, остаются цепочками — подтвердить.

## Суть
Карта заданий — интерактивный граф карточек квестов, показывающий точный путь к цели (Капа, Смотритель маяка). Карточки переиспользуются в побочных заданиях ([[Задания — сюжетные, побочные, события.md]]). Плюс — отдельные страницы конкретных квестов.

## Как сейчас
- Граф из **2000+ нодов**, линии не должны пересекаться. Dev-инструмент «Правка»: перетаскивание карточек с примагничиванием к сетке и соседям; «Копировать позиции» → JSON-разметка координат вставляется в проект (иначе после reload сбрасывается).
- Поиск по заданиям с быстрым перелётом; фильтр по графу торговца; фильтр по карте.
- Фильтрация «оптимальный путь» для Капы и Смотрителя; прогресс (последний выполненный квест, уровень, кол-во выполненных). Стор локальный → импорт/экспорт прогресса (обмен картами заданий между игроками).
- Система **линков/слагов**: если квест с кем-то линкован — подсвечивается имя и квест (напр. «Механик: Авиапочта» ↔ «Терапевт: Стандарты качества»).
- Иконки локаций на панели (выделяют квесты по карте).

## Решения созвона
- **Рендерить одного торговца за раз.** Отказ от одновременного рендера 2000+ нодов/связей — главная причина лагов при отдалении. Выбрал торговца → грузится только его ветка. Переходы между торговцами — через линки-флаги.
- **Убрать иконки локаций** с панели карты заданий. Поиск задания по локации — через глобальный тактический поиск; на графе фильтр локаций только отвлекает. (Насколько используется — свериться со статистикой компонентов позже.)
- **Оставляем отдельные страницы квестов** (не только drawer). V4DYA сначала хотел убрать — потом развернулся: при поиске конкретного квеста должна открываться полноразмерная карточка, из неё — переход на граф.
- **Near-fullscreen** по паттерну интерактивных карт ([[Карты — интерактивные.md]]): шапка сверху, граф до границ вьюпорта. Предупреждение «друголётчик» уже готово.
- **Двусторонние линки (запрос Димы).** Сейчас часть цепочек линкует только «назад». Нужно показывать и ветвление «вперёд» — какие квесты открываются после текущего.
- **Симметрия ветвлений.** Из квеста открывается 3 новых → родитель по центру, линии ровно вниз симметричными лучами (не «куриная лапка» вбок). Пример хорошего: Снабженец по центру → 3 квеста вниз.
- **Перекомпоновка панелей** (слишком много слоёв «давят»): торговцы — слева вертикальным блоком; поиск + fullscreen — наверх (кнопка fullscreen левее поиска); прогресс + импорт/экспорт — снизу.

### Страница конкретного квеста
- Увеличить шрифты по всей карточке; обложку — компактнее.
- Крупные иконки наград (предметы, опыт, деньги); отдельно подсветка прироста/потери репутации торговцев.
- Кнопки «← Предыдущее задание» / «Следующее задание →», «Завершить», «В избранное» (скрепка).
- Кнопка перехода к этому квесту на общей карте заданий.

## 🐛 Баги / проверить
- ✅ **Кнопка «Выполнено» / разблокировка** — **исправлено 2026-07-28** (`QuestNode`). Диагностика: код был исправен (`handleForceComplete` проставляет предков + квест), но разблокировка висела на **скрытом удержании 5 сек** — Вадим жал кликом, оттого «не работало». По решению V4DYA заменил на **клик → подтверждение «Уже прошёл? / Нет» → force-complete**. Убрал hold-механику.
- **Глобальный поиск:** при выборе квеста открывается вся карта заданий вместо отдельной карточки квеста — должна открываться карточка.
- Карта **лагает при отдалении** (см. решение «один торговец за раз»). У Tarkov Help / Market не лагает — ориентир.
- UI-копия: «Другалек» — нужна запятая (обращение) + знак вопроса; надпись не поменяли.
- Дубли/неточности в цепочках после квестов-лабиринтов (открывается 5–6 квестов сразу) — Дима переписывал правильный порядок руками, свериться.
