## Как сейчас
- **Сюжетные:** 10 статичных цепочек-историй (отличаются от побочных числом шагов). Клик → отдельная страница квеста, прогресс по шагам кнопкой «Выполнено», в каждом шаге видео-прохождение + скриншоты. Функционал залочен (готов). Отжать «Выполнено» можно вручную; есть общая кнопка сброса цепочки (в настройках аккаунта). Текст правит админ.
- **«Сообщить об ошибке»:** прописано **только** на странице сюжетных квестов (щепетильная тема из шагов, можно что-то забыть). Форма: email + до 5 скриншотов + сообщение → в модерацию.
- **Побочные:** список квестов всех торговцев; переиспользуют карточку с карты заданий; клик → drawer справа (переиспользуемый, из карты заданий): название, кто выдаёт, задачи (прокликиваются, синхронизируются со стором профиля/трекингом), встроенный трекер предметов. Есть глубинный фильтр: доступные / завершённые / заблокированные.
- **События:** хронология всех ивентов игры + текущий; фильтрация по праздникам / боссам / сезонам; поиск.

## Решения созвона
- **«Сообщить об ошибке» — убрать надпись-ссылку**, заменить сгенерированным контекстным текстом «ты сообщаешь об ошибке на странице, где сейчас находишься» (официально и понятно), чтобы человек не думал, что надо вводить ссылку. Оставить только на сюжетных.
- **Автозаполнение email:** авторизованному подставлять его почту (с возможностью изменить), не заставлять вводить каждый раз.
- **Лимиты вложений:** до 5 скриншотов, ~500 КБ каждый. Приходят в админку во временное хранилище, удаляются после просмотра (~300 МБ на серваке хватит).
- **Изоляция маркеров на карте:** при клике на пин квеста из drawer побочки открывается карта конкретного места, и **все посторонние маркеры (бартер, ключи и т.д.) авто-выключаются** — остаётся только квестовая цель. Улучшает понимание, куда идти.
- **z-index кнопки «Завоз»:** при открытии drawer побочки «Завоз» (и подобные плавающие) должны перекрываться drawer'ом.
- **Иконки торговцев** в фильтре побочек — горизонтальной строкой под навигацией раздела.
- **Синхронизация «Задачи ↔ Трекер предметов»:** жёстко слинковать. Прожал галку на задаче → трекер забивается нужным количеством предметов (и наоборот). Все задачи + весь набор предметов выполнены → квест авто-закрывается.
- **События русифицировать** (уйти от англицизмов: «текущий ивент» → «текущее событие»).
