# Прогресс, Убежище, Калькуляторы

**Статус:** 🔵 обсуждено (1-я итерация)
**Источник:** голосовое 2026-07-28 · [[audio_2026-07-28_00-08-31]] (10:58)
**Участники:** V4DYA, Дмитрий

## Суть
«Прогресс» — ядро прогрессии игрока: архетипы, геймификация (карма, очки профиля, аркады), путь новобранца. Плюс интерактивное Убежище и калькулятор бартеров/крафтов.

## Как сейчас
- Прогресс собирает функции трекинга и достижения целей.
- **Убежище:** интерактивная постройка модулей, трекинг ресурсов фиксируется в аккаунте (прогресс-бар по предметам).
- **Ферма биткоинов:** простой калькулятор (кол-во видеокарт → суточная прибыль).
- «Прибыль убежища» — не пересобрана в дизайне, просто отображает прибыль.
- Калькулятор бартеров/крафтов есть, но раньше был сложной мини-игрой с таблицами.

## Решения созвона
- **11 архетипов**, авто-определяются по действиям на сайте: частый просмотр цен + фильтры → «Барыга»; крафты + модули убежища → «Бывалый»; новый → «Новичок». Меняются вручную. Архетип задаёт **изначальную расстановку карточек** на главной EFT (карточки переставляемы).
- **Геймификация:** очки профиля **гейтят доступ к фичам** сайта + система кармы. Публичный профиль + профиль аккаунта (аккаунт-центр — отдельный разговор).
- **«Зал автоматов»** — аркадные мини-игры для ожидания (напр. поиск рейда), завязаны на рейтинг/репутацию.
- **«Путь новобранца»** — 10 простых шагов освоить Тарков, с бонусом за прохождение.
- **Калькулятор бартеров/крафтов пересобрать по образцу Tarkov Market:** сверху поиск предмета + выбор торговца + уровень лояльности; ниже — честная сортировка по мгновенному профиту. Раскрытие себестоимости компонентов (монета GP за 50к → обвес за 160–180к = профит 90–130к). Прибыль бартера и крафта — одна механика. «Пусть будет мини-игрой», но суть — удобство, как на Tarkov Market.
- **Связь с убежищем:** калькулятор учитывает уровни модулей (у каждого 3 уровня) и построен ли нужный модуль; учёт уникальных крафтов.
- **Вкладку «прибыль бартера» убрать** — она уже есть в карточке каждого товара (заходишь → видно, выгодно забартерить или нет).

## Что делать
- Пересобрать калькулятор бартеров/крафтов (поиск + торговец + уровень лояльности + сортировка по мгновенному профиту + раскрытие себестоимости).
- Линковать калькулятор с построенными модулями убежища (+ их уровни).
- Освежить дизайн блока используемых предметов (доделать сбор инфы по инъекторам и пр.).

## 🐛 Баги / проверить
- «Прибыль убежища» не модерирован и не пересобран в дизайне — переделать.

## 🤖 Задачи для Клода
- Реализовать 11 архетипов: авто-детект по поведению + ручная смена + расстановка карточек главной под архетип.
- Калькулятор профита бартеров/крафтов с раскрытием себестоимости; привязка к убежищу (уровни + построен ли модуль). Цены — из зеркала (§4.11, см. `/cta-backend`), не рантайм-фетч.
- Система очков профиля/кармы (гейт фич сайта).
