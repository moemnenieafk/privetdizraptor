## 1. 🔴 Граф квестов («Карта заданий») — главный открытый кластер
Источник: [[2026_07_25_Раздел_«Карта_заданий»_и_страницы_квестов]] + голос `audio_..._00-08-15`. Дом для исполнения — спринт квест-вью под УЛ 1.1.0.0 (данные ✅, вью ⏳ ждёт дизайн V4DYA).

- ⏳ **Лаг при отдалении графа** — главная боль модуля. Решение из раскладки: рендерить **одного торговца за раз** (клик по иконке торговца → его линейка), убрать фильтр локаций, минимизировать ноды/линии.
- ⏳ **Двусторонние линки квестов** — показывать не только «до», но и «после»; сквозная сверка цепочек по Tarkov Wiki, убрать пересечения.
- ⏳ **Кнопка «Выполнено» не срабатывает** — V4DYA дословно: *«сколько ни нажимал — не разблокировать… это последнее, что надо»*. Проверить работоспособность разблокировки квеста. **Кандидат в баг релиз-качества.**
- ⏳ **Глобальный поиск → граф вместо карточки** — при выборе квеста из поиска открывается вся карта заданий, а должна — детальная карточка квеста (с неё уже переход на граф в точке).
- ⏳ **Смотритель маяка / Капа** — если сюжетка («Билет») открывает Смотрителя досрочно, автозачесть его цепочку на графе (связка сюжетных и побочных разблокировок).
- ⏳ **Сквозная ревизия данных квестов** по Wiki — задачи (точное «убить 10», а не «любых»), награды, опыт, деньги, репутация, выбор торговца сдачи, картинки наград, требования издания.
- ⏳ **Карточка квеста** — кнопки «← предыдущее / следующее →», крупнее шрифты, полноэкранный режим по паттерну карт, симметрия веток (родитель по центру, без «куриной лапки»).

**Вывод:** это отдельный спринт и он гейтится дизайном квест-вью (гибрид УЛ-плитки+цепочки). Часть — чистые баги (кнопка «Выполнено», поиск→граф), их можно чинить **до** редизайна.

## 2. 🟠 Трекеры предметов — объединение + баги
Источник: голос `audio_..._00-08-38`, раскладка 25.07 (раздел «Я в рейде»). Существующее: [[player-tracking-tab]], [[tracking-needed-items]], [[tracking-favorite-items]] (done).

- ⏳ **Объединить «Важные предметы» + «Трекер предметов»** в один раздел (одна таблица в БД, красивые карточки, фильтры «убрать собранные / незавершённые квесты»). По раскладке — это зонт «Я в рейде».
- ⏳ **Баги трекера:** дубли квестов (аккумулятор ×2 «Авторем», АК ×2 «Каратель ч.5», Salewa ×2 «Дефицит»); плюс/минус не убирает предмет; «сброс» визуально сбрасывает и тут же возвращает «всё найдено». **Кандидаты в баги релиз-качества.**
- ⏳ **Проактивный сбор** — показывать предметы для ближайших/заблокированных квестов заранее, с шансом на карте (LEDX по EC ~50%), «ты на этой карте — можешь собрать тут». → за paywall с бесплатной пробой.
- ❓ **Отслеживаемые модули убежища в трекере** (как на Tarkov Market) — сверить, что уже есть (hideout-трекинг [[tracking-hideout]] сделан).
- ⏳ **Удалить вкладки «Рейтинг предметов» (S/A/B) и «Цена за слот»** — признаны бесполезными/путающими. Простое удаление.

## 4. 🟡 Дровер квестов ↔ карта
Источник: голос `audio_..._00-08-09`. Частично покрыто скиллом map-interactions.

- ⏳ **Клик по пину квеста → карта в точке, скрыть все прочие маркеры** (бартер/ключи), оставить зону этого квеста. Чёткий UX-запрос.
- ⏳ **Связка трекер ↔ задача:** закрыл задачу → списываются предметы и наоборот; квест закрывается автоматически, когда прожаты И задачи, И количество. Сейчас баг — не закрывается без прощёлкивания трекера.
- ⏳ **z-index кнопки «Завоз»** — перекрывает контент дровера, увести влево/под дровер.
- ⏳ **Дровер вмещает весь текст** (длинные названия типа «Эпицентр» обрезаются).
- ⏳ **«Сообщить об ошибке»** — работает только на сюжетных; убрать поле ссылки → текст «сообщение относится к текущей странице», авто-email авторизованного, лимит 5 скринов ~1 МБ, не хранить (админка → посмотрел → удалил).
- ⏳ **Русификация «текущего ивента»** + бегущая строка события; проверить события — часть спарсилась некорректно (даты/названия «нейросеть выдумала»).
