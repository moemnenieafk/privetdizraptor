## Карта заданий (/eft/questmap) — 3 гэпа закрыты
- **УЛ-табы I/II/III/IV** на мобилке: вертикальная полоса у левого края канваса (`QuestTierToggles orientation='vertical'`), гейтится `!isGate`. Логика та же (enabledTiers / ПКМ-фокус ряда).
- **Поиск** (`QuestSearchSheet`): чипы ВСЕ/Смотритель%/Каппа% + лента портретов + строки-результаты с трейдер-тинтом; фильтр по каппа/лк/торговцу, поиск клиентский.
- **Шит закреплённых** (новый `QuestPinnedSheet`, sheet `'pinned'`): триггер-скрепка со счётчиком в `MobileQuestBar`, тап=перелёт, ✕=снять закреп.

## Карты локаций (/eft/maps/[slug]) — 4 гэпа закрыты
- **ЗАВОЗ-таймер**: новый `MapRestockChip` в `MobileMapBar` (аватар ближайшего торговца + живой отсчёт из зеркала restock, §4.11-safe).
- **Легенда/фильтр маркеров**: `MapLayersDrawer` сделан адаптивным (мобилка = bottom-sheet); дерево категорий/счётчиков переиспользовано 1:1, синхронно с `useMapViewStore.activeFilters`.
- **Меню инструментов** (новый `MapToolsSheet`, sheet `'tools'`): метка / линейка / редактирование / удаление / GPS; собран из `useMapUiStore`, триггер-гаечник в `MobileMapBar`.
- **Поиск на локации** — `MapSearchDrawer` уже был адаптивным bottom-sheet; сверено с макетом M5, правок не потребовалось.

## ⚠️ Остаточный PLACEHOLDER (данные)
**Map-пины M6 — квест-уровня, не пообъектные.** У `TaskObjective` нет координат в зеркале; на интерактивных картах геометрия агрегируется в `MapQuestZone` по `questId` (одна зона на квест). Поэтому пин у любого объекта летит к **зоне квеста** (координаты не выдумывали, §4.11). Пообъектная точность (каждый пин — своя точка) = **новый синк `objectiveId → {x,z}`** (данных сегодня нет; пообъектные маркеры есть только на статик-карте Ледокола). Плюс мелочь: в макете пин зелёный (`quest-visit`), в коде — амбер-«locate» (паттерн проекта); свап на `text-success` — одна строка, если захочешь по макету.
