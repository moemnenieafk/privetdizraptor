# Мобильная адаптация «Карта заданий» и «Карты» по готовым макетам Figma

**Статус:** ✅ обе мобилки доведены до макета, `tsc`=0, **не в main** (ждут теста V4DYA и мёржа).
**Как сделано:** сессия `/autopilot` — разведка кода → 2 параллельных субагента (файлы страниц не пересекаются), каждый по паттерну `cta-mobile` + `figma`, Figma-ноды сняты через `get_design_context`. Правки строго в мобильном слое (`lg:hidden` / мобильные ветки адаптивных оболочек), десктоп не тронут.

## Коммиты (ветка `autopilot/road-to-release`)
- `1c8cf0ac` — чекпоинт-слоты + полиш десктопного шелла карты заданий (база сессии).
- `142b4aa1` — мобилка **Карта заданий**.
- `25b243e1` — мобилка **Карты локаций**.

## Карта заданий (/eft/questmap) — 3 гэпа закрыты
- **УЛ-табы I/II/III/IV** на мобилке: вертикальная полоса у левого края канваса (`QuestTierToggles orientation='vertical'`), гейтится `!isGate`. Логика та же (enabledTiers / ПКМ-фокус ряда).
- **Поиск** (`QuestSearchSheet`): чипы ВСЕ/Смотритель%/Каппа% + лента портретов + строки-результаты с трейдер-тинтом; фильтр по каппа/лк/торговцу, поиск клиентский.
- **Шит закреплённых** (новый `QuestPinnedSheet`, sheet `'pinned'`): триггер-скрепка со счётчиком в `MobileQuestBar`, тап=перелёт, ✕=снять закреп.

## Карты локаций (/eft/maps/[slug]) — 4 гэпа закрыты
- **ЗАВОЗ-таймер**: новый `MapRestockChip` в `MobileMapBar` (аватар ближайшего торговца + живой отсчёт из зеркала restock, §4.11-safe).
- **Легенда/фильтр маркеров**: `MapLayersDrawer` сделан адаптивным (мобилка = bottom-sheet); дерево категорий/счётчиков переиспользовано 1:1, синхронно с `useMapViewStore.activeFilters`.
- **Меню инструментов** (новый `MapToolsSheet`, sheet `'tools'`): метка / линейка / редактирование / удаление / GPS; собран из `useMapUiStore`, триггер-гаечник в `MobileMapBar`.
- **Поиск на локации** — `MapSearchDrawer` уже был адаптивным bottom-sheet; сверено с макетом M5, правок не потребовалось.

## ⚠️ Две развилки — решает V4DYA (PLACEHOLDER)
1. **M6 «Подробности квеста поверх карты»** (`2591:5683`): полноценный drawer квеста прямо на карте (переиспользовать `QuestDetail variant="drawer"` + видео-гайд + пообъектные map-пины) **ИЛИ** оставить текущее — тап по квесту в `MapQuestSheet` перелетает к зоне + стрелка ведёт на `/eft/questmap?quest=id`. Спекулятивно не делали.
2. **Место ЗАВОЗ-таймера**: в макете M1 таймер стоит в **шапке сайта** (ROW1, у бургера), а не в панели карты. Сделали в `MobileMapBar` (map-scoped, не трогает глобальный `Header`). Хочешь строго по макету → переносить в `Header`/header-modules (правка вне мобильного слоя карт).
