# ⚠️ BSG 1.1.0.0 — переработка квестов (влияние на нашу разработку)

**Статус:** 🟢 подтверждено официально · руководство к действию: **не тратить силы на связи квестов**
**Повод:** V4DYA принёс пост из офиц. ТГ BSG (28.07.2026), попросил сверить и продумать наперёд.
**Затрагивает:** [[Карта заданий и страницы квестов.md]], [[Задания — сюжетные, побочные, события.md]]

## Суть
BSG в обновлении **1.1.0.0** (старт первого сезона **Kord Breach**) переделывает систему **побочных заданий**: большинство перестаёт быть цепочками. Значит наша ключевая работа по карте заданий — **линки, двусторонние связи, симметрия графа, сверка цепочек «до/после»** — обесценивается. Делать её сейчас = дурная работа.

## Что подтверждено (официально)
- **Побочки — не цепочки.** Подавляющее большинство побочных заданий больше не открывается «после предыдущего». Вместо этого привязка к **уровню лояльности (УЛ)** торговца: на каждом УЛ — свой набор заданий, выполнил несколько → следующий УЛ с более сложным набором.
- **Награды смещаются в деньги** (меньше бартер-предметов и снаряжения).
- **Торговые предложения — по УЛ, а не по квесту.** Пример: рюкзак Tri-Zip → УЛ3 Барахольщика, шлем DevTac Ronin → УЛ2 Механика.
- **Цепочки остаются только как исключения** — с редкими наградами/крафтами; ключевые награды показываются уже при взятии первого квеста цепочки.
- **Коллекционер/Капа переделан:** разблокировка = **УЛ4 со всеми торговцами + репутация Скупщика 3.0 + уровень 40 + короткий список квестов**. Многие прежние требования-побочки убраны. Старый ачив «Путь к Капе» становится недоступен после старта сезона (заменяется новым).
  - **4 выживающие цепочки под Коллекционера:** Chemical P4 (Лыжник), A Shooter Born in Heaven (Механик), The Tarkov Shooter P4 (Егерь), Sew It Good P4 (Барахольщик).
- **QoL-прогрессия:** базовые боеприпасы раньше (7.62×39 Т-45М1 у Прапора с начала), ниже уровни для ранних УЛ, **исчезает требование по обороту валюты**, быстрее ранние модули убежища, реже нужны FIR/соседние модули.
- **Страховка:** в Kord Breach недоступна; в PvP/PvE быстрее возврат (дороже); появляется страховка у Егеря (дороже, возврат ~2 ч).

## Что это значит для наших заметок

|---|---|---|---|
| **Карта заданий** | Сверка цепочек с Tarkov Wiki, двусторонние линки, симметрия ветвлений («куриная лапка»), рендер связей графа | Near-fullscreen раскладка, страница-карточка квеста (шрифты, награды, реп торговца, избранное), фикс бага «Выполнено», UI-копия | Сам граф → вид «квесты по УЛ торговца»; «путь к Капе» → под новые требования Коллекционера |
| **Задания (побочные)** | Фильтр «заблокированные» по логике «предыдущий квест», связи побочек | Drawer (название/выдающий/задачи), синк «задача↔трекер», z-index «Завоза», строка иконок торговцев, изоляция маркеров на карте | Группировка побочек по УЛ вместо списка-цепочки |

| **События** | — | Всё (не связано с квестами) | — |
| **Трекер / «Я в рейде»** | — | OCR, стоимость лута, объединение трекеров | «Показ будущих нужных предметов» опирался на цепочки → под УЛ-модель предсказание «что дальше» становится другим |

2. **Делать сейчас** только косметику и не связанное с цепочками: раскладки, карточку квеста, баг-фиксы, карты, меченки, бартер, события, «Сообщить об ошибке», OCR/«Я в рейде», Gunsmith, убежище.
