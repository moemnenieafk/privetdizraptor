# 🌟 Сезоны и Боевой Пропуск (задел)

**Статус:** 🟡 задел на будущее. Триггер — релиз 1.1.0.0 ввёл целый новый домен, которого у CTA **нет ни одной страницы**. Исполнение — **после** того, как приведём существующие фичи к новой реальности патча (см. [[BSG 1.1.0.0 — влияние на портал.md]]).
**Зачем сейчас:** это заголовочная фича патча, конкуренты уже строят сезон-трекеры. Фиксируем возможность, чтобы не пропустить окно, но не распыляемся до реконсиляции существующего.

## Что ввёл патч (сырьё домена)
- **Сезонный персонаж** — отдельные сервера, независим от PvP/PvE; авто-сброс каждые **4–6 мес** с новым сезоном. Первый сезон — **Kord Breach**.
- **Модификаторы сезона:**
  - *Общие* — правила сезона для всех, менять/отключать нельзя.
  - *Личные* — очки (− за усложнение добавляют очки, + на упрощение их тратят); итоговый баланс ≥ 0 для создания персонажа.
- **Сезонные награды** — уникальные торговые предложения; разблок за уровень ЧВК / задание / цепочку. После сезона неразблокированные пропадают, полученные — навсегда во всех режимах (PvP/PvE/PvP Season).
- **Боевой Пропуск (бесплатный):** прогресс общий для всех режимов; продвижение — находить и сдавать **документацию TerraGroup**.
  - Документы с локаций — индивидуальные (как квест-предметы, чужой не заберёт); с ботов Black Division — общие.
  - **Дневной лимит** документации, прогресс лимита общий по режимам.
  - **Секретные данные** — универсальная замена любых документов, добываются в Центре расширений.
- **Сезонные достижения** — только сезонным персонажем; после сезона доступны в следующих.
- **Синхро с EFT: Arena** — односторонняя (Arena → PvP Season) по опыту/реп/валюте; тактическая одежда — в обе стороны.

## Возможные фичи CTA (мозговой штурм, не обязательство)
- Трекер прогресса Боевого Пропуска (сколько документов собрано, дневной лимит, что осталось до награды).
- Планировщик Личных модификаторов — калькулятор очков ± с балансом.
- Каталог Сезонных наград с дедлайном сезона («успей разблокировать до конца Kord Breach»).
- Карта дропа документации TerraGroup / точек Black Division.

## Гочи и открытые вопросы
- **Данных, скорее всего, нет во внешнем API** (tarkov.dev не отдаёт БП/сезоны) → потребуется `/game-data-ingest` из файлов игры + своё зеркало (§4.11). Проверить охват после старта серверов.
- Автономность (§4.11) обязательна: рантайм-фетч сезонного источника из страницы/компонента — нельзя, только серверный синк в зеркало.
- Приоритет и объём — за V4DYA, после реконсиляции портала под 1.1.0.0.
