# Бартер — фильтры и аналитика

**Статус:** 🟢 самый проработанный раздел, почти готов
**Источник:** голосовое 2026-07-28 · [[audio_2026-07-28_00-08-24]] (2:30)
**Участники:** V4DYA (монолог-отчёт)

## Суть
Раздел «Бартер» — самый доведённый блок. Быстрые + расширенные фильтры и аналитика профита: кому выгоднее продать предмет и у кого выгоднее купить.

## Как сейчас (сделано)
- **Быстрые фильтры:** только бартер · только крафт · предметы для заданий · ГПшки (монеты GP) · важные предметы · прибыльные (отдельно выгодные для покупки и для продажи).
- **Расширенные фильтры:** диапазон цен, сортировка по цене покупки / продажи, ранжирование по стоимости (напр. «до 200к»).
- **Сохранение фильтров:** после перезагрузки страницы настройки восстанавливаются.
- **Избранное** (по умолчанию пусто, заполняет пользователь).
- Ключевые индикаторы вынесены наверх, обновлены иконки, добавлен ещё один раздел.
- **Аналитика профита:** сразу видно, кому из торговцев выгоднее продать и у кого выгоднее купить.

## Решения созвона
- По бартеру в целом **всё готово** — можно переходить к следующим разделам. Именно остальные разделы вызывали вопросы и разбирались дальше.

## 🐛 Баги / проверить
- «Апшка» (важный предмет?) всегда показывается сверху — решить, убирать это поведение или оставить.

## 🤖 Задачи для Клода
