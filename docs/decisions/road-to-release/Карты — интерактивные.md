# Карты — интерактивные (near-fullscreen)

**Статус:** 🔵 обсуждено (1-я итерация)
**Источник:** голосовые 2026-07-28 · [[audio_2026-07-28_00-07-58]] (10:08) + [[audio_2026-07-28_00-08-02]] (1:45, Twitch)
**Участники:** V4DYA, Дмитрий

## Суть
Интерактивная карта должна открываться максимально крупной **по умолчанию**, сохраняя верхнюю шапку сайта для навигации. Убрать лишний клик на «Полноэкранный режим».

## Как сейчас
- Чтобы карта заняла экран, нужно жать кнопку «Полноэкранный режим» — она прячет шапку, глобальный тактический поиск и остальное. Лишний клик + потеря контекста навигации.
- Строка «Я новичок / Search / Escape from Tarkov» и нижняя статусная панель съедают вертикаль.
- Иконки выбора карт (серые + оранжевым активная), переключатель слоёв.
- Спроектировано по логике окна Windows: статусная строка снизу, панель навигации сверху.

## Решения созвона
- **Near-fullscreen по умолчанию.** Карта расширяется влево, вправо и вверх до границ браузера, упираясь в глобальную шапку (логотип, профиль, меню остаются). Кнопка полноэкранного режима остаётся опцией — для тех, кто хочет скрыть и шапку.
- **Убрать промежуточную строку** «Я новичок / поиск / Escape from Tarkov» — освободить вертикаль.
- **Нижнюю статусную панель — наверх**, на уровень иконок карт. Инфа про длительность рейда, число игроков, тип карты — компактными виджетами в верхней строке управления.
- **Боковые зоны** (появляются, т.к. карта расширилась): слева — боссы столбиком (от большего шанса спавна к меньшему) + переключатель этажей/уровней; справа — drawer выезжает при клике на объект, не перекрывая всю карту; блок фильтров/слоёв (таски, лут, выходы).
- **Mobile First.** Карта открывается сразу во весь экран под шапкой; выбор карт и иконки сворачиваются в компактный drawer/кнопку; боковые панели — плавающие, по кнопкам-иконкам.

## Что делать
- Реализовать раскладку near-fullscreen: хедер сайта сверху, карта до границ вьюпорта влево/вправо/вверх.
- Перенести мета-информацию рейда с нижней панели в верхнюю строку; оставить одну статусную панель.
- Левый столбец боссов, правый drawer, блок слоёв.
- Референс раскладки — Tarkov.dev / Tarkov Help (taskFilter / itemFilter / поиск, координаты). Посмотреть их размещение поиска.

## Техническая заметка: авторизация через Twitch
- **Контекст:** по новым законам РФ нельзя регистрироваться через иностранные сервисы; Tarkov Help уже убрал кнопку «Sign in with Twitch».
- **Решение:** скрыть прямую кнопку быстрой авторизации через Twitch. Основной вход — **Email/Пароль** (включая почты, привязанные к Twitch-аккаунтам). Существующим Twitch-юзерам — вход по ссылке на привязанную почту.

## 🐛 Баги / проверить
- Инфа про длительность рейда / число игроков пропала со статусной строки — вернуть.

## 🤖 Задачи для Клода
- CSS near-fullscreen: расширение хедера/карты до границ вьюпорта с сохранением шапки. Токены §6 NIGHTFALL, канон Tailwind v4 (`/tw-fix`).
- Leaflet/canvas грузить `next/dynamic` c `ssr:false` (§4.6) — иначе билд падает на `window`.

## ❓ Открытые вопросы
- Верхняя строка уходит вниз или наверх — колебались («как читается: сверху вниз / снизу вверх»).
- Выпадающий селектор выбора карт справа — «или не надо, пускай одна навигация».
