## Суть
Три раздела: **Сезоны** (анонс + конструктор билдов), **Сборки оружия** (Gunsmith), **Трекер предметов** (переработка). Часть трекера пересекается с [[Я в рейде — киллер-фича.md]].

## Как сейчас
- **Сезоны:** показывают текущий анонсированный сезон (ещё не начался), конструктор билдов + краткая инфа с советами. Конструктор — геймификация, можно крутить / выбрать рандомно.
- **Сборки оружия:** создать сборку можно, но «пока не очень» — непонятно. Выбор калибра — короткий горизонтальный переключатель («пипка»). Есть пресеты/мета, вкладка сообщества.
- **Трекер предметов:** дизайн не утверждён. Рядом второй раздел — «важные предметы» — тоже по сути трекер.

## Решения созвона
### Сборки оружия (Gunsmith)
- **Выбор калибра:** убрать короткий горизонтальный скроллер → выпадающий список или сетка в 2+ строки.
- **Валидация критических модулей:** без цевья / газовой камеры сборку сохранить нельзя (обязательный слот с замечанием, как на Tarkov Market).
- **Отказ от динамического рендера** оружия под каждый обвес — слишком ресурсоёмко, «игра не стоит свеч». Вместо этого — качественные **статические карточки** сборок + проверенная база предметов.
- Публичный ростер сборок сообщества + мета.

### Сезоны
- Баннеры-обложки сезонов — сгенерированные изображения устраивают. Если выбор игры на главной будет так «вертеться» — круто.

### Трекер предметов
- **Пересобрать по образцу Tarkov Market/Help.** Оставить отслеживаемые модули прямо в трекере (главная причина, почему V4DYA купил подписку TM). Отмечаешь предметы по заданиям плюсом/минусом по количеству.
- **Показ будущих нужных предметов:** если игрок авторизован и отмечает карту заданий — сайт знает, какие предметы понадобятся скоро (будущие заблокированные + текущие квесты), и подсказывает собирать заранее. **Премиум-фича** («дай попробовать, потом плати»).
- **Объединить «важные предметы» + «трекер предметов»** в один раздел — решает дублирование записей в БД. Подробнее в [[Я в рейде — киллер-фича.md]].

## 🐛 Баги / проверить
