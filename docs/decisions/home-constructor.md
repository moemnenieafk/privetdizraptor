# Конструктор главной EFT (Слой 1) — ручная правка поверх авто-базы, гейт PRO

Главная = «динамически умная адаптируемая под стиль» страница. **Слой 0** (авто-набор архетипа как
HubCard'ы) — готов (commit 0146354d). **Слой 1** — ручной конструктор поверх авто, **редактирование
за платным тиром** (`isPro = tier !== 'free'`).

## Решения (грил V4DYA)
1. **Глубина — лёгкий конструктор** (кнопки на карточке, БЕЗ dnd-библиотек): закрепить вверх / скрыть /
   размер big↔rect / вверх-вниз. Порядок — pin-приоритет + move. Без drag-drop (Слой 1.5 позже, если надо).
2. **Гейт — PRO.** Кнопка «Настроить» видна всем; PRO → режим правки, free → **апселл-CTA** (PRO-бейдж,
   клик → апселл «Настрой главную под себя — в PRO» → переход на подписку `/account`). Гейт клиентский
   (мягкий): раскладка = localStorage, серверных данных нет → энфорс не нужен (§ прогресс-спека: анлоки мягкие).

## Модель override (глобальный, по featureId — применяется к любому архетип-набору)
`useHomeLayoutStore` (zustand persist, localStorage), одно состояние на юзера (НЕ per-profile):
- `hidden: string[]` — скрытые фичи.
- `pinned: string[]` — закреплённые вверх (в порядке закрепления).
- `sizes: Record<string, 'big' | 'rect'>` — переопределение размера.
- `added: string[]` — добавленные из полного каталога (не из архетип-набора).
- actions: `toggleHidden`, `togglePinned`, `setSize`, `addFeature`, `removeAdded`, `reset()`.

## Вычисление показа (в EftHomeHubClient)
1. База = `ARCHETYPE_FEATURES[role]` + `added` (уникально).
2. Минус `hidden`.
3. Порядок: `pinned` первыми (в их порядке), затем остальное в порядке базы.
4. Размер: `sizes[id] ?? (feature.big ? 'big' : 'rect')` → `variant 'square' | 'rectangle'`.
Пустой override → чистая авто-база (Слой 0 без изменений).

## UI режима правки (PRO)
- Кнопка-тумблер «Настроить / Готово» над сеткой. PRO → toggle `editing`. free → апселл.
- В `editing`: на каждой карточке оверлей-контролы (иконки-кнопки): pin↑ (тумблер), скрыть ✕,
  размер (big↔rect), вверх/вниз. + панель «Добавить раздел» (скрытые + фичи каталога не в наборе) +
  «Сбросить к авто» (reset). Вне `editing` — карточки как обычные ссылки (Слой 0).
- NIGHTFALL §6; контролы — токены/иконки-шкала; не ломать HubCard-навигацию (в edit клики по контролам,
  не переход).
