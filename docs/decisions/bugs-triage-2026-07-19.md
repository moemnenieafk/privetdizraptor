## Анимация плиток на 2К (аним-1, аним-2) — РАЗОБРАНО + ИСПРАВЛЕНО (25.07)

Воспроизведено в Chrome на проде (`privetdizraptor.vercel.app`), замеры через `javascript_tool`.
«Не работает» и «резко» — **две разные первопричины**, обе подтверждены данными, не гипотезой.

### Причина 1 — плитки «не работают» на 2К: Embla loop не заполняет широкий вьюпорт
- Карусель главной (`src/components/ui/Carousel.tsx`) запущена с `loop: true` + `align: center`.
- Замер: 8 активных плиток = **`containerScrollW` 2228px**. Порог поломки — **вьюпорт > 2228px**.
- 2К-монитор Дмитрия (2560px @100%) переваливает порог → суммарная ширина плиток НЕ заполняет
  экран → Embla не может разложить клоны лупа → луп ломается / щёлкает рывком.
- Машина Вади = **1824px CSS** (замерено), порог не достигнут → «плавно». Отсюда и расхождение.

### Причина 2 — подъём «резко»: box-shadow в transition + нет will-change
- `computed style` карточки: `transition-property = "transform, border-color, box-shadow"`.
- Неон-тень `--shadow-neon = 0 14px 28px` (blur 28px) **анимируется вместе с подъёмом** →
  репейнт крупной размытой области каждый кадр. `will-change = auto` (нет промоута слоя).
  Плюс в тот же момент стартует `<video>` (декод дёргает главный поток). На большом экране
  площадь репейнта больше → рывок у слабой/другой GPU.
- `prefers-reduced-motion` на машине Вади = false (у Дмитрия проверить отдельно — но фикс
  теперь уважает эту настройку в любом случае).

### Фикс (в рабочем дереве, `tsc` зелёный; ждёт деплой-верификации на 2К)
1. **`Carousel.tsx`** — `loop` включается только когда `containerScrollW > viewport` (пересчёт на
   resize через `ResizeObserver` + `emblaApi.reInit`). На 2К/ultrawide — статичный центрированный
   ряд без сломанного лупа.
2. **`globals.css`** — класс `.game-card`: `box-shadow` убран из `transition`, добавлен
   `will-change: transform` (подъём на GPU, тень снапится мгновенно, без per-frame repaint).
3. **`globals.css`** — `@media (prefers-reduced-motion: reduce)` гасит подъём/транзишены глобально.
4. **`GameCard.tsx`** — оживлён мёртвый entrance: `isLoading` (всегда был `false`) удалён,
   `transitionDelay` заменён на реальную волну `motion-safe:animate-[fade-in-up]` со стагером по индексу.

**Осталось:** визуальная проверка на настоящих 2560px после следующего preview/prod-деплоя
(локальный 2-й dev на общий `.next` не поднимаем — гоча с зависанием ПК).
