# Карты: дев-инструмент редактора маркеров

**Статус:** ✅ сделано (2026-06-29) — вариант **A (файловый дев-тул, без бэкенда)**, не БД-CMS.
**Затрагивает:** `MapMarkerEditor.tsx` (новый) · `MapViewerClient.tsx` · `data/map-markers/*` · роут `[slug]/page.tsx`

## Контекст
Хочется универсальный дев-инструмент добавления/редактирования маркера на карте: у маркера набор полей и связей с категорией. Но сейчас маркеры **read-only** — синкаются 1:1 из tarkov.dev в `mapMarkers`. Прямая правка затрётся следующим кроном.

## Почему отложено
Ручной редактор = **новый бэкенд-слой**, а не UI-фича:
- нужна таблица ручных оверрайдов/добавлений (поверх синка), чтобы крон их не стирал;
- логика слияния «синк + оверрайды» при чтении (`getEftMapData`);
- admin-UI для CRUD маркера (поля из `MapViewMarker`: type, position, faction, sides, categories, label, linkedItemId, linkedQuestId, meta);
- режим «поставить точку на карте» → получить игровые `{x,y,z}` из клика (обратный CRS-трансформ).
- Граница БД/схемы = бэкенд-сессия, скилл `cta-backend`, `db:push` — необратимая операция.

## Предусловия

## Исполнено — вариант A (2026-06-29, файловый дев-тул)
Для статик-карт (Ледокол) маркеры — НАШИ данные (не синк tarkov.dev), поэтому БД-слой из «Почему отложено» не нужен. Выбран **A** (файловый); B (БД-CMS) оставлен на будущее, если понадобится живая правка в проде мультиюзером.
- **`MapMarkerEditor.tsx`** — панель по `?edit=1`: выбор типа (выход/спавн/переход/опасн./замок/рычаг/лут) + подпись + фракция; **клик по карте ставит маркер** на текущий этаж; список с удалением; «Скопировать TS».
- Координаты {x,z} = clicked latlng (само-согласованно через `ll()`), этаж = индекс активной палубы. Без обратного CRS-трансформа.
- **Хранение** — `src/data/map-markers/{slug}.ts` (git), реестр в `index.ts`. Экспорт из тула → вставляешь/коммитишь.
- **Рендер** — статик-ветка `MapViewerClient` рисует ручные маркеры одним слоем, фильтр по индексу этажа (`applyFloor`); `iconFor` дополнен.
- Проверено вживую: `?edit=1` → панель, клик ставит точку, экспорт = валидный TS. Обычный режим — панели нет, регрессии нет.
- Паттерн в скилле `import-external-map`.
