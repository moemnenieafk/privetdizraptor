# Трекинг: Побочные задания (торговцы)

## Цель
Секция «Побочные задания» во вкладке «Трекинг» ([[player-tracking-tab]]): сводный прогресс трейдерских квестов игрока — по торговцам (Прапор X/67, Терапевт X/…), прогресс Каппа/Смотритель, закреплённые (pinned) квесты как вотчлист. Часть платного контура трекинга (PRO).

## Контекст
- Прогресс УЖЕ трекается: `useQuestStore` → `completedQuests`, `pinnedQuests`, `questNotes`, `itemProgress`; облако `quest_progress` + `ProgressSync`. Ничего нового в БД не нужно — чистая агрегация (как достижения в v1).
- Данные квестов: `EFT_QUESTS` (`src/data/quests`), поля `kappaRequired`/`lightkeeperRequired`, `trader.normalizedName`.
- Готовые паттерны UI: фильтры-индикаторы у торговца (`QuestTraderList` — Доступно/Завершено/Заблокировано + Каппа/Смотритель, см. [[done/fix-quests]]), `QuestStatusBar`.
- Кросс-линки: `/eft/questmap?quest=<id>`, `/eft/quests/<trader>`, `/eft/quests/task/<id>`.

## Развилки
- Что в вотчлисте: pinned-квесты (уже есть механика!) или отдельный «отслеживаю» для квестов?
- Разрез: по торговцам (полосы) · по статусу · Каппа-центричный вид?
- Показывать ли доступные-сейчас (по уровню игрока из телеметрии)?

## Гарды
- БД/сторы не трогаем — только агрегация. PRO-гейт — общий (см. хаб).
