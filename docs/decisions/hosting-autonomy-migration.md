## Контекст
Куплен домен `cta.quest` (reg.ru, на 3 года) + по ошибке взят shared-хостинг ISPmanager (триал, стек не тянет). Возник вопрос переезда «части готовых разделов». В ходе грилинга цель уточнена: не привязка домена, а **полная автономность от Vercel + доступность портала везде** (портал планируется международным, региональность — только на биллинге).

Ключевое напряжение: «свежесть по сезону» держится на связке **крон → Supabase → UI читает зеркало** (§4.11) — то есть на серверном рантайме и планировщике, а не на статике. Значит переезжает не «папка со страницами», а рантайм + БД + Auth + крон.

## Решения (зафиксированы грилингом 2026-08-19)

| Развилка | Решение | Почему |
|---|---|---|
| Цель | Автономность от Vercel + глобальная доступность | Международный портал, региональность только на биллинге |
| «Частично» | Переезд **целиком, поэтапным выкатом** | Одна БД на все разделы → раздвоение = анти-автономность; «частично» = порядок миграции, не финал |
| Origin | **Timeweb Cloud, локация Амстердам (NL)**, 4 vCPU / 8 ГБ / 80–160 ГБ NVMe + swap | EU-локация (голландский IP → западные сервисы видят EU, не РФ) при РФ-оплате. Изначально план был Hetzner CPX31, но Hetzner **отклонил регистрацию/оплату РФ-карты** (2026-08-19) — барьер платёжный, не локационный. Timeweb = РФ-компания (РФ-карта проходит) + EU-ДЦ. План идентичен (Ubuntu+Docker). Запасные: Aeza, PQ.Hosting |
| CDN / фронт | **Cloudflare** (free) | Глобальная раздача статики (гео-скорость для РФ и Запада), скрытый origin, точка флипа DNS |
| Панель | **Coolify** на VPS | «Свой Vercel»: git-push деплой, Let's Encrypt SSL, бэкапы, healthcheck-автоподъём |
| Бэкенд | **self-hosted Supabase** (Docker) | GoTrue = тот же Auth, `@supabase/supabase-js`/`ssr` без изменений, меняется только URL. Свою Auth с нуля НЕ пишем |
| Ассеты (R2) | **Остаются на Cloudflare R2** | R2 не Vercel-зависимость и не РФ-блок; уже заполнен (5044 иконки, тайлы). Тащить на VPS = раздувать диск без выигрыша |
| Эксплуатация | Самовосстановление, настраивает Claude | Nightly-бэкап Postgres во внешнее хранилище, `restart: always`+healthcheck, Telegram-алерты. V4DYA — реагирует на редкие алерты |
| Cutover | Стейдж → обкатка → флип, Vercel как резерв | Домен ещё чистый → можно обкатать, не задев трафик; откат = вернуть DNS |

### Юр-фон (BSG / RU)
Риск низкий: у V4DYA личный контакт с разработчиками BSG, проект им известен, претензий не ожидается. Оговорки: неформальная договорённость ≠ лицензия юротдела; РКН/ПДн — отдельная тема, для малого проекта практически не трогает. Домен нейтральный (`cta.quest`, без «tarkov») ✅. Портируемость (Docker-стек поднимается на новом VPS за час) держим как страховку в любом случае. Ср. `transport-json-canon`, §4.12.

## Риски и откаты
- Билд-OOM на 8 ГБ → swap; при упорстве апгрейд CPX41 в клик.
- Auth не заводится (ES256) → ключи наши, закладываю время; откат — Vercel жив.

- Флип сломал прод → DNS назад на Vercel за минуты.
- BSG/претензия → портируемый Docker-стек, переезд за час.
