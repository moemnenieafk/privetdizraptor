# Вкладка «Трекинг» — единый хаб прогресса игрока

## Цель
Сейчас трекинг игрока разрознен: строка-стата в Аккаунт Центре («Квестов / Бартеров / Достижений») + отдельные страницы по доменам. Нужна **единая вкладка «Трекинг»** в Аккаунт Центре: игрок видит СВОЙ прогресс по каждой игре в одном месте. v1 = достижения (вотчлист + разбивка по редкости — закрывает отложенное из [[done/achievments-redesign]]); квесты/бартеры/убежище подселяются следующими итерациями без переименования.

## Развилки — ЗАКРЫТЫ V4DYA (2026-07-02, два раунда Q&A)
| Развилка | Решение |
|---|---|
| Где живёт | **Вкладка в Аккаунт Центре** (кросс-игровой личный кабинет; там же стата и сброс) |

| Обзор-блок | **Разбивка по редкости**: общий прогресс-бар (X/110) + три счётчика по тирам в цветах редкости (легендарные X/60, редкие X/23, обычные X/27) |
| Название вкладки | **«Трекинг»** (под будущий рост доменов) |

## План (v1)
1. **`src/app/account/page.tsx`** (RSC) — дозагрузить `getEftAchievements()` + `getEftMaps()`/`getEftTraders()`, резолвнуть SMART-подсказки для всех 110 server-side (`resolveAchievementHint` → `Record<id, AchievementHint>`), передать в `AccountCenter` (achievements + hints).
2. **`AccountCenter.tsx`** — новый таб `tracking` («Трекинг») в TabId/навигацию; рендер `<TrackingPanel>`.
3. **Новый `src/app/account/TrackingPanel.tsx`** (client, co-located как остальные панели кабинета):
   - секция-шапка EFT (лого + название; список секций по играм — пока одна);
   - **вотчлист**: `trackedIds` из `useAchievementStore` (mounted-гард!) → карточки: иконка (`achievementIconUrl`), имя, бейдж редкости (`rarityMeta.badgeClass`), %, тоггл ✓ (`AchievementTrackToggle` compact — выполнение убирает из вотчлиста по логике стора) + ★ снять с отслеживания + чипы-кросслинки из hints; клик → деталь `/eft/progress/achievements/[id]`;
   - пустое состояние: CTA «Отмечайте ★ на достижениях» → ссылка в раздел;
   - **обзор**: прогресс-бар X/110 + 3 тира (счёт по `normalizedRarity` × `completedIds`), цвета редкости;
   - мобилка по канону `cta-mobile` (карточки 1-в-ряд <640px).
4. Чипы-кросслинки: вынести рендер чипа из `AchievementDetail.tsx` в общий `features/achievements/HintChips.tsx` (DRY) ИЛИ лёгкий локальный рендер в панели — по месту.
5. `tsc` чисто → REVIEW-пауза → коммит docs+code.

## Границы
- **В scope:** вкладка «Трекинг» в Аккаунт Центре (v1 достижения): вотчлист + обзор + шапка EFT; переиспользование готовых либ/компонентов достижений.
- **НЕ трогаем:** сторы/таблицы/API/синки (уже готовы в Фазе 2 достижений — только читаем); БД (**никакого db:push — чистая фронт-агрегация**); квесты/бартеры/убежище (следующие итерации); строку-стату профиля и GameResetCard (остаются как есть).
