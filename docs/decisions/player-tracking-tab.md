# Вкладка «Трекинг» — единый хаб прогресса игрока

## Цель
Сейчас трекинг игрока разрознен: строка-стата в Аккаунт Центре («Квестов / Бартеров / Достижений») + отдельные страницы по доменам. Нужна **единая вкладка «Трекинг»**, где игрок видит СВОЙ прогресс по каждой игре в одном месте: квесты, достижения, бартеры, убежище — «выполнено» и «отслеживаю», с переключателем игр (сейчас EFT, дальше мультигейм). Вобрать отложенную из [[achievments-redesign]] «вкладку достижений с разбивкой по редкости».

- **Сторы (persist localStorage):** `useQuestStore` (completed/pinned/notes), `useAchievementStore` (completed/tracked), `useGamificationStore` (barter xp/badges/confirmed), `useHideoutStore` (station→level).
- **Таблицы (per user+game):** `quest_progress`, `achievement_progress`, `barter_progress`, `player_profiles`. Убежище — только localStorage (DB-таблицы нет).
- **Синки (гидрация+дебаунс-сейв на логине):** `ProgressSync`, `AchievementSync`, `useGamificationSync`, `PlayerProfileSync` (все в `app/layout.tsx`).
- **Аккаунт Центр:** `src/app/account/AccountCenter.tsx` (табы: profile/security/billing/…), `getAccountStats` в `src/lib/auth/me.ts` (агрегирует counts), `GameResetCard` (сброс по игре: чистит БД + localStorage-ключи).
- **Мультигейм:** таблица `games` (code eft/abi/gzw), всё скоуплено по `gameId` (`eftGameId()`); UI пока хардкодит EFT (напр. `PlayerTelemetry.tsx GAMES`).
- **Заметки:** [[achievments-redesign]] (Фаза 2 трекинга достижений — эталон паттерна), [[project-cta-backend]], [[sprint-backend-state]].
- **Известные гочи:** hydration-mismatch при чтении persist-стора в SSR → mounted-гард (см. `AchievementTrackToggle`). Не-залогиненный = только localStorage.
