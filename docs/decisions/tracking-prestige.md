# Трекинг: Престиж

## Цель
Страница/секция «Престиж» во вкладке «Трекинг» ([[player-tracking-tab]]): текущий престиж игрока, условия перехода на следующий уровень престижа и чек-лист их выполнения. Часть платного контура трекинга (PRO).

## Контекст
- Текущий престиж уже в телеметрии: `usePlayerStore` → `profile.prestige` (0..6), задаётся в `ProfileSettingsModal` (иконки престижа есть: `icon-eft-profile-prestige-*`, `icon-eft-prog-prestige`).
- **Данных об условиях престижа в нашем зеркале НЕТ** (tarkov.dev их не отдаёт) → скорее всего ручной контент-датасет `src/data/prestige.ts` (условия по уровням: уровень ЧВК, Каппа, задания и т.п. — сверить с игрой 1.0.x).
- Условия пересекаются с другими доменами трекинга: уровень (телеметрия), задания (useQuestStore), Каппа (kappaRequired квесты) → чек-лист может считаться автоматически из имеющихся сторов.

## Развилки
- Источник условий: ручной датасет (наиболее реалистично) · ждать появления в API?
- Насколько автоматизировать чек-лист (авто-вычисление из сторов vs ручные галочки)?
- UI: карточка-лестница престижей 0→6 с текущим положением?

## Гарды
- БД не трогаем, пока не понадобится зеркалирование; PRO-гейт — общий для трекинга (см. хаб).
