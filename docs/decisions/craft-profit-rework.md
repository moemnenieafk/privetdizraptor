# Переработка раздела «Прибыль убежища» (/eft/progress/hideout/craft-profit)

Цель V4DYA: **ультимативный инструмент для крафтеров** + **единообразие дизайна и максимальное переиспользование** уже разработанного функционала сайта. Отказ от текущего табличного вида в пользу карточек и канон-компонентов.

Спека собрана гриллингом 2026-08-21. Числа/формулы — из ресёрча `docs/research/eft-craft-profit-tarkovdev.md` (сверен с исходниками tarkov.dev + вики).

---

## 1. Формула профита (канон tarkov.dev, из ресёрча)

```
профит = цена_продажи × кол-во − стоимость_входов − налог_барахолки
₽/час  = floor(профит / (эфф_время / 3600))
```
- **Входы**: за единицу — дешевейшее из {покупка нал (барахолка/торговец)}. v1 БЕЗ «вход как бартер/крафт» (follow-up). Инструменты не считаются. FIR-входы = 0₽.
- **Выход**: `max(лучшая продажа торговцу, барахолка − налог)`. Награда всегда FIR.
- **Налог барахолки** — вычитаем всегда, **показываем отдельной строкой** на карточке. Формула (verbatim из `flea-market-fee.mjs`):
  ```
  fee = ceil( V0·Ti·4^P0·Q + VR·Tr·4^PR·Q ) · IC
  Ti = Tr = 0.03 ; V0 = basePrice, VR = sellPrice, Q = count
  P0 = log10(V0/VR), PR = log10(VR/V0)
  VR<V0: P0 = P0^1.08 ; VR>=V0: PR = PR^1.08
  IC = intelCenter>=3 ? 1 − (0.01·HM + 1)·0.3 : 1
  ```
- **Тумблер «Пустой бак»** (глоб.): топливные баки во входах оцениваются в 10% от продажи торговцу.

## 2. Навыки (гибрид C: авто из профиля + слайдеры override)

- **«Ручное производство» (Crafting)** → режет ВРЕМЯ: `эфф_время = floor(duration − duration·(lvl·0.75)/100)` → −0.75%/ур, −37.5% на 50. (Элита 51 = 2 предмета/цикл — v1 не моделируем на карточку.)
- **«Управление убежищем» (HideoutManagement)** → на время НЕ влияет. Влияет на профит: (1) усиливает скидку налога через Разведцентр (член `HM` в `IC`), (2) «0.66»-сокращение дробных входов (−0.5%/ур) — v1 применяем к IC; дробные входы опционально.
- **Разведцентр (Intelligence Center) ур.3+** — из профиля убежища (`built('intelligence-center')`), включает −30%…−45% скидку налога.
- Подача (**гибрид C**): по умолчанию уровни навыков из профиля (`resolveSkillLevel` — usePmcStatsStore + useManualProfileStore), плюс **два слайдера 0–51** (Crafting, HideoutManagement) для override/«что-если». Показываем базу и буст (время `база → с навыком`).

## 3. Данные — расширение синка (слой B, выбран V4DYA)

Зеркало `crafts` сейчас: `station/level/duration/входы/выходы`. Добавить:
- `crafts.task_unlock` (text, nullable) — id квеста-анлока.
- `crafts.game_editions` (jsonb `string[]`, nullable) — издания, дающие крафт.
- Апдейт дамп-скрипта (`scripts/…dump-crafts` / sync) — тянуть `taskUnlock`/`gameEditions` из `json.tarkov.dev/{mode}/crafts`. ⚠️ Выверить точные имена полей в дампе.
- Миграция: **additive SQL** (`db:push` требует TTY — гоча cta-backend), затем `db:sync-*`.
- Ридер отдаёт эти поля в `ProcessedCraft`.

## 4. Раскладка страницы (сверху вниз)

1. **Интро-блок** (лёгкий, НЕ полный HubNav — соседи по убежищу его не используют): иконка `craft-profit.svg` + H1 «**Прибыль убежища**» + короткое описание (влезает в высоту иконки):
   > Что выгодно крафтить сейчас — профит с учётом налога барахолки, твоих навыков и построенных станций.
2. **Ряд фильтр-вкладок модулей** (единый ряд, дизайн плитки из /modules): плитка = **иконка станции + уровень «0N»** (1-я строка) → **«рецептов доступно / всего»** (2-я строка). Короткое имя станции если влезает. Уровень из `built()` (с учётом издания). Первая вкладка «**Все**». Одиночный выбор = фильтр по станции. **Одна строка**, мобилка — горизонтальный скролл. (Отдельную панель «Убежище ЧВК» тут НЕ ставим — её роль несёт этот ряд.)
3. **Блок поиск+фильтры+сортировка** (паттерн из «Важных предметов»: `поиск flex-1 + FilterChip + дропдаун СОРТИРОВКА`):
   - Поиск — **по выходу** (что хочу скрафтить).
   - Чипы (3): **Только прибыльные** · **Доступно сейчас** · **Скрыть заблокированные**.
   - Сортировка (6): ₽/час (дефолт) · Прибыль ₽ · ROI % · Время (короче) · Дешевле вход · Алфавит.
4. **Грид карточек рецептов** (адаптив 1/2/3 кол.; НЕ таблица, НЕ группировка секциями — станцию несёт фильтр).
5. Пустое состояние: «Ничего не найдено — измените фильтры».

## 5. Карточка рецепта (в духе EFT Item Card)

Вертикальная, `rounded-lg border bg-card-menu p-4`. Сверху вниз:
1. **Шапка**: иконка станции + название + чип «УР. N» + статус (🟢 доступно / 🔒 заблокировано).
2. **Герой — предмет-ВЫХОД**: крупная иконка (рарити-фон), имя, `×N`, цена продажи. Ссылка на карточку предмета.
3. **Входы**: ряд `TrackCell` в режиме **display + «в схроне»** (read-only из `useInventoryStore`, БЕЗ +/−): рарити-фон, иконка, `×кол-во`, цена, оверлей «в схроне N». Скругление `rounded-sm` (4px).
4. **Требования** (nvg-green чипы, синхрон с профилем): **уровень станции** (built), **квест-анлок** (useQuestStore, чип-ссылка на /questmap), **издание** (usePlayerStore.edition). met = зелёный+✓, нет = амбер. (Скиллов/торговцев в требованиях крафта НЕТ.)
5. **Метрики (подвал)**: время `база → с Ручным производством` · стоимость→выручка · **налог барахолки** (строкой) · **ПРОФИТ** · **₽/час** (цветокод `pphColor`).

**«Доступно сейчас»** = станция построена ≥ уровня крафта **И** квест-анлок пройден **И** издание есть.

## 7. Разбивка для /autopilot

1. **Данные**: схема `crafts` +2 колонки → additive SQL → апдейт синка (taskUnlock/gameEditions) → ре-синк → ридер отдаёт поля.
2. **Расчёт**: модуль профита по формуле §1 (fee, топливо-тумблер) + скилл-бонусы §2 (Crafting время, HM/IC налог). Чистые хелперы (§4.7), не в JSX.
3. **Интро-блок** §4.1.
4. **Фильтр-вкладки модулей** §4.2 (иконка+уровень+«доступно/всего», одна строка, скролл).
5. **Контролы** §4.3 (переиспользовать паттерн Важных предметов).
6. **Карточка рецепта** §5 (герой-выход, TrackCell-входы, nvg-green требования, метрики).
7. **Грид** §4.4 + фильтр/сорт/поиск-логика + слайдеры навыков (гибрид C).
8. tsc+eslint, live-verify, замкнуть петлю (статус ✅, обновить снапшот).
