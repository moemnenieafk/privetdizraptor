# Таблица выпадения лута в контейнере

## Цель
Создать для каждого контейнера отдельную страницу (по образцу ID-страницы предмета) с таблицей добычи — что можно найти в контейнере — и ценностью лута. Собрать эти страницы в раздел с иконкой `.icon-eft-loot-containers` и разместить в навигации. Дизайн — в стиле проекта.

## Контекст (по итогам разведки 2026-07-08)
- **Данных для таблицы лута НЕТ.** В проекте нет источника «что спавнится в контейнере»: ни `staticLoot`, ни GraphQL-запроса. Наша БД (`items` + `prices`) зеркалит tarkov.dev, а он статические loot-таблицы контейнеров не отдаёт. Страница `loot-rate` — это рейтинг ценности предметов, НЕ содержимое контейнера.
- **Ассеты есть:** webp loot-контейнеров (`/…/loot-containers/loot-container-*.webp`, `containerFile()` в `src/data/map-marker-icons.ts`), иконка `.icon-eft-loot-containers` (`src/styles/icons.css`).
- **Терминология (важно):** loot-контейнеры (Jacket/Safe/Duffle/сейф — мировые, обыскиваемые) ≠ gear-контейнеры (кейсы/секьюр/сторэдж — предметы под `/eft/items/gear/containers`, их «таблицы добычи» не существует).
- **Референс страницы:** ID-страница предмета — `src/app/eft/items/item/[slug]/page.tsx` (мимикрия под её структуру/стиль).
- **Категории:** `src/lib/item-category.ts` (`container` → `/eft/items/gear/containers`, иконка `icon-eft-eq-containers`), `src/lib/eft-category.ts` (GEAR_TYPES).

## Границы
- **В scope:** loot-контейнеры (мировые), раздел + страницы.
- **НЕ трогаем:** gear-контейнеры (secure/storage/cases) — у них нет loot-table; их раздел `/eft/items/gear/containers` уже есть и работает.

## Развилки (нужно решение V4DYA)
1. **Тип контейнеров.** Иконка + цель диктуют **loot-контейнеры** (мировые). Тогда путь — НЕ `gear/containers` (там gear-предметы), а свой: напр. `/eft/loot-containers` или `/eft/items/loot-containers`. → выбрать тип + путь.
2. **Источник данных loot-table (БЛОКЕР).**
   - **A) Найти данные** — SPT `staticLoot.json` (серверные loot-пулы контейнеров + вероятности) → парсинг в нашу БД/зеркало. Дата-проект + `db:sql` (⚠ manual, крупно; ср. с идеей SPT из [[maps-marker-render]] Фаза F). Лицензия: SPT — комьюнити-данные, проверить условия (не тянуть вики 1:1, CLAUDE.md §4.9).
   - **B) Структура-первой** — собрать раздел + страницы контейнеров с метой (имя, картинка, где встречается, ценность самого контейнера как предмета), БЕЗ таблицы лута; таблицу добавить, когда появятся данные (A).
