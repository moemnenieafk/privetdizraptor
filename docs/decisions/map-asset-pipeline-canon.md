# Канон пайплайна карт-ассетов (любая карта, любая игра портала)

Правила ниже — результат прогона Леса (`woods-asset-epic.md`). Они **переопределяют** более
ранние заметки в `docs/img-promt-help/` там, где противоречат (в частности «кроп вплотную» из
`CTA-MAP-OBJECTS-vector-prompts.md`, п. «Порядок прогона» 1).

## 1. Порядок слоёв — сначала земля, потом объекты

Каждый новый прогон карты идёт строго так:

1. **Карта глубины (рельеф)** — grayscale height map всей локации. Возвышенности/скалы/крыши
   светлее, вода/низины темнее, мягкие градиенты по склонам. В Figma — Multiply/Soft-Light ~50 %
   под объектами. **Не трассируется**, живёт растром.
2. **Карта материала поверхности («оттиск»)** — плоские цветовые зоны по материалу
   (трава/грунт/песок-гравий/бетон-асфальт/вода/болото), **без зданий и объектов**: там, где
   стоит здание, продолжается материал под ним. Цвета — из `src/lib/mapper/palette.ts`
   (default-тон семейств `soil`, `dirt`, `gravel-sand`, `concrete`, `water`, `swamp`).
   Не трассируется (или трассируется отдельно как зоны, но это не объектный пайплайн).
3. **Объекты** — библиотека нарезок → генерация флэта → vtracer. Только после 1–2.
4. **Штампы-скаттер** — растительность/валуны по маске плотности исходника, $0.

Референс результата 1–2: Таможня в Figma (`customs-01-ground-floor › HD-Map › карта глубины`,
`ground-material`).

### 1.1 Как делать рельеф и материал (V4DYA, 2026-09-02)

| Ранг | Слой | Метод | Когда |
|---|---|---|---|
| **1 — канон** | рельеф | **Ортографический depth-render геометрии сцены** в Unity (⚠️ проверено 2026-09-02: `TerrainData` в клиенте EFT НЕТ — просканированы все 714 `levelN`, карты сделаны мешами, не Unity-террейном; «взять готовый heightmap» невозможно). Нужно: найти сцену карты, ортокамера сверху, depth-pass → 16-бит grayscale + hillshade. Точно и бесплатно, но отдельный мини-проект. | отдельная сессия |
| 2 — рабочий | материал (и рельеф как временный) | Gemini image-to-image по квадрантам: 8192-webp → 4 × квадрант, вход ≤1024 JPEG, выход 2K → сшивка 4K. Промт материала: «buildings and objects are removed — continue the ground material underneath». ≈$0.5 за слой | сейчас, пока нет heightmap |
| 3 — фолбэк | материал | Кластеризация исходника по OKLab в 6 семейств палитры + морфологическое закрытие дырок от зданий. $0, шумнее по кромкам | если Gemini недоступен |

## 1.2 ⚠️ ПАРАДИГМА ИДЕНТИФИКАЦИИ (V4DYA, 2026-09-02)

**Сначала находим РЕАЛЬНЫЕ имена мест локации, потом задаём вопросы по листу сверки.** Не выдумывать
описательные ярлыки («большое здание с тёмной крышей») там, где у места есть каноническое имя
комьюнити («Скелетон», «Склад 3», «Крэкхаус»). Порядок на каждую новую карту:

1. Собрать справочник именованных мест (вики/чек-листы/гайды) → `docs/registry/<map>-landmarks.md`.
2. Резать объекты и в листе сверки сразу подставлять кандидата из справочника.
3. Спрашивать V4DYA только по спорным — он подтверждает/поправляет.

Так идентификация точнее, а **семантика карты сохраняется**: игрок ищет «Бойлерную», а не
«здание с двумя трубами». Эталон справочника: `docs/registry/customs-landmarks.md` (27 мест).

**Два вида типов в реестре** (следствие):
- `kind: "landmark"` — уникальное именованное место карты (Скелетон, Склад 17, Главный мост).
  Один экземпляр, не переиспользуется между картами, но именно его ищет игрок.
- `kind: "asset"` — переиспользуемый объект (бочка, контейнер, вагон, опора ЛЭП, валун).
  Один SVG → много экземпляров на всех картах, перекраска заменой триады семейства.
  **Генерацию начинать с asset-ов** — каждый закрывает десятки мест, landmark-и точечно.

## 2. Нарезка объектов — квадрат 1:1 с воздухом

- **Кадр всегда 1:1.** Gemini лучше держит ортографию и «видит высоту» объекта в квадрате;
  вытянутые кропы дают перспективные искажения и ломают распознавание.
- **Объект в центре, вокруг свободное пространство**: сторона квадрата = `max(w, h) × 1.5`
  (≈25 % поля с каждой стороны), центр — центр bbox, клампинг к границам растра. Модель сама
  «вырезает» объект из окружения — это лучше, чем резать впритык.
- **Размытые объекты не режем и не генерим** — размытие на исходнике = вне игровой зоны.
  Детектор: дисперсия Лапласиана на 512 px; на Лесу порог однозначный (≤19 → размыто,
  следующий 143). Такие уходят в `cut/<map>/_out-of-bounds/`, в JSON — `outOfBounds: true`.
- Payload в ProxyAPI: кроп в запрос — **≤1024 px JPEG q90**, анкер — **≤512 px PNG** (`ANCHOR_PX=512`): ProxyAPI резервирует стоимость по размеру входа, с анкером 1024 ловит 402 при балансе <~300 ₽.

## 3. Генерация — режим FAITHFUL («оттиск»), анкер, палитра, 2K

- **Режим по умолчанию — `--faithful`** (V4DYA, 2026-09-02): «CLEAN-UP, NOT A REDRAW» — та же геометрия пиксель-в-пиксель, схлопнуть цвета в палитру, убрать текстуру, ничего не сочинять; земля внутри кадра вне объекта → маджента. Даёт реалистичный векторный оттиск игрового прототипа (лесопилка, самолёт — 1:1 с игрой). Иллюстративный TYPE A (`REDRAW`) — только для штампов-скаттера (валуны, кусты), где нужна форма, а не точность.
- Ландмарки-регионы (массив, лагерь) в faithful выходят как **тайлы участка** с лесом внутри bbox — это нормально для оттиска, изоляция объекта там не нужна.

- Первый объект набора — самый простой (валун) — **анкер**; утверждается глазами, потом
  идёт вторым вложением во все остальные. Крутить анкер — только STEP 2/3 промта.
- `{PALETTE}` — триады семейств объекта из `palette.ts` + `concrete` + контур `#0D0D0E`;
  vtracer — только против этого сабсета (`tracePalette`), никогда против всех 63.
- **2K ≈ 39 ₽/выход через ProxyAPI** (4K ≈ 70 ₽; вход-картинки 632 ₽/1M токенов): после трассы 4K не даёт ничего, кроме микро-фасетов. Считать бюджет по 40 ₽, не по $0.13.
- В SUBJECT построек — явно: «seen from directly above, only roofs visible, no walls»,
  иначе модель уходит в 3/4-«изометрию» (прецедент: hilltop-settlement).
- Трасс-пресет 2K: `filterSpeckle 24, cornerThreshold 70, lengthThreshold 6` (mode `spline`
  для камней/техники, `polygon` для построек).

## 4. Гочи (проверено)

- **ProxyAPI `402 Insufficient balance` при живом балансе = резерв стоимости по размеру входа.** ProxyAPI перед запросом оценивает цену (вход-байты + выход) и отказывает, если баланс ниже оценки. Симптом: без картинок 200, с картинками 402. Лечение: ужать вложения (кроп ≤1024 JPEG, анкер 512), `maxOutputTokens: 4096`; эндпоинт `/proxyapi/balance` для ключа закрыт — включить в кабинете, чтобы скрипт мог гейтить сам.
- **Кап генераций в скрипте (`CAP`) — считать по логу**, не по ощущениям: за день Леса 17 объектных + 4 материала + ~5 проб ≈ 1000 ₽, в финале 6 объектов + слой.
- **Модель дорисовывает снизу ленту исходного кропа** (земля/трава). Авточистка `cleanStrip`
  в `scripts/woods-gen.mts`: ряд = полоса, если >90 % ширины не-маджента (объект всегда с полями);
  порог 55 % срезает сами объекты — не понижать.
- **`bg-[var(…)]` в md/скриптах = краш Tailwind-скана** — см. `gotcha-tailwind-content-scan`.
- Маджента `#C000C0` — единственный матовый; маркеры карт (`MARKER_TYPE_COLOR`) в палитру
  материалов не входят, ближайший риск `container #9A8866 ↔ wood #A18265`.
