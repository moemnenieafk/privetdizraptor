## Что изменилось в игре (1.1.0 «KORD BREACH»)
- Достижений стало **123** (в нашем зеркале **111**, 3 тира: common 27 / rare 23 / legendary 61 — seasonal НЕТ).

## ⚠️ Гоча — почему НЕ строки в зеркале
`src/db/landing.ts` `syncEftLandingData()` реконсилит: `db.delete(achievements).where(id NOT IN <tarkov.dev keep>)`.
Сезонных достижений **нет в tarkov.dev** (концепт 1.1.0; §4.12 — на них не опираемся, API к тому же лежит).
→ Ручные строки в `achievements` крон **сотрёт**. Решение: **статический датасет-файл + мёрж в ридере** (паттерн `/game-data-ingest`, §4.11 — данные, которых нет во внешнем API, берём из игры и держим у себя).

## План
1. **Данные** — `src/data/eft/seasonal-achievements.ts`: массив `SeasonalAchievement[]` (форма совместима с `AchievementView`), `normalizedRarity: 'seasonal'`, `hidden:false`, синтетические стабильные id `kbreach-<slug>`, `side` (см. ниже), `playersCompletedPercent` со скрина.
2. **Ридер** — `getEftAchievements()`/`getEftAchievement(id)` в `src/db/landing.ts` **конкатят** статические сезонные к зеркальным (крон их не трогает). Сортировка/фильтры уже поддержат новый тир.
3. **Фронт-тир** — `src/lib/achievement-visuals.ts`: в `AchRarity` добавить `'seasonal'`; в `RARITY` — мета (цвет `--color-season-01` #5FD5C0, бейдж/тинт/бордер по образцу); в `RARITY_RANK` — `seasonal: -1` (выше легендарного, «сначала престижные»); в `ALL_RARITIES` — первым. `sideLabel` при необходимости.
4. **Рамка** — синяя `AchievementSeasonal.png` вокруг иконки сезонных (в `AchievementsClient` тайл + деталь). Ассет положить в `public/images/achievements/frames/` (или R2 по паттерну). У обычных иконка «плавает» (решение редизайна) — рамку добавляем ТОЛЬКО сезонным.
5. **Иконки сезонных** — отдельная тема (как в иконочном спринте): извлечь/отрендерить эмблемы. Пока — плейсхолдер в синей рамке.
