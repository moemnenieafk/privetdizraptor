# Сезоны / Боевой Пропуск — данные (предметы БП + спавны) → старт эпика

Активирует отложенный задел [[Сезоны и Боевой Пропуск.md]] (🟡). Триггер — V4DYA: завести БП-предметы
патча 1.1.0 в каталог и их спавны на карту, чтобы заработала фича [[where-to-find-item]] и бейджи БП.

## Цель
БП-предметы текущего патча (1.1.0, «KORD BREACH») **есть в нашем каталоге** и **их спавны видны на
карте** — автономно (§4.11), из файлов игры. Это данные-фундамент эпика; UI-фичи (трекер БП, каталог
наград, планировщик модификаторов) — следующими фазами.

## Зафиксированные решения (V4DYA, 2026-08-14)
1. **Источник предметов = `/game-data-ingest` из файлов игры.** tarkov.dev не задатамайнил 1.1.0 →
   крон-синк их не принесёт. Достаём BSG id / имена / иконки из клиента EFT (тулинг есть: AssetRipper,
   иконки уже extracted). **НЕ вики** (§4.9 — вики только визуальный референс).
2. **Источник спавнов = loot-таблицы игры** (реальные координаты, как heatmap-датасет
   [[heatmap-loot-ev-dataset]]), автономно. **Фолбэк — ручная editorial-разметка:** V4DYA + друг ставят
   метки через визард (source='user'), если у доков нет фиксированных точек в файлах. Вики даёт привязку
   к КАРТАМ (не координаты). НЕ вики-скрейп (§4.9).
3. **Скоуп = старт эпика Сезоны/БП** (не только предметы+спавны). Но исполняем **фазами**: сперва
   данные-фундамент, потом UI-домен.

- **Связь каталог↔БП:** `src/data/icon-bundle-map-eft.json` (BSG id→bundle) — **сейчас 0 БП-бандлов**
  (проверено grep'ом) → предметов в каталоге нет.
- **Каталог предметов:** наполняется ВРУЧНУЮ — `public/images/items/eft/items_database.json` +
  `npm run db:etl` (`scripts/etl-items.ts`, идемпотентный upsert). НЕ синкается из tarkov.dev.
- **Спавны:** единая `markers` (source `sync`|`user`); синканные — крон `sync-maps-geometry` из
  tarkov.dev (у 1.1.0 БП-доков там пусто); ручные — визард (`/api/admin/editorial-markers`).
- **Фича «Где найти»:** [[where-to-find-item]] уже читает `markers` + `container-loot.json` → как только
  спавны БП-доков лягут в `markers`, блок заработает для них **без доп. кода**.
- **Тулинг извлечения:** скиллы `/game-data-ingest`, `/game-asset-extraction`; память
  [[eft-asset-extraction]] (иконки extracted, AssetRipper, Unity 2022.3.43).

## ⚠️ Ф0 — risk-check ДО кода (как spt-loot-tables-research для heatmap)
Три неизвестных, любое может изменить план — снять по первоисточникам ПЕРЕД ингестом:
1. **Файлы 1.1.0 у нас есть?** Извлечённые ассеты — под 1.0.5 (память [[eft-asset-extraction]]). Для
   1.1.0 БП-предметов нужен **текущий клиент** (у V4DYA установлен?) + прогон извлечения id/имён/иконок.
2. **SPT покрывает 1.1.0?** loot-таблицы брали из локального SPT-дампа; SPT 4.0 = EFT 0.16.9.0, лагает
   за 1.1.0 ([[spt-loot-tables-research]]). Если SPT не знает 1.1.0 — координаты доков придётся брать из
   **сырых loot-файлов текущего клиента** (locations/*/looseLoot.json) или падать на editorial-фолбэк.
3. **У доков TerraGroup вообще ЕСТЬ фиксированные точки?** Документы БП могут быть **quest-forced**
   (`spawnpointsForced`) или динамикой (с ботов Black Division — «общие»), а не обычным loose-пулом.
   Патчноут: «с локаций — индивидуальные (как квест-предметы), с ботов — общие». → часть доков = НЕ
   картируемые точки (динамика с ботов) → показывать честно (бейдж-факт, без ложных координат).

**Вердикт Ф0 (recon 2026-08-14):** SPT в `D:\Games\SPT` = **`0.16.9.40743`, ДО 1.1.0** → БП-предметов
1.1.0 в нём НЕТ (items.json: только старые `tgdocs/labrys/maps/militaryflash/securedtape`; флаеров/
контейнера/BD-жетонов — нет), их спавнов в loot-таблицах тоже нет. Лаг SPT ([[spt-loot-tables-research]])
подтверждён. →
- **Предметы (Ф1):** источник = **живой клиент 1.1.0** (`D:\Games\Escape from Tarkov`) — извлечение
  локали (id→имя) + маппинг id→bundle через `/game-asset-extraction` (AssetRipper). SPT отпадает.
- **Спавны (Ф2):** реальных координат в файлах НЕТ (SPT стар, live-loot серверный) → **ручная editorial-
  разметка** (V4DYA + друг по вики-таблице) = основной путь (не фолбэк).

## Фазы (исполняем по одной, с подтверждением на БД/схеме — §5)
- **Ф0 — risk-check** (ресёрч, БЕЗ кода): снять 3 неизвестных выше по первоисточникам (клиент 1.1.0,
  SPT/loot-файлы, тип спавна доков). Вердикт: что картируется точками, что — динамика/quest-forced.
- **Ф1 — предметы в каталог:** extract 20 БП-предметов (id/имена/иконки) из клиента → добавить в
  `items_database.json` + `db:etl` → заполнить `icon-bundle-map-eft.json` (id→bundle) → бейдж/фильтр БП
  активируются. Рецепт — `/game-data-ingest`.
- **Ф2 — спавны в зеркало:** нормализовать координаты доков (loot-файлы/SPT) → `markers(source='sync')`
  своим синком (mirror-таблица/аддитив, как heatmap). Динамические/quest-forced — пометить, не врать.
- **Ф3 — активация (без нового кода):** [[where-to-find-item]] показывает спавны БП-доков; бейджи БП на
  карточках/плитках. Live-verify.
- **Ф4+ — UI-домен эпика (отдельные спеки):** трекер прогресса БП (дневной лимит документации),
  каталог сезонных наград с дедлайном, планировщик Личных модификаторов. Приоритет — V4DYA.
