# Геймификация компаньона цен — «Вместе сделаем лучшее комьюнити Таркова»

Превращаем сбор цен из утилиты в **кооперативную пассивную мини-игру**: полезное действие (иногда скриньшотить барахолку) = игровой прогресс. Тон: «играй как обычно, попутно помоги», НЕ «работай на нас».

## Три экрана-крючка
1. **Бегущая строка = «Доска заказов»** — тикер самых протухших/дорогих предметов без свежей цены. Данные = worklist (2-C). Динамические множители кармы на дефицит → система сама направляет усилие. Клик → страница предмета.
2. **Карта игрока (HUD)** — аватар + ник (есть `/u/[username]`), полоса кармы, текущий ранг, «принято сегодня / стрик».
3. **Ранги лояльности (Скупщик-стайл)** — LL-уровни: `Новобранец → Барыга → Оценщик → Смотрящий рынка` (имена в стиле Nightfall). Порог кармы + перк (бейдж, вес голоса ↑, косметика).

## Награды — лестница
| Уровень | Награда | Риск |
|---|---|---|
| Косметика/статус | ранг-бейдж на `/u/`, рамка аватара, титул, лидерборд | 0 |
| Социальное | «Топ контрибьюторов недели/сезона», сезонная цель комьюнити (собрали 80% покрытия → плюшка всем) | 0 |
| Ощутимое | **дни премиума за вклад** (milestone кармы → N дней «Оперативник») | ⚠️ каннибализация подписок |

**🔑 ОТКРЫТО (решение V4DYA) — модель премиум-награды.** «Заработай премиум вкладом» — сильнейший крючок, но подрывает платные подписки, если давать много. Варианты:
- **Проба** — вклад даёт *вкус* (короткие бусты/разовые дни), постоянный премиум — за деньги;
- **Ускоритель** — скидка/ускорение, не замена;
- **Кап** — не больше X дней/мес заработать.
Стыкуется с [[monetization-subscriptions]] (тир «Оперативник»). Это меняет всю экономику — надо решить до реализации наград.

## Механика начисления кармы (в коде)
- База **0.01 за принятую выгрузку** (`KARMA_PER_UPLOAD`, Скупщик-стайл микро; тюнится до 0.001). ✅ 2-D.
- **✅ Бонус за устаревание (2026-07-23):** обновил протухшую цену — чуть больше (направляем на доску заказов). По самому старому предмету пачки: >60мин → +0.01, >6ч или нет данных → +0.02 (`uploadKarmaFor`, считается ДО вставки по прежней свежести). Ридер показывает «+X.XXX» за выгрузку (game-feel).
- **Осталось:** вес голоса по карме в агрегате (weighted-median), ранги/пороги, тикер-UI, HUD, лидерборд, сезонные цели, экономика наград.

## Game-feel («сок»)
Тост при попадании «+0.02 · принято 8 цен» · стрики (заходишь несколько дней → бонус) · дневная/недельная цель («обнови 5 из доски заказов») · прозрачность «твои N цен помогли M игрокам».

## Риски
1. **Ферма** — гасят: карма микро + валидация + якорь tarkov.dev + (скоро) вес по карме; премиум-порог держим выше цены «нафармить».
2. **Каннибализация подписок** — см. открытую развилку.
3. **«Неоплаченный труд»** — фрейминг миссии + реально пассивное действие.
