3. **Селектор режима Season/PVP/PVE = по-настоящему 3 набора статы** на профиль (в EFT PVP/PVE — раздельные прогрессы). Стор хранит до трёх, таб переключает показ мгновенно. **Волна 2** (расширение модели профиля).
4. **Состав секции — полный паритет** со старой страницей: навыки + мастерство оружия (76, свёрнуто топ-N + «показать все») + таблица рейдов по сторонам (BEAR/USEC/Scav/Всего).
5. **Маршрут** `/eft/comlink/players` → 308-редирект на `/eft/hub`. Хинт «где взять файл» → ссылка «Скачай свой профиль тут» в блоке.
6. **Порядок сборки:** сначала визуал на текущей одно-режимной модели, трёхрежимный стор — отдельной волной.

## Модель профиля (волна 2 — стор-рефактор)
`PlayerProfile`: плоские стат-поля (`raids/kills/deaths/survivalRate/hoursPlayed/level/prestige/experience/kd/survived/killed`) → per-mode наборы `modes: { season?, pvp?, pve?: StatSet }` + `activeMode`. Идентичность (nickname/faction/edition/memberCategory) — общая на профиль. Сводка/жетон/секция читают активный режим. Схема localStorage — **обратно-совместимая миграция** (старый плоский профиль → `modes.pvp`, дефолты). ~15 файлов-консюмеров.
