# Система управления контентом

## Цель
Нужно разработать свою удобную систему администрирования и управления контентом на сайте.

## Решение (утв. V4DYA 2026-07-04)
**Своя лёгкая CMS на `role=admin`** (НЕ готовый headless типа Directus/Payload) — уже есть
фундамент: `role=admin` в `profiles`, роут `/admin` (`layout.tsx` + `page.tsx` + `items/`).
Довести свои админ-экраны под наши таблицы: `feedback` (обращения), истории, маркеры карт,
модерация. Эпик E10 роадмапа [[additional-workout]] — делаем ПОСЛЕ стабилизации контент-модели
(после Фаз 2–3: карты/mobile), чтобы не переделывать схемы под меняющиеся данные.
