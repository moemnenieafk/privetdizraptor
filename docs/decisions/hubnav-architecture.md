# HubNav — канон блока навигации раздела (НЕ переизобретать)

**Правило V4DYA:** блок HubNav спроектирован как **переиспользуемый**. При создании новой страницы
её НЕ переписывают и НЕ верстают заново — берётся готовый компонент + конфиг из `HEADER_DICTIONARY`.

## Что это
Двухколоночный блок навигации раздела. **Контентная область (`max-w-275` = 1100px) делится на две
половины** (`lg:w-[32.625rem]` ≈ 522px каждая, `gap-7` = 28px между ними):
- **Левая половина** — иконка (плитка 21×21, маска 10.5, `bg-(--primary)`) + **H1-заголовок раздела** +
  краткое описание.
- **Правая половина** — микро-лейбл «НАВИГАЦИЯ ПО РАЗДЕЛУ» + линия, затем **ряд иконок-табов разделов**
  (`SectionNavTab`); если у раздела есть **подразделы** — они идут **вторым рядом в том же блоке**
  (другая сетка, `flex-wrap gap-2`).

Сетка: контейнер 1100px · две половины ~522px · gap 28px (Figma «HubNav-Prapor» 1100×126, «536 Fill × 80»).

## Три вариации (различаются слегка — суть одна: простая сетка + навигация)
| Раздел | Компонент | Файл |
|---|---|---|
| **Квесты** | `QuestsHubNav` (+ `QuestNavTab`/`QuestsNavBar`) | `src/components/features/quests/` |
| **Предметы** | `HubNav` | `src/components/features/items/HubNav.tsx` |
| **Остальные разделы** | `SectionHubNav` (+ `SectionNavTab`) — БАЗА | `src/components/features/navigation/` |

`SectionHubNav` вариации:
- `variant='full'` — полная шапка (иконка+заголовок+навигация), для ИНДЕКСНЫХ страниц раздела.
- `variant='bar'` — тонкая полоса-переключатель, для страниц со своим заголовком (`deepOnly` — только на глубоких путях).
Конфиг (ряд разделов + подраздел) **само-вычисляется** из `HEADER_DICTIONARY` через
`getSectionHubNav(rootPath, pathname)` (`src/lib/section-hub-nav.ts`). На самом хабе (`pathname===rootPath`)
не рендерится — там карточки.

Прочие обёртки поверх базы: `ComlinkHubNav`, `DossierHubNav` (Досье — реюзит `getSectionHubNav`+`SectionNavTab`).

## Как делать новую страницу в разделе (НЕ верстать навигацию руками)
1. Добавить узел/ссылки раздела в `HEADER_DICTIONARY` (`src/data/headerConfig.ts`).
2. Дропнуть готовый компонент: `<SectionHubNav rootPath="/eft/…" variant="full|bar" … />`
   (или `QuestsHubNav`/`items HubNav` для тех разделов). Навигация подтянется сама.
3. Иконки табов — реальные ассеты; подразделы отрисуются вторым рядом автоматически.

Consumers (примеры): `gamesetting/*`, `progress/*`, `comlink/*`, `videos/*`, `items/*`, `quests/*`, `hub` (Досье).
