# Story/lore-слой: путь истории по карте

## Цель
Выбрал сюжетную историю в левом поиске → на карте подсвечен её маршрут: чекпоинты с номерами шагов, соединённые линией по порядку. Наш ров — полные walkthrough-гайды привязаны к географии (у конкурентов сухие маркеры).

## Границы
- **В scope:** выбор истории (drawer СЮЖЕТ), постоянная подсветка её чекпоинтов (кольца story-tint + номера linkStep + пунктирная линия-путь), клик по чекпоинту → walkthrough на шаг.
- **НЕ трогаем:** авторинг (визард уже ставит linkKind='story'+linkId+linkStep), схему/БД, walkthrough-данные (гео у чекпоинтов гайда нет — координаты из editorial-пинов).

## Контекст (каркас частичный)
- `storiesForMap(slug)` (`lib/story-map-link.ts`) — истории на карте по `condition.mapIcon` (без гео). Уже рендерится в drawer (чип СЮЖЕТ, `StoryRow`).
- `storyPins` (в `MapSearchDrawer`) = editorial-маркеры `linkKind='story'` → позиции по slug истории. Гео = отсюда.
- Порядок = `linkStep` на editorial-маркере (визард, шаг 4, поле «шаг»).
- Оверлей — паттерн лут-фильтра/реверса (`/map-interactions` рецепт 2): свой layerGroup, вне LOD.

## Реализация
- **`useStoryFilterStore`** (нов., эфемер) — `slug: string | null` (одна выбранная история), select/clear.
- **`MapSearchDrawer`**: клик по `StoryRow` → select истории (стор) + подлёт; активная строка выделена; повторный клик/другая = смена; нет пинов → подсказка «чекпоинты не размечены».
- **`MapViewerClient`**: оверлей выбранной истории — из `editorialMarkers` (linkKind='story' && linkId===slug), сорт по linkStep: `L.circleMarker`-кольца + divIcon-номера + `L.polyline` (пунктир, story-tint) по порядку.
- **`EditorialMarkerCard`** story-чип: deep-link на шаг walkthrough при linkStep (`?step=` / `#`).

## Развилки (грилинг 2026-08-01)
1. Слой → **выбор истории → подсветка чекпоинтов** (одна за раз, drawer-driven).
2. Порядок → **номера + пунктирная линия-путь** (линия только по пинам с linkStep).

## Критерий готовности
- [ ] `tsc`/eslint чисто, смоук зелёный
- [ ] Выбрал историю с размеченными чекпоинтами → кольца+номера+линия; сброс/смена работает.

- Фича data-dependent: без editorial story-пинов подсветка пуста (список историй всё равно есть).
- Бэкенд/схему не трогаем.
