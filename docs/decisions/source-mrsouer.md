# Источник контента: mrsouer.com

## Что это (research 2026-07-04)
https://mrsouer.com — персональный сайт стримера Mr. Souer (twitch: mr_souer). Двуязычный RU/EN, ~163 страницы. Next.js RSC + Mantine, скрины на storage.mrsouer.com.
- **/guides** — 120+ пошаговых гайдов: сюжетки EFT 1.0 (boreas, ticket, batya, the_unheard, tour, accidental_witness, falling_skies, labyrinth, they_are_already_here, blue_flame, btr_questline, nachalo, kollektsioner…) + 60+ квестов Arc Raiders.
- **/eft/maps** — 18 интерактивных карт (вкл. Terminal, Labs, Labyrinth, Icebreaker); **/event** — 11 комьюнити-ивентов (Tarkov Bingo, Gun Game, Boss Run…).
- Формат: шаги + webp-скрины + twitch-клипы как видеопруфы. Обновляется активно (Борей: создан 25.05, обновлён 20.06.2026).
- **Техника парсинга (воспроизводимо):** контент вшит в Next.js RSC-payload страницы (`self.__next_f.push`, массив steps + текст-чанки RU/EN) — парсится fetch'ем без браузера.

Гайд «Борей» (15 глав) использован как фактологическая база шагов нашего walkthrough ([[quest-story-design]]) — пересказ, не копия.

## Идея V4DYA (2026-07-04)
«Вообще весь сайт надо бы использовать в качестве интересных заметок для своего сайта» — т.е. mrsouer как постоянный источник фактуры для контентных разделов ЦТА: прохождения сюжеток, гайды, находки.

## Правила использования (важно)
- **Факты игры не защищены авторским правом, тексты — защищены.** Берём фактуру (шаги, предметы, количества, локации), но переписываем СВОИМИ словами. Дословное копирование — нельзя.
- Скриншоты/картинки сайта — НЕ переносить (авторские). Свои скрины или ассеты из клиента игры (скилл game-asset-extraction).
- Правило NO EXTERNAL WIKI LINKS распространяется и сюда: на mrsouer со страниц ЦТА не линкуем — контент интернализуем.
- Хорошая практика: пометка «сверено с игрой vX.Y» в футере раздела (уже есть в walkthrough).

## Как использовать (процесс)
1. Deep research агентом по конкретному гайду → структурированная фактура.
2. Перенос в наши data-модели (`story-walkthroughs/*`, будущие гайды).
3. Сверка с игрой/зеркалом (id предметов из каталога, цены из prices).
