# Ранбук: как прогнать карту целиком

**Что это даёт.** Набор слоёв, извлечённых из клиента и положенных в **одну пиксельную сетку
с растром карты**. V4DYA кладёт их поверх своего HD-арта и видит, где расставил объекты не так.

**Это не фича сайта.** Ни базы, ни UI, ни синков. Скрипты в git, артефакты — нет.

Инвентаризация, гочи и находки: **`eft-map-layers.md`**. Здесь — только как запускать.

---

## 🔑 Три правила, нарушение которых стоит прогона

**1. Все слои кладутся ОДНОЙ аффиной, и никто не выводит её заново.**
Источник — `gen/<map>/rooms/<map>-rooms-frame.json`. Скрипты сверяют свою аффину с этим файлом
и **падают при расхождении**. Иначе один слой однажды уедет на метр, и найдётся это нескоро.

**2. `coordinateRotation: 180` — это ОТРАЖЕНИЕ по X-индексу, а не поворот на 180°.**
`IDX[:, ::-1]`, не `IDX[::-1, ::-1]`. Ошибка жила во всех трёх потребителях террейна и не была
замечена, потому что **статистики к отражению инвариантны**: после починки ни одна цифра
Таможни не изменилась.

**3. `UnityPy Mesh.export()` зеркалит X** (`-pos[0]`). Вершины читать через `MeshHandler`.

## Одна команда

```bash
python scripts/eft-map-layers/run-all.py <map>            # весь конвейер, 12 шагов
python scripts/eft-map-layers/run-all.py <map> recon      # только разведка новой карты
python scripts/eft-map-layers/run-all.py <map> --dry-run  # план шагов, ничего не делает
```

Шаг, у которого выход уже на диске и свежее входа, **пропускается** с явной строкой;
`--force` пересобирает. Выбор шагов: `--only zone,roads` · `--skip render` · `--from walls` ·
`--with-deps` (дотянуть предков). Коды возврата: `0` ок · `1` упал обязательный шаг ·
`2` preflight · `3` ошибка вызова.

Шаги: `recon manifest terrain height material vegetation rooms frame zone roads stones walls
render` плюс вне дефолтного плана `gate verify-bin align`.

Ниже — те же шаги по отдельности, если нужно руками.

## Порядок и зависимости

⚠️ **`frame.json` производит `render-rooms.py`.** Значит комнаты идут рано — до зоны, дорог,
камней и стен. Это неочевидно и это главная ловушка порядка.

```
манифест карты ──┬─> dump-terrain ──> .bin ──┬─> build-heightmap ──> height-meters.npy ──┐
                 │                           ├─> build-material                          │
                 │                           └─> extract-vegetation ──> vegetation.json ─┤
                 └─> dump-rooms ──> rooms.json ──> render-rooms ──> frame.json ──────────┤
                                                                                          │
  frame + height ──> dump-zone ──> zone-mask.png ──┬─> dump-roads                        │
                                                    └─> dump-stones ──> stones.json      │
  frame + height ──> cut-walls                                                            │
  stones.json + vegetation.json + frame ──> render-objects <──────────────────────────────┘
```

## Команды по шагам

Пути по умолчанию: клиент `D:\Games\Escape from Tarkov\EscapeFromTarkov_Data`,
манифест `D:\Games\raster\<map>\manifest.json`, промежуточное `D:\eft-export\<map>\`,
выход `map-exports/OBJECTS-MAPS/gen/<map>/<layer>/`.

| Шаг | Команда | Даёт |
|---|---|---|
| 0. Манифест | `make-manifest.py <map> <outdir>` | границы карты, если каталога растра нет |
| 1. Дамп террейна | `dump-terrain.py <sharedassets> <level> <outdir> <map> [with-neighbours]` | `.bin` + `splat_*.bin` |
| 2. Высоты | `build-heightmap.py <bin> <manifest> <outdir> <map> [4096]` | 16-бит PNG, отмывка, **метры `.npy`** |
| 3. Материал | `build-material.py <splatdir> <bin> <manifest> <outdir> <map> [4096]` | PNG палитры + индексы |
| 4. Растительность | `extract-vegetation.py <sharedassets…> <bin> <manifest> <outdir> <map> [allow-unresolved]` | JSON/CSV поштучно + плотность |
| 5. Комнаты | `dump-rooms.py <Data> <map> <outdir>` | комнаты, проёмы, двери, выходы |
| 6. **Рамка** | `render-rooms.py <rooms.json> <manifest> <outdir> <map> [locks.json]` | оверлей по этажам + **`frame.json`** |
| 7. Зона | `dump-zone.py <Data> <map> <manifest> <outdir> [--height npy]` | полигон + **`zone-mask.png`** |
| 8. Дороги | `dump-roads.py <Data> <map> <rooms-frame.json> <outdir> [zone-mask.png]` | полотно/разметка/площадки |
| 9. Камни | `dump-stones.py <Data> <map> <manifest> <outdir>` | экземпляры + классы размера |
| 10. Стены | `cut-walls.py <Data> <map> <manifest> <outdir> [--height npy]` | 5 SVG по этажам + группа `props` |
| 11. Рендер | `render-objects.py all --map <map> ...` | камни и растительность сверху с текстурами |

⚠️ **Ловушка сигнатур:** у `dump-roads.py` третий аргумент — **манифест РАМКИ**
(`<map>-rooms-frame.json`), а не `manifest.json` карты. Единственный такой случай в конвейере.
У `extract-vegetation.py` первый аргумент принимает **список файлов через запятую**.
Флаги `dump-terrain.py` — голые слова (`with-neighbours`, `orient-override`), посторонние отвергаются.

**Проверки, которые стоит гонять:**

| Что | Команда |
|---|---|
| Дамп против Unity-эталона | `verify-terrain-bin.py <эталон.bin> <наш.bin>` |
| Привязка по 4 гипотезам × 4 масштабам | `verify-alignment.py <grounddir> <bin> <manifest> <map> <эталон> landsea\|gradient` |
| Шумовой гейт ориентации | `check-orientation-gate.py` — 5 опытов, «сошлось 5 из 5»; карты в аргументах нет |

## ⚠️ Новая карта — это НЕ смена аргумента

Соглашения общие, **словари имён у каждой карты свои**. Перед прогоном — разведка:

| Что проверить | Как | Пример расхождения |
|---|---|---|
| Граница | есть ли корень `<Карта>_LevelBorders` в `*_Scripts` | Таможня 440 панелей, Маяк 1 439 |
| Комнаты | `<Карта>_Sound`, сколько `SpatialAudioRoom` | Таможня 398, Улицы 1 239, Лес 139 |
| Дороги | есть ли узел `OO/ROAD` в дорожной сцене | **у Маяка его НЕТ** — отбор по именам тянет ~1 млн треуг. с реквизитом |
| Камни | какие семейства по именам | Таможня `Stone_0N`; Маяк `AM_Rock_Big/Middle/Small`, `Arid_rock_*_cliff` |
| Этажи | доля комнат с этажным токеном в пути | Таможня 52 % (207/398) — воспроизведено дважды. По Маяку два замера разошлись: разведка дала 12 %, `recon` раннера — 69 %. **Число не подтверждено, перемерить.** Лес 3 % |
| Слайсы террейна | есть ли соседние колонки в чужих `sharedassetsN` | Маяк: 3 своих + 3 соседних, покрытие 64 % → 98.5 % |

**Объекты карты разбросаны по ВСЕМ её сценам,** а не по одной: слой камней нашёл экземпляры
в семи неочевидных сценах помимо основной. Не ограничиваться `levelN` террейна.

## Известные мины на оставшихся картах

| Карта | Что упирается |
|---|---|
| **Лес** | сырые `m_Heights` в `[2673, 32767]` не лезут в делитель **32766** — делитель не константа формата |
| **Берег**, **Резерв** | контрольная формула сетки промахивается **опорной точкой** на 2852.1 и 1759.1 м, одинаково для всех слайсов карты |
| **Развязка** | проходит `exit 0`, следующая на очереди |
| **Маяк** | три упора, см. ниже |

### Маяк — результат `recon` (13 с, живьём)

**Пойдёт само:** террейн (`level200`/`sharedassets200`, 3 своих + 3 соседних слайса,
`with-neighbours` подставляется автоматически), комнаты (**291** комната, 1347 проёмов,
**300** дверей, 10 выходов — сошлось до штуки с живым прогоном), зона (**1448** панелей),
камни (2562 кандидата, 226 имён).

**Требует ручной настройки:**
1. **Ветки `OO/ROAD` нет.** Дефолтный regex ловит **1** объект; отбор по именам берёт
   12 368 из 12 369 GO вместе с 4 162 узлами реквизита. Есть `OO/ROADS`, но там всего 71 объект.
   Профиль дорог для новой карты **правится руками** — `recon` даёт числа, решение за глазами.
2. **Веток `BUILDING`/`BUILDINGS` — ноль.** Списка зданий у Маяка не будет; живой `dump-rooms`
   подтверждает `buildings: 0`.
3. **Манифест синтетический, `layers[]` пуст** → поэтажной разбивки у `frame` и `walls` не будет.
   Этажи придётся задать вручную либо выводить Y-кластеризацией.

## Что НЕ сделано

- **Слой 7 «препятствия выше 1 м» — не в заказанной форме.** Заказывали *один* слой с резом
  на 1 м **от земли**; получилась группа `props` внутри **поэтажных** SVG стен с резом 1.2 м
  над полом каждого этажа. Содержимое даром выпало, форма — нет. Нужен отдельный прогон.
- **У стен только SVG, растра нет** (у комнат, дорог и камней есть оба).
- **Теней на землю нет** — рендер содержит только объекты, shadow-catcher не ставился.
- **Рендер только камней и растительности**, зданий нет (меши и трансформы для них уже добыты).
- **Наружные/внутренние стены разделены приблизительно** — заливкой снаружи; точное разделение
  только по ветке-источнику иерархии.
- **Рез `underground` на 0.20 м — оценка** (мода низов 636 building-мешей), не факт из данных.
