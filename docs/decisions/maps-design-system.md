# Карты: единая дизайн-система SVG

**Статус:** 🔵 обдумываю — твоя зона (дизайн). Параллельный трек.
**Затрагивает:** `public/images/maps/eft/*.svg` (+ Supabase `cta-media/maps/eft/`) · Figma

## Контекст
Карты надо привести к единому визуальному языку: однообразие цветов, толщина линий, идентичность. Идея — взять одну карту с максимумом объектов как **эталон**, затем пройтись по всем и сделать редизайн под него.

## Рабочий процесс (как править в Figma)
- SVG лежат в `public/images/maps/eft/{slug}.svg` (фолбэк) и Supabase `cta-media/maps/eft/`. Импортировать в Figma оттуда.
- ⚠️ **Слои этажей — `<g id="Ground_Level">`, `<g id="Underground_Level">` и т.п. — имена групп менять НЕЛЬЗЯ**: Leaflet переключает этажи по этим ID. Перекрашивать/менять штрихи — ок; переименовывать/схлопывать слои-группы — нет.
- После редизайна — заливка обновлённых SVG обратно (фолбэк в `public/` + Supabase). Координатная привязка (`transform`/`bounds` в `eft-map-config.ts`) не должна поехать — viewBox/габариты SVG сохранять.

## Открытые вопросы (твои, как дизайнера)
- Какая карта — эталон (макс. объектов)? Кандидаты: Streets / Reserve / Interchange.
- Палитра из NIGHTFALL-токенов для слоёв карты (земля/вода/здания/дороги/зоны).
- Толщины линий, стиль контуров зон, читаемость на тёмном фоне.

## Вывод
*(твой дизайн-вывод: эталон + палитра + правила линий)* → затем при необходимости Claude Code для интеграции/конфига.
