# Карта Квестов: фракция-aware дедуп + метка легит-повторов

**Статус:** ✅ реализовано (main). Грилл V4DYA 2026-08-26.

## Контекст (жалоба)
На Карте Квестов один квест выглядел задвоенным — «Загладить вину» ×3 идентичными карточками. Карта кладёт узел на КАЖДЫЙ task-id из `EFT_QUESTS`, без дедупа и без фильтра по фракции.

## Диагноз (сверка с каталогом, 527 квестов)
Дублей objective-id нет. Есть 10 групп с одинаковым ИМЕНЕМ квеста — три природы:
1. **Фракционные USEC/BEAR** (Обновка/Текстиль Ч1-2) — одинаковые цели, но разные квесты по фракции; игрок делает только свою.
2. **Настоящие дубли** (Путь охотника ×2 — оба старт; Цена независимости ×2 — одинаковые пререки) — не требуют друг друга, схлопывание безопасно.
3. **Легит-повторы** (Загладить вину ×3, Поменять батарейку) — одно задание делается несколько раз как этапы цепочки. У «Загладить вину» цепь строго линейна: `…Вооружение → ЗВ(47df) → Наблюдение → Зачистка → ЗВ(3ab2) → ПО → Карантин → ЗВ(c323)`. **Схлопнуть нельзя — будет цикл в графе** и потеряется правда «делается 3 раза».

Данные достоверны (= tarkov.dev). Проблема — в подаче на карте.

## Решение (грилл: «фракция-aware + дедуп», для повторов «оставить, пометить этап»)
Хелпер `src/lib/quest-map-dedup.ts` → `dedupeQuestsForMap(tasks, faction)`:
1. **Фракция-фильтр:** `factionName` USEC/BEAR → оставляем фракцию игрока (из `usePlayerStore`).
2. **Группировка** по (трейдер + имя + сигнатура целей). Группа >1:
   - **связаны цепочкой** (транзитивная достижимость по `taskRequirements`) → легит-повтор: все узлы остаются, `repeatMarks` = «этап i/N» по порядку в цепочке;
   - **не связаны** → настоящий дубль: один выживший, требования схлопнутых объединяются в него, внешние ссылки ремапятся (без self/дублей).
3. Реально разные квесты с общим именем (разные цели) не группируются.

Подключение: `QuestMapClient` — `initialTasks` memo расширен дедупом (фракция в deps), `repeatMarks` прокинут в `QuestNode`. `QuestNode` рисует компактную метку «Этап i/N» в шапке (амбер-чип).

Транзитивная проверка гарантирует отсутствие циклов: линейные повторы (ЗВ) не сливаются, параллельные дубли — сливаются.

## Проверено
Скрипт на живых данных (BEAR): фильтр 527→521; «Загладить вину» ×3 → REPEAT этапы 1/3·2/3·3/3; «Цена независимости»/«Поменять батарейку» → безопасный дубль-схлоп. Цикла нет. tsc 0, прод-билд webpack зелёный.
