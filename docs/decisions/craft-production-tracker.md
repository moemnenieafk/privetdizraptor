# Трекинг производства крафта — карточка в 4 состояния

Редизайн карточки крафта (`/eft/progress/hideout/craft-profit`) в **4 состояния** + реальный
**трекинг производства** (живой обратный таймер, как в игре). Эталон — Figma-нода **2990-584**
(4 фрейма: Заблокировано · В производство · Производится · Готово). Числа в макете — «рыба»,
экономику считаем сами (`computeCraftEconomy`).

## 1. Машина состояний
```
ЗАБЛОКИРОВАНО ──(станция достроена)──▶ В ПРОИЗВОДСТВО ──(клик «В производство»)──▶
ПРОИЗВОДИТСЯ ──(таймер=0)──▶ ГОТОВО ──(клик «Забрать»)──▶ В ПРОИЗВОДСТВО
                    └──(«Отменить крафт»)──▶ В ПРОИЗВОДСТВО
```
+ 5-й вид **«СТАНЦИЯ ЗАНЯТА»**: сёстры по станции, пока она занята другим крафтом — кнопка
«В производство» гашена, подсказка «Верстак освободится через ЧЧ:ММ».

Определение состояния (приоритет):
1. Станция производит ЭТОТ крафт → `ПРОИЗВОДИТСЯ` (таймер>0) / `ГОТОВО` (таймер≤0).
2. Станция занята ДРУГИМ крафтом → `СТАНЦИЯ ЗАНЯТА`.
3. `builtStationLevel < craft.level` (или квест/издание не выполнены) → `ЗАБЛОКИРОВАНО`.
4. Иначе → `В ПРОИЗВОДСТВО`.

## 2. Трекинг (реальный, §game-timer-dock)
- **`useCraftProductionStore`** (Zustand + persist localStorage): `Record<stationKey, { craftId, startedAt, durationSec }>`. **Одна станция = один активный крафт** (реш. A).
- **Заморозка на старте**: `durationSec` = эффективное время (с текущим навыком «Ручное производство») в момент клика — снапшот. Прокачка навыка позже идущий крафт НЕ ускоряет. Слайдеры навыков влияют лишь на будущие запуски + витринные цифры незапущенных карточек.
- **Таймер** = `durationSec − (now − startedAt)`, кламп ≥0; формат `дни : часы : минут : секунд` (как в макете, ведущие нули). Тик — на клиенте (интервал), экстраполяция от `startedAt` (устойчиво к сну вкладки).
- **Действия:** «В производство» → пишет снапшот (если станция свободна). «Отменить крафт» → удаляет запись станции. «Забрать крафт» → удаляет запись (освобождает станцию). *Допущение: «Забрать» только чистит стейт, в «в схрон» НЕ плюсует (флип одним словом, если надо).*
- **Глобальный вотчер `CraftWatcher`** (без UI, монтируется в layout — напр. `/eft/progress/layout` или выше): тикает, на переходе любого крафта через 0 → браузер-`Notification` + звук (запрос разрешения, persist — паттерн `game-timer-dock`). Дока НЕТ (follow-up).

## 3. Облик (компакт, пиксель-перфект по ноде 2990-584)
- **Шапка:** иконка станции + имя + «УР. NN» справа. Заблок. — доп. «ТРЕБУЕТСЯ ПОСТРОИТЬ NN» + иконка молотка (`hammer-anim`/`hideout-build-icon`). Готово — зелёная обводка/иконка (success/nvg-green).
- **Герой-выход (компакт):** мелкая ячейка `TrackCell` (рарити-фон, бейдж «×N») + **shortName** предмета + строка «ПРОДАЖА <flea> ₽» справа (иконка ₽).
- **Входы:** секция «ВХОД» (лейбл-линия) → ряд `TrackCell` (display + «в схроне») → лейбл-линия «ВЫРУЧКА» перед метриками.
- **Метрики (с иконками, цвет по знаку):**

| Лейбл | Поле `computeCraftEconomy` | Цвет | Иконка |
|---|---|---|---|
| ВРЕМЯ | `effDurationSec` (одно значение, от навыка) | нейтр. | lucide `Clock` |
| ВЫРУЧКА | `outputValue` | нейтр. | `currency-ruble` |
| ПОКУПКА | `totalCost` | красный `−` | lucide `ShoppingCart` |
| КОМИССИЯ | `fleaFeeTotal` | красный `−` | lucide `Percent` |
| ЭКОНОМИЯ | `savings` | nvg-green `+` | `savings-icon` |
| ПРИБЫЛЬ | `profit` | nvg-green `+` | `profit-icon` |
| Р/ЧАС | `profitPerHour` | зелёный (`pphColor`) | `currency-ruble` |

- **ПРОДАЖА** (герой) = цена барахолки выхода (рыночный ориентир). **ВЫРУЧКА** = реальная выручка лучшим каналом (в прибыль). Разные по смыслу — не дубль.
- **Формат ₽:** полный — «177 362 ₽», «+92 400 ₽», «−24 400 ₽» (пробел-разделитель + ₽). Компактный «177к» — только вне карточки.
- **Кнопки (подвал) по стейту:** ЗАБЛОКИРОВАНО (gray, disabled) · «В ПРОИЗВОДСТВО» (янтарь, active) · «ПРОИЗВОДИТСЯ…» (disabled) · «ЗАБРАТЬ КРАФТ» (зелёный). Рядом всегда **скрепка** 📎.
- **Скрепка = «в список нужного» (стаб):** клик → тост «добавлено» + пишет id входов в `useShoppingListStore` (новый лёгкий persist-стор). Полноценный экран «Список нужного» — **follow-up**.

## 4. Переиспользование
`RecipeCard` (T6–T8) переделываем в 4-стейтную. `TrackCell` (герой+входы), `computeCraftEconomy`,
`RequirementChip` (требования остаются), `game-timer-dock`-паттерн (таймер+вотчер+уведомления),
`getTarkovBackgroundColor`, иконки из `public/icons` + lucide. shortName из `CraftSlotItem.shortName`.

## 5. Мобилка (cta-mobile канон)
Карточки уже грид 1/2/3 (1-в-ряд <sm). Таймер-цифры и кнопки стекаются внутри карточки; метрики
право-выровнены. Спец-обработки не требуется — следуем канону.
