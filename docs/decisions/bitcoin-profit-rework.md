# Переработка раздела «Прибыль BITCOIN» (/eft/progress/hideout/bitcoin-profit)

Цель V4DYA: **красивый сочный раздел, где в основе видно, как выгодно держать биткоин-ферму в убежище ЧВК** + единообразие дизайна и максимальное переиспользование компонентов (эталон — соседний `craft-profit-rework`). Текущая страница — голый 2-колоночный калькулятор, выпадает из дизайн-языка соседей и использует **устаревшую формулу**.

Спека собрана брифингом 2026-08-22. Числа/формулы — из ресёрча `docs/research/eft-bitcoin-profit-tarkovdev.md` (сверен с исходниками tarkov.dev `data.js` + live JSON-дампом).

Отличие от craft-profit: биткоин-ферма — **одна пассивная станция**, а не каталог рецептов. Поэтому переносим не грид карточек, а **дизайн-язык** (интро-блок, плитки-модули, скилл-индикаторы, тумблеры, MetricCard, токены NIGHTFALL) в форму **единого дашборда одной фермы**.

---

## 1. Формула добычи (канон tarkov.dev 1.1.0, из ресёрча)

```
сек_на_коин(GPU) = 300000 / (1 + (GPU − 1) · 0.041225)
коинов/сутки      = 86400 / сек_на_коин
```
- **BASE = 300000 сек** (⚠️ НЕ 145000 — устарело в текущем коде). Коэффициент **0.041225**. Один произведённый юнит = **1 Physical Bitcoin** (продаётся как есть).
- **Слоты GPU по уровню фермы**: L1=**10**, L2=**25**, L3=**50** (в дампе — инкрементальные бонусы 10/15/25, суммируются). L0 (не построена) = 0.
- Буфер: ферма стопится на **3** несобранных биткоинах (элита УУ → 5) — показываем справочной строкой, в профит v1 не моделируем.

## 2. Экономика (доход − топливо − окупаемость GPU)

```
доход/сутки       = коинов/сутки · цена_продажи_BTC
топливо/сутки     = цена_бака / длительность_бака_мс · 86 400 000     (для выбранного бака)
чистая_прибыль/сут = доход/сутки − топливо/сутки
GPU-вложение      = GPU · цена_GPU
окупаемость (дней) = ceil(GPU-вложение / чистая_прибыль/сут)          (∞ если ≤0)
прибыль на 1 GPU  = чистая_прибыль/сут / GPU
ROI %/мес         = чистая_прибыль/сут · 30 / GPU-вложение · 100
```
- **Цена продажи BTC** — из зеркала `prices` (лучшая продажа: Терапевт; барахолка — только если оффер присутствует в зеркале, иначе венью скрываем). Цена динамическая (обновляется в игре ночью) — берём как есть.
- **Топливо (V4DYA: включаем)**: генератор ест топливо. Баки — **Expeditionary fuel tank** и **Metal fuel tank**; базовые длительности из ресёрча (Expeditionary 45 473 000 мс, Metal 75 789 000 мс). Тумблер выбора бака. Цена бака — дешевейшая закупка из зеркала.
- **Навык «Управление убежищем» (HideoutManagement)**: режет ТОЛЬКО расход топлива −0.5%/ур (кап −25% на 50): `длительность_бака /= (1 − rate)` → дешевле в сутки. На скорость добычи НЕ влияет. (Скорость — только GPU.)
- **Тумблер «Учитывать топливо»** — вкл по умолчанию; выкл = только GPU-затраты (старое поведение, для сравнения).

## 3. Навыки/профиль (гибрид C — как craft-profit)

- По умолчанию: **уровень фермы** из профиля (`useHideoutStore.levels['bitcoin-farm']` через `editionFloor`), **УУ** из профиля (`resolveSkillLevel` — usePmcStatsStore + useManualProfileStore).
- **Слайдеры «что-если»**: GPU (1…слоты выбранного уровня) и УУ (0…51). Показываем базу профиля и override.
- Выбор уровня фермы = плитка-таб (1/2/3); он задаёт потолок слайдера GPU. Построенный из профиля уровень помечаем.

## 4. Данные — БЕЗ миграции

Ресёрч: биткоин-добыча ПАССИВНА, крафта в зеркале НЕТ → формула = **конфиг-константа** в `src/lib/bitcoin-profit.ts` (не читается из craft.duration). Миграция БД **не нужна**.

Единственное расширение чтения — `fetchBtcPrices` (page.tsx) добавляет цены топлива:
- `expeditionary-fuel-tank`, `metal-fuel-tank` (по normalizedName, как уже делается для `physical-bitcoin`/`graphics-card`). Отдаём в `BtcPrices`.

## 5. Раскладка страницы (сверху вниз)

1. **Интро-блок** (лёгкий, как craft §4.1): иконка `bitcoin-farm` (`stationIconClass`) + H1 «**Прибыль Bitcoin**» + короткое описание:
   > Стоит ли держать биткоин-ферму — чистая прибыль с учётом топлива, твоих навыков и числа видеокарт.
2. **Конфигуратор фермы** (переиспользуем дизайн плиток /modules):
   - **Ряд плиток-уровней** (L1/L2/L3): иконка фермы + «0N» + «N слотов GPU». Построенный уровень помечен. Одиночный выбор → потолок GPU.
   - **Слайдер GPU** (1…слоты) + быстрые кнопки (1/10/25/полный слот) — стиль текущего слайдера, но в дизайн-язык.
   - **Скилл-индикатор** «Управление убежищем» (read-only из профиля, паттерн `SkillIndicator` craft) + слайдер override.
   - **Тумблеры** (IconToggle-паттерн): выбор бака (Expeditionary/Metal), «Учитывать топливо».
3. **ГЕРОЙ — Вердикт + шкала GPU** (центр «сочности», R05):
   - **Баннер-вердикт**: крупно «**+X ₽ / сутки чистыми**» с цветокодом (nvg-green выгодно / amber около нуля / danger в минус) + «окупаемость за **N дней**» + строка «за месяц ≈ …».
   - **Шкала масштабирования**: горизонтальные бары чистой прибыли/сутки при 1 / 10 / 25 / 50 GPU (или до слотов уровня) — наглядно «как растёт профит от числа видеокарт». Текущее число GPU подсвечено.
4. **Метрики** (грид `MetricCard` из kit): Добыча BTC/сутки · Время на 1 BTC · Доход/сутки · Топливо/сутки · **Чистая прибыль/сутки** (accent) · Окупаемость GPU · Прибыль на 1 GPU · ROI %/мес.
5. **Что нужно / вложения**: цена 1 GPU × кол-во = вложение (строка/чип), цена BTC (Терапевт), справка про буфер 3 коина и динамику цены. (Лёгкий блок, без TrackCell v1 — ферма не «собирается» по предметам.)
6. Пустое/ошибка: «Цена биткоина недоступна (зеркало выключено) — метрики появятся после синхронизации цен.»

## 7. Разбивка для /autopilot

1. **T1 — Расчёт** `src/lib/bitcoin-profit.ts`: чистые хелперы §1–2 (сек_на_коин, коинов/сутки, топливо/сутки с УУ, чистая прибыль, окупаемость, прибыль/GPU, ROI, слоты по уровню). Константы из ресёрча. Не в JSX (§4.7).
