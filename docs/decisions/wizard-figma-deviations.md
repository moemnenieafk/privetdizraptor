# Универсальный визард маркеров — где отступил от Figma и почему

V4DYA просил объяснять расхождения. Ниже — только осознанные отступления (не то, что ты сам
направлял: Контейнер-иконка, дедуп Врага, Метка=default-marker, источник Лута, ростер боссов — это
твои прямые указания, они исполнены as-is).

## 1. Футер визарда — «Назад / Область / Далее», а не «Перемещение / Далее»
Figma Step-01 показывает в футере `ПЕРЕМЕЩЕНИЕ` слева. Я сделал **Назад / Область / Далее**:
- **Почему:** спека Ф2 явно пишет навигацию «Далее/Назад». «Переместить» логичнее живёт на карточке
  ПОКАЗА (Ф1) + как отдельный move-режим — дублировать его ещё и в футере визарда незачем.
- **Область** добавил в футер по твоей же последующей просьбе (лассо).

## 2. Квест-связь — богатый ряд трейдер/имя/уровень/каппа, а не единый чип
Figma для сюжета рисует компактный чип (`story-boreas` «Борей»). Для КВЕСТ-связи я оставил прежний
богатый ряд (аватар трейдера + имя + ур. + каппа), а чип — только для сюжета/события.
- **Почему:** ряд информативнее чипа (трейдер, уровень, каппа — производные квеста), и это уже
  работающая фича. Скажешь «унифицируй под чип» — сведу.

## 3. POI-маркеры на КАРТЕ — default-marker (img), потерян цвет-код связи
Раньше editorial-POI на карте рисовались CSS-«капелькой», крашеной по типу связи (сюжет=сталь и т.п.).
Перевёл на `default-marker.svg` (img).
- **Почему:** твоё правило «все маркеры карты через img, у них свой градиент» + «Метка=default-marker».
  Цвет-код связи POI-пина ушёл — **связь теперь видна в карточке** (ряд-заголовок + чип + закладка).
  Хочешь цвет-код вернуть на пин — верну (доп. слой/обводка по linkKind).

## 4. Иконка ОВЕРРАЙДА синканного — маппится, не пиксель-копия оригинала
Клик по синканному tarkov.dev-маркеру → оверрайд получает иконку по маппингу type/category
(`syncedToEditorial`), а не побайтовую копию исходной иконки.
- **Почему:** схема editorial ограничена (нет колонок linkedItemId/sides/spawnFaction синканного).
  Маппинг даёт близкую иконку (loose loot→предмет, quest→quest_zone, spawn→spawn). Для move/hide/аннотаций
  точность иконки некритична; при желании — редактор доправит категорию в шаге 2.

## 5. Область-лассо — завершение кнопкой «Готово», а не двойным кликом
- **Почему:** dblclick конфликтует с «ЛКМ = поставить вершину» (двойной клик = 2 лишние точки).
  Кнопка «Готово» (от 3 точек) однозначнее. ПКМ — убрать последнюю, Esc/Отмена — выйти.

## 6. Заливка Области — цвет из палитры категории (`MARKER_TYPE_COLOR`), не пиксель-извлечение
Ты просил «цвет, который преобладает в иконке категории». Взял цвет из нашей палитры типов
(Выход=зелёный, Опасность=красный, Спавн=амбер…).
- **Почему:** палитра И ЕСТЬ канонический цвет категории; попиксельно тянуть доминанту из svg —
  оверкилл с тем же результатом. Если конкретный оттенок будет мимо — поправлю точечно per-категория.

## 7. «Скрыть» синканный — без UI-развскрытия (одностороннее в MVP)
Скрытый синканный маркер исчезает, а hidden-оверрайд не рендерится → кликнуть, чтобы вернуть, нельзя.
- **Почему:** MVP. Развскрытие требует отдельного admin-вида «показать скрытые» (или снести строку в БД).
  Заведём, если понадобится.

## 8. Ф6 (Completed-превью пина, полировка 1:1) — не делал
Морфинг иконки по связи (Ф4) в резолвере есть; но пиксель-полировка карточек и Completed-Marker
фреймов — это Ф6, к нему не приступал (опционально, ждёт твоего слова).
