# Витрина тарифов: закрыть «Платежи» и «PRO-статус» в Аккаунт-центре

## Цель
Тариф перестаёт быть надписью «Не настроено». Пользователь видит, **что он купил и что купит**, а V4DYA меняет состав тарифа **из админки без деплоя** — потому что витрина считается из той же матрицы гейтов, по которой работает пейвол.

## Решения грила (V4DYA, 06.09)

Первый заход дал 4 решения, грил добавил ещё 3 и снял 2 «развилки» фактами из кода.

1. **Состав тарифа — гибрид.** Основа выводится из `feature_gates`, editorial-перки из `tiers.perks` кладутся сверху. Иначе витрина врёт: гейт поменяли — маркетинговый текст остался старым.
2. **«ИЗМЕНИТЬ» ведёт на полноценный экран сравнения**; кнопка оплаты неактивна с честной подписью. UI верстаем сейчас — на E5 останется вкрутить адаптер, а не рисовать.
3. **Публичная `/pricing`** — теми же карточками, что в кабинете.
4. **Оплата (адаптер ЮKassa) — вне задачи**, отдельным E5.
5. **Витрина выходит переключателем в админке, не деплоем.** Выключен → `/pricing` отдаёт 404. Причина: `/legal/offer` сейчас `draft: true` со штампом «не имеет юридической силы», а раздел «2. Стоимость и порядок оплаты» — пустая рыба. Публиковать цену раньше оферты нельзя, но и держать готовый код в ящике до E5 незачем.
6. **Флаг один — на все цены.** Выключен → `/pricing` 404, а в кабинете виден **состав** тарифов без цифр («цена — скоро»). Включён → цены везде. Запуск атомарный: ни одного места, где цена утекла раньше оферты. Полумеры вида «в кабинете можно, публично нельзя» отвергнуты — регистрация открытая, скриншот уйдёт в чаты за час.
7. **Запуск на ДВУХ тирах.** Грил вскрыл: в `FEATURE_MIN_TIER` **8 фич на «Оперативнике» и ровно 2 на «Ветеране»** — витрина обнажила бы карточку из двух строк за +250 ₽. Раньше это было незаметно, потому что состав тарифа нигде не отрисован. «Ветеран» архивируется и вернётся **новым** содержимым. Тиры живут в БД → третий добавляется формой в админке, без деплоя.
8. **Осиротевшие ключи опускаются на `operative`.** `advanced_analytics` и `early_access` указывали на ранг, которого после архивации никто не достигнет — две фичи заперлись бы навсегда. Вариант «отключить гейты» отвергнут: `enabled: false` в `resolve.ts:216` → `{ ok: true }`, то есть фича открывается **всем бесплатно**, а потом её пришлось бы отбирать. Никогда не запирать уже отданное.
9. **Цена — 199 ₽/мес, без изменений.** Набор фич фактически не вырос, поменялась упаковка. На запуске важнее объём конверсий и доверие, чем ARPU; рекуррента ещё нет → поднять позже дёшево и без обиженных старых подписчиков.
10. **Годовой тариф — после запуска.** Механика срока уже есть (`setUserTier({months})` → `make_interval`), не хватает только второй цены в `tiers`. Но годовая предоплата — обязательство на год при недостроенном сервисе и ненаписанной политике возврата.
11. **Тон — сухой тактический брифинг.** «Доступ по подписке „Оперативник“. Ядро сайта остаётся бесплатным.» Без восклицаний и продающего нажима: аудитория хардкор-шутеров его остро чует.

Отдельная таблица `app_settings` отвергнута как схема ради одного булева; ENV — как требующая передеплоя (противоречит решению 5).

## Модель витрины — ядро задачи

Чистая функция, доменная логика вне JSX (§4.7). Вход — снимки, которые движок гейтинга **уже кеширует**: `getTiers()` + `getGateMap()` из `src/lib/gating/resolve.ts`.

**Состав тира T (rank > 0)** = гейты, у которых `min_tier` указывает ровно на T:

```
own(T) = { g ∈ gates | g.enabled && rank(g.min_tier) === rank(T) && g.behavior !== 'hide' }
```

- `enabled === false` — гейт не применяется (фича открыта всем), из витрины вон.
- `behavior === 'hide'` — фичу намеренно прячут от неплательщика; рекламировать то, что скрываем, нечестно и палит скрытое.
- **Каскад, а не повтор:** карточка ранга N печатает свои строки + одну «Всё из ‹имя тира N−1›». Актуально с возвращением третьего тира; на запуске двух — вырождается.
- **У `free` авто-списка НЕТ.** Секционные гейты по умолчанию `free` — авто-вывод дал бы сто строк. Карточка «Боец» — только editorial `perks` (там и живёт «База-6»).
- **Подписи:** фичи — `FEATURE_LABELS`, секции — заголовок узла из `HEADER_DICTIONARY`. Сейчас лейблы задвоены (`FEATURE_LABELS` в `gate-registry.ts` vs `FEATURE_META` в `admin/billing/gate-tree.ts`) — свести в один резолвер `gateLabel(key)`, чтобы админка и витрина не разъезжались (§4.10).
- **Два режима карточки:** с ценой и без (флаг витрины, решение 6). Режим без цены показывает состав и подпись «цена — скоро».

**Побочный выигрыш:** `/pricing` становится инструментом аудита матрицы — «массовая расстановка порогов по 31 фиче» из родительской заметки перестаёт быть слепой. Перекос 8/2 нашёлся именно так.

## Гочи

- **Архивный тир — не «нет тира».** Юзер может сидеть на `archived` тире (дедовщина после переоценки — а после Ш0 это ещё и `veteran`). Из витрины архивные скрыты, но `tierMeta`/карточка обязаны отрисовать его имя в кабинете. Не сужать `TierId` до базовых слагов — он открытый `string`, и `getSubscription` это уже уважает.
- **Игровые тиры.** У `tiers` есть `game_id` (задел per-game). `/pricing` v1 — только портальные (`null`), иначе список поедет.
- **Кеш.** `getTiers`/`getGateMap` — `unstable_cache`, `revalidate: 3600`. Своей выборкой мимо них витрина разъедется с пейволом и перестанет реагировать на `invalidateGating()`.
- **Пустая БД → дефолты из кода.** `resolve.ts` fail-safe: витрина обязана пережить пустые `tiers` (покажет `TIERS` из `subscription-tiers.ts`), а не упасть.
- **`/pricing` без `force-dynamic` уронит деплой Coolify** — статический роут, читающий БД (§4.13).
- **Обратная семантика `enabled`** — см. Ш1. Единственное место, где мы читаем гейт-строку в обход `requireTier`; без комментария это выглядит как баг.
