# Карты: переключение этажей хоткеями + тултип

**Статус:** ✅ сделано (2026-06-29) — через Claude Code, ревью UI в VS Code.
**Затрагивает:** `MapFrame.tsx` · `MapFloorSwitcher.tsx` · `eft-map-config.ts`

## Контекст
Сейчас этажи переключаются только кликом по вертикальной колонке кнопок (`MapFloorSwitcher.tsx`, top-left). `MapFrame` уже держит клавиатурные хендлеры (Ctrl+F, Esc) — добавить туда переключение уровней.

## Спека
- **Биндинги** (переключение активного этажа вверх/вниз):
  - `Alt (левый)` + колёсико мыши
  - стрелки ↑ / ↓
  - клавиши `+` / `−` (и NumPad, и основная клавиатура)
- **Онбординг-тултип** при наведении на блок переключателя этажей: текст «Используй сочетание клавиш чтобы переключать этажи, это удобно».
- Границы: не уходить за пределы доступных этажей (clamp по `floors.length`); не конфликтовать с зумом Leaflet (Alt-модификатор как раз разводит с обычным колесом-зумом).

## Вывод
Решено: реализовать по спеке выше. Развилок нет. UI/поведение → **REVIEW в VS Code** перед коммитом. → Claude Code (после [[maps-ui-fixes]]).

## Исполнено (2026-06-29)
Через Claude Code, ревью UI в VS Code (V4DYA: «всё отлично»). По спеке + находки сверх неё:
- **MapFrame.tsx** — `stepFloor(dir)` шагает по визуальному стеку этажей (`orderFloorsByLevel`), не по индексу: `floors = [ground, ...layers]` не отсортирован по уровню (у Customs подвал раньше 2-го этажа). Clamp по краям, без зацикливания.
- Хоткеи `↑↓` / `+−` (осн. + NumPad); гарды: только мульти-этаж, не в инпуте, игнор `Ctrl/Meta/Alt` (чтобы не ломать зум браузера и `Ctrl+F`).
- `Alt`+колесо — в **capture-фазе + non-passive**: перехват до зума Leaflet (без Alt колесо зумит как прежде).
- **MapFloorSwitcher.tsx** — онбординг-тултип. Текст по ревью: «Используй ALT + Scroll, чтобы переключать этажи.»
- **eft-map-config.ts** (сверх «Затрагивает») — `floorLevel` / `orderFloorsByLevel` вынесены как одна точка правды (DRY; раньше `floorLevel` дублировался в свитчере).
- Проверка: `tsc --noEmit` — 0 ошибок · стиль-долг NIGHTFALL синхронен.
