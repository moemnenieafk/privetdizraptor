# Позиция маркера по скриншоту EFT

## Цель
Куратор жмёт **«Позиция по Скриншоту»**, выбирает PNG-скрин из рейда — портал парсит координаты игрока из имени файла, ставит черновик метки в этой точке на **текущей** карте (нужный этаж по высоте, сам скрин прикреплён первым фото) и открывает наш editorial-визард.

## Границы
- **В scope:** кнопка + файл-пикер + парс имени + единый резолвер позиции (SVG-карты сразу, тайловые — через калибровку) + префилл визарда (позиция/этаж/скрин) + `worldTransform` Завода как **пробная** калибровка.
- **НЕ трогаем:** CRS/тайловый пайплайн, трекер игрока (`useEftTracker`), автодетект карты по координатам (осознанно вне scope — вариант А: только текущая карта), интерактивный калибратор (позже, когда тайловых карт станет много).

## Контекст (готовая инфра)
- `src/lib/eft-screenshot.ts` — `parseScreenshotName(name)` → `{x,y,z,yaw}`, `floorIndexForHeight(floors,y)` → индекс этажа. **Переиспользуем как есть.**
- `MapViewerClient.tsx` — постановка черновика: `addMode`→клик→`setPendingMarker({x,z,floor,...})`→`EditorialMarkerCard`. Резолвер позиции встраиваем рядом.
- Editorial-метки: **SVG-карты хранят метки в игровых координатах** (CRS проецирует), **тайловые (Завод) — в canvas-space 0–256** (клик = `latlng` в CRS.Simple). Отсюда два пути резолвера.
- Координатный readout снизу-справа (X=lng, Y=lat) — им куратор снимает canvas-координаты для калибровки.
- Гоча: у Завода `transform:[1,0,1,0]` — плейсхолдер, **не** game→canvas. Трекер/heat на Заводе сейчас тоже врут (общий корень — нет калибровки).

## Поведение
1. Кнопка **`MapPinned`** (lucide) — слева от кнопки добавления маркера в editorial-тулбаре; видна при `canEditMarkers`.
2. Клик → `<input type="file" accept="image/png">`. Берём выбранный файл (имя → координаты, байты → фото метки).
3. `parseScreenshotName(file.name)`. Не распарсилось (скрин не из рейда / переименован) → предупреждение, стоп.
4. **Резолвер позиции по типу карты:**
   - тайловая + есть `worldTransform` → `pos = worldTransform(x,z)` (canvas 0–256);
   - SVG с `transform` → напрямую `{x: pose.x, z: pose.z}`;
   - тайловая без `worldTransform` → кнопка **задизейблена**, тултип «нет калибровки координат».
5. `pos` вне `config.bounds` → предупреждение «скрин не с этой локации» (вариант А: только текущая карта), метку **не** ставим.
6. Иначе `setPendingMarker({ x, z: pos, floor: floorIndexForHeight(floors, pose.y), screenshots: [<staged файл>], type:'poi', ... })` → открывается визард. Скрин заливается в Storage при сохранении метки (как обычные фото).

## Калибровка Завода (`worldTransform`, проба)
- Аффин 2×3 game→canvas: `canvasX = a·x + b·z + c`, `canvasY = d·x + e·z + f`. Шесть коэффициентов ловят масштаб, сдвиг, **поворот и зеркало** осей.
- Решаю методом наименьших квадратов из **≥3** опорных точек (3 — точное решение, больше — усреднение ошибки). Утилита `src/lib/map-calibration.ts` (`solveAffine(points) → [a..f]`, `applyAffine`).
- Значение кладётся в `EFT_MAP_CONFIG.factory.worldTransform`. Тип: `worldTransform?: [number,number,number,number,number,number]`.
- После калибровки — вывести контрольную ошибку (px) по каждой точке; >~2–3 клетки холста = нужны точнее/больше точек.

## 🎮 Твои действия на Заводе (метод «маркеры-опоры» — точнее ручного)
Идея V4DYA: не переписывать числа руками, а поставить POI-метки прямо на арт и назвать их именами скринов — я читаю метки из БД, парсю координаты из имени, `marker.x/z` беру как canvas. Точнее (ставишь прицельно с зумом) и данные уже в системе.

1. **Зайди в рейд на Заводе** — можно **офлайн** (быстрее). Координаты пишутся в имя скрина **только в рейде**, не в меню.
2. Папка скринов `…/Escape from Tarkov/Screenshots/`, клавиша **PrtScn**.
3. Выбери **3+ приметных места**, однозначно узнаваемых и в игре, и на арте (угол здания, центр ворот, характерный станок, люк). **Разнеси пошире**; полезно на **разных этажах** (проверка авто-этажа).
4. На каждой точке встань **ровно на ориентир** (координаты от ног игрока, не от прицела) → **скрин**.
5. Открой `/eft/maps/factory`, поставь **POI-метку точно на то же место** (зумни для точности) и **назови её именем файла скрина** — скопируй имя PNG целиком, напр.:
   `2024-05-01[19-42]_-146.3, 5.2, -217.8_0.0,0.6,0.0,0.8_11.22 (0).png`
   (важно сохранить кусок `_x, y, z_qx,qy,qz,qw_` — из него парсятся координаты). Сохрани метку. Повтори для всех точек.
6. Напиши «готово». Я запускаю `npx tsx scripts/calibrate-factory.ts` → он берёт метки с именем-скрином, решает аффин, печатает `worldTransform` + невязку по каждой точке (выбросы — если метка сдвинута). Вписываю `worldTransform` в конфиг Завода.
7. Метки-опоры после калибровки можно удалить (они не реальные POI) — или оставить как reference.

*(Альтернатива без БД — прислать табличку `gameX,gameZ,canvasX,canvasY`, где canvas снят курсор-readout'ом; но метод с маркерами точнее и без ручного переписывания.)*

## Критерий готовности (детерминированный)
- [ ] `tsc` чисто / eslint без новых.
- [ ] На **SVG-карте** (напр. Таможня): выбор скрина из таможенного рейда → метка встаёт в верную точку, визард открыт, скрин прикреплён.
- [ ] Кнопка **задизейблена** на тайловой карте без `worldTransform` (тултип виден).
- [ ] После калибровки Завода: скрин с известной точки → метка в неё (глазами по арту), верный этаж по высоте.
- [ ] Скрин не из рейда / чужой карты → предупреждение, метка не ставится.

## Развилки (решены на гриле 2026-08-15)
- Определение карты → **вариант А: текущая карта** (в имени скрина карты нет; автодетект неоднозначен — вне scope).
- Тайловые без game→canvas → **B2: калибруем Завод** (`worldTransform`), проба; тайлы — релизное направление, поэтому вложение оправдано.
- Хранение калибровки → **(a) хардкод в конфиг** из опорных точек (интерактивный калибратор — позже).
- Точек → **3+**, аффин 2×3 least-squares (поворот/зеркало ловятся сами).
- Источник скрина → **(b) файл-пикер** (портативно, без File System Access API).
- Префилл визарда → позиция **+ этаж из `y` + скрин первым фото**.
- Скоуп → **единый резолвер** (SVG сразу, Завод после калибровки, прочие тайловые — дизейбл) + предупреждение о промахе.

## Гарды
- Бюджет: несколько файлов (кнопка+резолвер во вьюере, поле конфига, утилита-солвер, протяжка файла в аплоад скринов карточки). Не рефактор.
- Ручное подтверждение: не требуется (БД/схему не трогаем, метки — существующий флоу). Пуш в main — по твоей команде.
- Блокер Завода: `worldTransform` пишется только после твоих 3 точек; до этого фича живёт на SVG-картах, Завод — дизейбл.
