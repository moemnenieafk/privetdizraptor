# Трекинг: Сюжетные задания (истории)

## Цель
Секция «Сюжетные задания» во вкладке «Трекинг» ([[player-tracking-tab]]): прогресс прохождения сюжетных цепочек/историй (главы прочитано/пройдено, текущая глава, переход к продолжению). Часть платного контура трекинга (PRO).

## Контекст
- Контент сюжеток: статика `src/data/story-quests/*.ts` (`StoryQuestChapter[]`), страницы `/eft/quests/lore-quests` + `/eft/quests/<slug>` (`StoryQuestGuide`).
- **Прогресса сюжетных, похоже, НЕТ** (проверить: useQuestStore трекает только трейдерские id) → вероятно нужен новый лёгкий стор/поле «пройденные главы» + (опц.) облачная колонка. Это отличает домен от side-quests: тут может понадобиться БД-работа (⚠️ db:push — с подтверждением).
- Сюжетки пересекаются с трейдерскими квестами (главы ссылаются на task id?) — сверить структуру StoryQuestChapter.

## Развилки
- Что считать «прогрессом» сюжетки: прочитал главу · выполнил связанные задания · ручная галочка?
- Хранение: расширить `quest_progress` (jsonb-поле) · отдельная таблица · только localStorage?
- UI: полоса прогресса по цепочке + «продолжить с главы N»?

## Гарды
- Если появится облачное хранение → db:push только с ручным «ок». PRO-гейт — общий (см. хаб).

## Развилки — ЗАКРЫТЫ V4DYA (2026-07-09): A1 + B2 + C1

**Устаревшее допущение ноты:** «прогресса сюжеток, похоже, нет». На деле `useStoryProgressStore`
(localStorage `cta-story-progress`) уже существует — `conditionDone` (чеки условий) + `branchChoice`.
«Глава пройдена» не хранится отдельно, а выводится из этих чеков + авто-чек убежища
(логика `stepDone` в `StoryWalkthrough`). Сюжетки НЕ ссылаются на трейдерские task id —
пересечения-зависимости нет.

- **A1 — без облака.** Дайджест-ридер поверх существующего стора. 0 БД, 0 `db:push`, 0 новых полей стора.
- **B2 — «шагов N / всего» на историю + «продолжить с главы N»** (дип-линк на `/eft/quests/<slug>`, страница авто-резюмит на первый незакрытый шаг).
- **C1 — без пинов.** Сетка всех историй с полосами + общий счётчик «историй пройдено» / «шагов пройдено».

## Что сделано
- `src/lib/story-progress.ts` — чистый `computeStoryProgress(story, conditionDone, branchChoice, levels) → { done, total, nextStep }` (логика 1:1 с `stepDone` гайда).
- `src/app/account/TrackingStoryDigest.tsx` — домен «Истории» (близнец `TrackingQuestsDigest`): общий прогресс по шагам + полосы по историям + «Гл. N» / ✓ + `ResetControl` (сброс `conditionDone`/`branchChoice`).
- `src/app/account/TrackingPanel.tsx` — запись домена `story` в `TRACKING_DOMAINS` (после «Задания») + рендер.
