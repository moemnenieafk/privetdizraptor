# Трекинг позиции игрока на карте (по скриншотам EFT)

> [!success] Закрыто 2026-07-08 (ревизия 2026-07-14)
> Проверено в коде: `lib/eft-screenshot.ts`, `store/useTrackingStore.ts`, `features/maps/PlayerTracker.tsx` (File System Access API, вариант A). Остаток: live-калибровка оффсета стрелки на ПК.


**Статус:** ⚪ отложено — идея на будущее, не блокер MVP
**Затрагивает:** [[maps-marker-render]] · `MapViewerClient` · `eft-map-config.ts`
**Источник:** deep research [[deep-research-maptracker-looteditor]] (разбор TarkovMapTracker)

## Контекст
EFT **запекает мировые координаты игрока + кватернион поворота камеры в ИМЯ ФАЙЛА** скриншота
(`…_x, y, z_qx, qy, qz, qw_hash.png` в `Documents/Escape from Tarkov/Screenshots/`). Это не CV —
просто парсинг имени. BattlEye-safe (читаем файл, который игра сама записала; та же категория, что
динамическая карта tarkov.dev). TarkovMapTracker так и работает (десктоп Go, лицензия CC BY-NC-ND —
их код не копируем, техника имени файла свободна).

**Почему нам это дёшево:** мы уже владеем идентичным трансформом проекции (`EFT_MAP_CONFIG`):
`imgX = x*t0+t1; imgY = z*t2+t3` + `coordinateRotation` (значения = tarkov.dev). Спроецировать
игрока = переиспользовать то, что уже рисует маркеры. `y` (высота) → авто-выбор этажа (floor-фильтр есть).

## Варианты
- **A — Браузерный (File System Access API).** Кнопка «Отслеживать позицию» → `showDirectoryPicker()`
  один раз даёт доступ к папке скриншотов → JS каждые ~1-2с читает свежий PNG, парсит имя → трансформ →
  маркер игрока + стрелка (yaw из кватерниона). 100% клиент, без бэкенда, без рантайм-tarkov.dev (§4.11 ок).
- **B — Desktop-companion** (как оригинал). Отдельный мини-апп следит за папкой, шлёт позицию в наш веб
  (localhost/WS). Больше трения установки, зато работает вне Chromium.
- **C — Ручной drag&drop.** Юзер перетаскивает скриншот в карту → разовая точка. Фолбэк для не-Chromium.

## За / Против
| Вариант | За | Против |
|---|---|---|
| **A** | без установки, чисто клиент, переиспользует трансформ+этажи, §4.11 ок | только Chromium; апдейт по нажатию клавиши скрина (не непрерывно) |
| **B** | работает везде | установка .exe, доверие, поддержка десктоп-кода |
| **C** | тривиально, любой браузер | ручной каждый раз, не «трекинг» |

## Вывод
Целевой — **A** (браузерный), с **C** как фолбэк для не-Chromium. Отдельный клиентский компонент поверх
`MapViewerClient`: хук `usePlayerPosition` (dir-handle + poll + парсер имени + quaternion→yaw) + маркер-стрелка.
Труд S-M. Ограничения: апдейт по нажатию игровой клавиши скрина (как оригинал); Factory/Labs — поворот
ненадёжен (known issue источника). **Перед реализацией:** снять 1 реальный скриншот EFT и сверить точные
разделители имени (могут отличаться по версии/локали).

→ Когда возьмём в работу: Claude Code (клиентский хук + компонент). Пока — **отложено**, ждёт приоритизации V4DYA.

## Связанное на будущее

объектов, которых нет в tarkov.dev (контейнеры in-raid). Инструмент авторинга, офлайн-SPT, ручной.
Держим в уме как источник недостающих координат. Детали — [[deep-research-maptracker-looteditor]].
