# Трекинг: Побочные задания (торговцы)

## Цель
Домен «Задания» во вкладке «Трекинг» ([[player-tracking-tab]]): дайджест прогресса трейдерских квестов — вотчлист закреплённых + полосы прогресса по торговцам + Каппа/Смотритель. Гибрид: быстрые действия тут, за деталями — в карту квестов.

## Развилки — ЗАКРЫТЫ V4DYA (2026-07-03, Q&A)
| Развилка | Решение |
|---|---|
| Переключение доменов | **Суб-табы под шапкой игры** (Достижения \| Задания \| Предметы) |
| PRO-гейт | **Пока открыто** — гейт отдельной задачей при появлении оплаты |
| Вотчлист | **Закреплённые (pinned)** — механика `pinnedQuests` уже есть (стор+облако), ноль нового |
| Глубина | **Дайджест + ссылки** в полные разделы (`/eft/questmap`), без дублирования UI |
| Обзор | **Полосы по торговцам** (X/Y, фото + бар; считаем впервые) + **Каппа/Смотритель** бары (токены `--color-kappa`/`--color-lightkeeper`) |
| Карточка pinned | **Мини-карточка с тогглом ✓**: фото торговца, имя, бейджи (Каппа/мин.уровень), `toggleQuest` (выполнение снимает пин — логика стора), кросс-линки `/eft/questmap?quest=` + `/eft/quests/task/` |

## Контекст (факты разведки 2026-07-03)
- Прогресс УЖЕ трекается: `useQuestStore` (`completedQuests`, `pinnedQuests`, `toggleQuest`); облако `quest_progress` + `ProgressSync`. **Ноль новых сторов/БД/API.**
- Данные: `EFT_QUESTS` (`src/data/quests`, статик, **520 задач**): `trader{name,normalizedName,imageLink}`, `kappaRequired`, `lightkeeperRequired`, `minPlayerLevel`.
- Пер-трейдер прогресс (X/Y) НИГДЕ не считается — впервые в этом домене.
- ⚠️ 520 задач в клиентский бандл вкладки не тащим: server-side готовим **лёгкие агрегаты** (questLite-словарь + totals по торговцам + kappa/lk totals) в `account/page.tsx`.

## План
1. `src/lib/tracking-digest.ts` (server-хелпер): из `EFT_QUESTS` → `questLite: Record<id,{name,trader,kappa?,lk?,lvl?}>`, totals по торговцам (+imageLink), kappaTotal/lightkeeperTotal.
2. `account/page.tsx` — прокинуть агрегаты в `AccountCenter` → `TrackingPanel`.
3. `TrackingPanel.tsx` — суб-табы доменов (Достижения | Задания | Предметы); текущий контент достижений → суб-таб «Достижения».
4. Новый `src/app/account/TrackingQuestsDigest.tsx` — вотчлист pinned (мини-карточки с ✓) + полосы торговцев + Каппа/Смотритель + CTA «Карта квестов». mounted-гард, мобилка.
5. `tsc` → приёмка → коммит.

## Критерий готовности
- [x] `tsc` чисто; суб-табы переключаются
- [x] Пины с карты квестов появляются в вотчлисте; ✓ выполняет квест и убирает пин; полосы двигаются
- [x] Цифры по торговцу сходятся со страницей `/eft/quests/<trader>`

## Гарды
- Сторы/БД/API не трогаем — чистая агрегация. Коммит по «ок».
