# Шаринг позиции игрока со сквадом на карте

## Цель
Тиммейты видят живые позиции друг друга на одной интерактивной карте EFT — поверх уже существующего одиночного трекера (`PlayerTracker.tsx`, чтение скриншотов).

## Границы
- **В scope:** Realtime-обмен позициями (Supabase broadcast+presence), UI входа в комнату (код+инвайт-ссылка), правый drawer «Сквад» с ростером, слой меток тиммейтов на карте, кнопка у «Позиции».
- **НЕ трогаем:** схему БД (никаких таблиц/RLS/миграций — фича эфемерная), одиночный трекер (переиспользуем его `pose`), приватные каналы/анти-спуфинг (вынесено в «потом»).

## Контекст
- Файлы: `src/store/useSquadStore.ts` (нов.), `src/components/features/maps/useSquad.ts` (нов., обёртка Realtime-канала), `src/components/features/maps/SquadDrawer.tsx` (нов.), `src/components/features/maps/MapViewerClient.tsx` (кнопка + слой тиммейтов + провод), `src/store/useMapUiStore.ts` (+`squadOpen`).
- Источник позиции: `useTrackingStore.pose` (x,y,z,yaw) + `floorIndexForHeight`. Клиент Supabase: `src/lib/supabase/client.ts`.
- Гочи: broadcast `self:false` (свою точку рисует старый трекер); presence несёт `{nick,color,mapId,mapName,broadcasting}`, broadcast несёт позу; вещать можно только Chromium-десктоп (гейт как у трекера), смотреть — откуда угодно.

## Критерий готовности
- [ ] `tsc` чисто, eslint чисто, смоук зелёный
- [ ] Два клиента с одним кодом видят метки друг друга на одной карте (ручная проверка V4DYA)
- [ ] Presence убирает метку при закрытии вкладки

## Развилки (закрыты грилингом 2026-07-31)
1. Транспорт → **Supabase Realtime** (broadcast+presence; клиент напрямую к Supabase, Vercel-функции не нужны)
2. Данные → **чисто эфемерно**, без БД
3. Комната → **код + ссылка-инвайт**, без логина
4. Идентичность → **ник при входе** (+ авто-цвет; prefill из профиля)
5. Карта-скоуп → **комната по коду**; ростер всех, точки — только своей карты
6. Наблюдатель → **вход и вещание независимы** (presence ≠ broadcast)
7. UI → **кнопка «Сквад» у «Позиции» → правый drawer** в стиле «Легенды»

## Гарды
- Бюджет: 3 новых файла + провод в MapViewerClient/useMapUiStore. Бэкенд не трогаем.
- Ручное подтверждение: не требуется (нет БД/пуша). Пуш в main — по отдельной отмашке V4DYA.
- Free-tier Supabase Realtime: 200 конкурентных подключений, 2M сообщений/мес — с запасом.
- **UI — черновой**: V4DYA доводит фронт после первой рабочей версии.
