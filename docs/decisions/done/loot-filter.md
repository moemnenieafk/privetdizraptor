# Лут-фильтр: выбрал предмет(ы) → подсветка всех спавнов

## Цель
«Где спавнится LEDX/видяха?» — отметил предмет(ы) в поиске → все их точки на карте получают постоянную подсветку (мульти-предмет = объединение).

## Границы
- **В scope:** пин-тоггл на результатах поиска предметов (левый drawer), стор фильтра (эфемерный), оверлей-подсветка позиций на карте.
- **НЕ трогаем:** бэкенд/данные (loose-loot маркеры с позициями уже на клиенте), существующий подлёт (остаётся как быстрый просмотр).

## Контекст (данные готовы)
- Поиск предметов уже группирует маркеры по label с позициями (`groups`), клик → `focus(positions)`.
- Оверлей — как реверс Ключ→Двери: `circleMarker`-кольца, вне LOD/фильтра. Цвет — accent-frago (#00CDAB), отличный от амбера ключей.
- Позиции по label считаются в MapViewerClient из `data.markers` (стор держит только labels — map-независим).

## Развилки (грилинг 2026-08-01)
1. Стиль → **постоянная подсветка-оверлей** (не жёсткий фильтр, не только подлёт).
2. Мульти-предмет → да (Set labels → объединение).
3. Персист → эфемерно (сессия, без localStorage; лут-фильтр — про текущий рейд).

## Критерий готовности
- [ ] `tsc`/eslint чисто, смоук зелёный
- [ ] Отметил предмет в поиске → его спавны подсвечены на карте; несколько → объединение; сброс очищает.

## Гарды
