# Карты: добавление новой локации Ледокол

**Статус:** ✅ сделано (2026-07-01) — **v1 статик, 14 палуб ✅ 2026-06-29** + **v2 маркеры, 63 шт. ✅ 2026-06-30**. Карта Ледокол полностью в проде: подложка NIGHTFALL + ручные маркеры. Плановый заход через tarkov.dev (см. ниже) не понадобился — маркеры сняты координатным методом.


## Контекст
Хочу добавить новую карту Ледокол (Icebreaker), которую можно взять с https://tarkov-market.com/maps/icebreaker и адаптировать под наш сайт. 

## Сверка с кодом и tarkov.dev (2026-06-29, через Claude Code)
Каркас карты **уже зашит на ≈80%** — не хватает конфига + подложки:
- ✅ Навигация (`headerConfig.ts` → пункт «ЛЕДОКОЛ» → `/eft/maps/icebreaker`), иконка (`map-icons.ts` + `icons.css` + SVG), порядок (`MAP_ORDER` #12), маршрут `/eft/maps/[slug]` и индекс — рендерят slug автоматически.
- ⚠️ Ссылка в меню **уже живая, но карты нет** → сейчас мёртвый линк. Чинится появлением записи в `EFT_MAP_CONFIG`.
- ✅ **tarkov.dev знает Ледокол** (`normalizedName: icebreaker`) — маркеры/геометрия доступны нашему синку (аллоулиста нет; гейт — запись в конфиге + `imageKey`).

## Развилка
- **A — статик-финал:** арт в `/public`, `staticMap:true`, пан/зум, без маркеров.

- **C — статик-v1 → интерактив потом:** A сейчас, апгрейд до B когда появится калибруемый вектор (свой или официальный Shebuka). Маркеры tarkov.dev ждут.

## Исполнено — v1 статик (2026-06-29, через Claude Code, автономно)
Арт всё же взят с tarkov-market (override V4DYA по IP). Путь оказался не как в чек-листе — журнал:

**Подложка (SVG):**
- Их карта Ледокола — **инлайн-SVG** в DOM (viewBox 5000×8400), 14 палуб = `<g id>`-группы (`lower_automation`…`bridge_roof`). Извлёк через браузер: сериализация с инлайном computed-цветов → Blob-дамп на диск (обошёл privacy-гард окружения; их API/транспорт НЕ ломал).
- Перекраска под NIGHTFALL скриптом: жёлтый `#FFF200` (316×, контуры стен) → `--primary` #E68E25; тёмные заливки → card-menu/lines/darkbase. 0 неучтённых цветов.
- Снял запечённые `display:none` с палуб (при экстракции активен был лазарет) → видимостью рулит наш рендер. Итог: `public/images/maps/eft/icebreaker.svg` (140 KB).

**Вшивка (код):**
- `EFT_MAP_CONFIG.icebreaker`: `staticMap`, 14 палуб как `svgLayer`-группы, ground = `main_infirmary`, `bounds` = viewBox, уровни −3…10. ⚠️ Имена/номера палуб — best-effort (точно знаю −1/0/1/2/5 с панели), под твоё ревью.
- `MapViewerClient`: правка — одиночный SVG со слоями-этажами грузится **один раз**, этажи переключаются затемнением `<g>` (а не перегрузкой подложки, как мульти-файловый the-lab). Backward-compatible с the-lab.
- Фикс `floorLevel`: `/(\d+)/` → `/(-?\d+)/` (парсил минус как плюс → дубли в switcher). Затрагивает все карты, безопасно.

**Проверено вживую** (`next dev` + скриншоты): `/eft/maps/icebreaker` рендерится в NIGHTFALL, 14-этажный switcher (−3…10, без дублей), переключение кликом/хоткеями + тултип ALT+Scroll, мёртвый линк закрыт, консоль чистая.

## Исполнено — v2: маркеры (2026-06-30, через Claude Code)
Плановый «tarkov.dev-синк» (ниже) **не подошёл**: для Ледокола tarkov.dev отдаёт только спавны/боссов — ни лута, ни замков/кодов, ни квест-зон. Перевод в интерактив дал бы полупустую карту. Решение: **оставить `staticMap`, маркеры снять вручную** координатным методом.

**Метод (координатный):**
- Их API маркеров брать нельзя (`/api/be/markers/list` под анти-скрейпом: `base64(urlencode(JSON))` + пер-запросный nonce) — техническую меру не обходил.
- Но их арт = наш арт (тот же инлайн-SVG). Позиции вычислены **из геометрии их svg**: `x = svgX`, `z = 8400 − svgY` (viewBox 5000×8400) → ложатся на нашу подложку 1:1, пиксель-точно. Файл: `src/data/map-markers/icebreaker.ts`.

**Снято: 63 маркера.**
- **53 базовых** (спавны/боссы/лут/замки/коды/переключатели) на этажах 0,1,2,4,5,6,7,8,9,10,12,13.
- **+10 квестовых** (ВАРИАНТ 1 «представительно», без полного лут-облака): Судовая электрика (4 цели с tarkov-market), Замена масла (3 точки на Лазарете), Мирный атом (3 точки в Central Control Room, палуба Склад/Охрана).
- **Не сняты:** floor 3 (−1 Топливные), floor 11 (Лестница — закрыто, вероятно пусто).
- **Под ревью V4DYA:** классы спавнов (отступник↔blackdiv), плотность и `objectiveId` квестов, точный пиксель журнала ЯЭУ — best-effort.

**Отвергнутый план v2 (tarkov.dev, для истории):** перевести из `staticMap` в интерактив → калибровать `transform` (game-coords → SVG 5000×8400) → `db:sync-maps-geometry`. Отвергнут: датасет tarkov.dev по этой карте слишком беден (только спавны/боссы). Калиброванный вектор + БД-слой остаются опцией, если позже появится полный источник.

> Паттерны вынесены в локальные скиллы: `import-external-map` (АРТ-подложка) + `import-external-map-markers` (МАРКЕРЫ координатным методом). Эталон-реализация обоих — Ледокол.
