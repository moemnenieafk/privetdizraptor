# Раздел «Сезоны» (Прогресс)

## Цель
Новый подраздел `/eft/progress/seasons` с интерактивным конструктором сезонных модификаторов
(перков) — по мотивам tarkov-market/season-1/perks, но удобнее и в нашей дизайн-системе.

## Разведка (сезоны EFT)
- **Season 1 «Kord Breach»**, патч **1.1.0** (июль 2026, день не назван), старт с события **Blackout**.
- Сезонный персонаж **отдельный и добровольный**: уровень 1, пустой схрон, только PvP. Основной
  профиль (стаж, схрон, убежище, «Каппа») не трогается. Минимум **74 дня**, два сезона в год, бесплатно.
- **Модификаторы**: 6 сезонных (навязаны всем) + личные с **бюджетом очков** — старт 0, негативные
  дают, позитивные тратят, баланс ≥ 0. Цифры BSG может подкрутить к релизу.

## Решение: не копировать конкурента, а обойти
tarkov-market — по сути список + счётчик. У нас уже есть инфраструктура, чтобы сделать инструмент:
- **Взаимоисключения** — взаимно гасящие пары (тромбофилия ↔ гемофилия и т.п.) блокируются: их логика
  наша, не запрет BSG (два противоположных эффекта просто вычитаются, очки впустую).
- **Живая валидация** — позитивный перк не по карману гаснет и говорит, скольких очков не хватает.
- **Каскадное снятие** — снял негатив-донор → уходят оплаченные им позитивные, билд не ломается молча.
- **Архетипы-пресеты** (Каппа-раш / Новичок / Тихий ход / Хардкор) — считаются от реальных цен.
- **Шаринг по коду** — весь билд в URL (`/seasons/[slug]/b/[code]`), паттерн `loadouts/b`, БД не нужна.

## Реализовано (v1, коммиты 773d5355, 679ec756, f619fc33)
- `src/data/eft-seasons.ts` — сезон + 36 перков. **Названия и эффекты — свои формулировки**
  (игровые факты BSG, не текст конкурента). Иконки: хелпер `withIcons` проставляет `iconUrl` по
  `id` → `/eft/seasons/kord-breach/{id}.png` (данные DRY, ручной `iconUrl` не перетирается).
- `src/lib/season-points.ts` — чистая математика бюджета/валидации/каскада/кодирования (вне UI).
- `src/store/useSeasonStore.ts` — выбор по сезонам, undo, persist (`cta-seasons`).
- `SeasonPerkBuilder` — липкая панель бюджета, пресеты, три группы карточек, undo/сброс/шаринг.
  `PerkCard` рендерит иконку из `iconUrl` (фолбэк — типизированная плашка со стоимостью), сама
  стоимость перка вынесена в цветной токен рядом с названием (как в оригинальной карточке BSG).
- Страницы: хаб, `/perks`, `/b/[code]`. Пункт меню + хлебные крошки + карточка в хабе Прогресса.

## Иконки (закрыто, коммит 1788a45b)
- **36 заглушек** кадрированы из превью-постера BSG (Season 1), фон вытравлен по яркости →
  прозрачные PNG 96×96 в `public/eft/seasons/kord-breach/{id}.png`.
- Хотлинк/перезалив картинок tarkov-market **отклонён**: чужой трафик + присвоение чужой работы.

## Осталось (пост-MVP)
- **Свой арт вместо заглушек** — маски NIGHTFALL / SVG ИЛИ извлечь из клиента (скилл
  `game-asset-extraction`) после релиза 1.1.0. Кладём `{id}.svg`, правим расширение в `withIcons` —
  разметка не меняется.
- Пост-MVP: сохранение нескольких билдов + облачный синк за paywall (как сборки оружия); каталог
  билдов сообщества; таймер обратного отсчёта, когда BSG назовёт дату.
