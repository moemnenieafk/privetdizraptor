# Единый стиль для мобилки

## Цель
Единый паттерн отображения блоков на мобилке. Навигация-хабы (HubCard) и каталог предметов (EftItemTile) — 1 карточка в ряд вместо двух, как на `design-ui-ux-figma/mobile/hubcard-mobile.jpg`. Дальше — раскатать паттерн на остальные сетки.

## Границы
- **В scope (эта сессия — 2 флагмана + канон):** `globals.css` `.tactical-grid` (все 10 HubCard-хабов), каталог предметов `ItemsCategoryClient` (сетка + скелетон).
- **НЕ трогаем сейчас:** десктоп (≥sm без изменений); длинный хвост прочих сеток (ачивки / торговцы / боссы / хайдаут / бартеры / подсетки категорий `minmax(160px)`) — отдельными проходами по канону; мёртвый `ItemsViewSwitcher`.

## Вывод (развилки закрыты с V4DYA, 2026-07-01)
- **Охват:** сначала 2 флагмана + зафиксировать канон, потом раскатка на хвост.
- **Плитка предмета** на 1/ряд — НЕ растягивать: фиксированный размер как на десктопе (`max-w-64` = 256px), по центру.
- **Брейкпоинт:** 1 колонка только на телефонах (<640px / `max-sm`); с `sm` — многоколоночно как сейчас.

## Канон мобильной сетки
- **Телефон (<640px):** 1 карточка в ряд.
  - HubCard — full-width (по макету).
  - EftItemTile — фикс. размер (256px), центрируется.
- **≥sm:** прежний многоколоночный рамп (не трогаем).

## Критерий готовности
- [x] `tsc` чисто
- [x] визуал <640px: хабы 1/ряд full-width; каталог 1/ряд карточкой десктоп-размера по центру
- [x] ≥sm без изменений

## Исполнено (2026-07-01) — код готов, ждёт визуальной приёмки
- **`globals.css` `.tactical-grid`** — база `repeat(2)` → `repeat(1)`, добавлен шаг `@media (min-width:640px) → repeat(2)`. Рамп: 1 (телефон) → 2 (sm) → 2 (md, `col-span-2`) → 3 (xl). Чинит все 10 хабов разом (eft, progress + подстраницы, quests side/lore, gamesetting, videos, hideout/modules, loadouts).
- **`ItemsCategoryClient`** — сетка каталога и скелетон: `grid-cols-2 md:3 xl:4` → `grid-cols-1 sm:2 md:3 xl:4` + `max-sm:justify-items-center [&>*]:max-sm:max-w-64` (плитка 256px по центру на телефоне, не растянута). Пагинация (`slice(0,visibleCount)`) не виртуализована → правка чисто CSS.
- **Не тронуто:** десктоп ≥sm; `ItemsViewSwitcher` (мёртвый код); прочие сетки — ждут раскатки.
