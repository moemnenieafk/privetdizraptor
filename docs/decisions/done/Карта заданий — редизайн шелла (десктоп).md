Шелл Карт переиспользуем (разведка кода 2026-08-06):

- `MapSearchDrawer` (`w-87`=348px, `absolute top-0 left-0 z-540`, backdrop-blur) — паттерн левого дровера.

- Канвас у Карт — Leaflet; у нас свой `QuestMapViewport` — **движок канваса наш, остаётся**.

## Решения поэлементно

### A. Трейдер-селектор
- Центр-**пилюля** (портрет + имя + твой УЛ) → **дропдаун** (`NavDropdown` 536px, 11 торговцев, у каждого твой УЛ). Ряд из 11 портретов уходит.
- Пункт **«Все»** = кросс-трейдер режим.
  - «Все» + Каппа/Смотритель/поиск/карта → подграф-куллинг (переиспус `computeMinSubgraph`/`filterKappa`/`filterLK` — уже в коде).
  - «Все» **без** фильтра → **гейт**: лёгкая подсказка «выбери путь/фильтр». Рендер 510 нод НЕ происходит никогда.
- **Кламп зума-аута**: поднять `minZoom` вьюпорта до пред-лагового порога (подобрать эмпирически в браузере; старт — фикс под самый тяжёлый куллед-кейс, адаптив при нужде).
- «Показать всех через дезселект» уходит — торговец всегда ровно один (кроме явного «Все»).

### B. УЛ-табы I / II / III / IV
- Независимые **тоглы видимости**, по умолчанию все 4 включены (= канвас как сейчас).
- `enabledTiers: Set<number>` (default `{1,2,3,4}`) в фильтр: квест виден, если `ulTier ∈ enabledTiers`; заголовки-полки и пунктиры куллятся тем же набором; зазоры чинит существующий замер-рефлоу.
- Нельзя выключить все 4 (минимум 1). Тоглы **глобальны** (меж торговцами).

### C. Верхняя панель (инженерка Клода)
Quest-бар по паттерну `MapTopBar` (h-14): поиск-иконка слева (→ левый дровер) · центр = два **стат-пилюля** + трейдер-пилюля + ряд УЛ-тоглов под ней · фуллскрин справа. Стат-пилюли (7/257, 7/128) = существующие метрики (`kappaTotal`/`lkTotal`/бартеры), смапить из кода.

### D. Нижняя панель (инженерка Клода)
Иконки карт (переезд из верхней панели вниз, по центру) · прогресс слева · импорт/экспорт/сброс справа.
- Фильтр карт в «один торговец» = **строго внутри торговца** (готово `0b21ecc5` ✅).
- Фильтр карт в «Все» = кросс-трейдер («что качать на этой локации у всех»).

### E. Левый дровер «ПОИСК ПО ЗАДАНИЮ» (348px, паттерн `MapSearchDrawer`)
- **Текст-поиск по 4 полям** (индекс): (1) название квеста · (2) предметы-цели (найти/сдать) · (3) предметы-награды · (4) **предметы из открываемых квестом бартеров/крафтов**. Мульти-поиск = ИЛИ.
- Чипы (ВСЕ / СЮЖЕТ / Каппа% / УЛ%) + ряд портретов = фильтры списка (не текст-термины). Каппа%/УЛ% → существующие `filterKappa`/`filterLK`.
- Поиск **глобальный** (по всем торговцам).
- **Клик по результату** → сменить торговца на канвасе + перелёт к ноде + открыть правый `QuestDrawer`. Левый на широком остаётся, на <1440 авто-закрывается (правило `useMapUiStore`).
- Кейс-эталон: «5.56» → квест, открывающий бартер/крафт на этот патрон.

### F. Правый дровер «Подробности выполнения задания»
- **Переиспус `QuestDrawer`/`QuestDetail`** как есть (уже Figma-шелл: `right-0 w-87` слайд).
- Единственная правка — **награды крупно** (блок наград в `QuestDetail` под макет).
- Открывается кликом по карточке (существующий `selectedTask`) и по результату поиска.

## ⚠️ Дата-риск (единственный)
Поиск-поле (4) «открываемые предметы»: **бартеры есть** (`bartersByQuest[questId]`) → кейс 5.56 через бартер закрыт. **Крафты** — проверить связь «квест→крафт» в зеркале; если нет, а нужна — отдельный синк (§4.11), за рамками десктоп-прохода.

## Вне объёма этого прохода
Мобилка (следующий проход, паттерны Карт + `cta-mobile`) · настоящий обзор «все торговцы разом» (нужна виртуализация вьюпорта).

## Порядок сборки
1. Хром-каркас: верхний/нижний бары + трейдер-пилюля (переезд контролов).
2. Дропдаун (`NavDropdown`) + режим «Все» + гейт + кламп зума.
3. УЛ-тоглы (`enabledTiers`).
4. Левый поиск (`MapSearchDrawer`-паттерн) + индекс наград + глобальный поиск + склейка результат→канвас→правый дровер.
5. Награды крупно в `QuestDetail`.

## Верификация (каждый шаг)
`tsc`=0 · in-browser скриншот + DOM-проверка (число нод, 0 наслоений сохраняется, куллинг работает) · клик-through новых контролов через DOM-селекторы.
