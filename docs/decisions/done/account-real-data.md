# AccountCenter — реальные данные

**Статус:** ✅ сделано 2026-06-29 — соцсети + стата/«участник с» + живой сброс прогресса. Цель «реальные данные» достигнута; 2FA/биллинг остаются честными плейсхолдерами «не настроено» (это небустроенные ФИЧИ, не фейк-данные → отдельный роадмап).
**Затрагивает:** [[supabase-jwt-fix]]

## Контекст
В `AccountCenter` захардкожены даты активности (`10.06.2026 15:10` и т.п.) и соц-привязки. Нужно завести на реальные данные.

## Вопросы
- Откуда брать активность: события из БД (`quest_progress`, `barter_progress`), `last_seen` в `profiles`?
- Соц-привязки: реальный OAuth (Twitch/YouTube/Discord) или поля в профиле, заполняемые вручную?
- Зависит от [[supabase-jwt-fix]] — аккаунт-фичи всё равно упираются в JWT-блокер.

## Вывод (эпик, по слайсам)
JWT-блокер снят архитектурно ([[supabase-jwt-fix]]) — аккаунт-фичи идут через Drizzle/service-role, не client-RLS.

**Решения по развилкам:**
- Соц-привязки — **ручные поля** (не OAuth): юзер вводит хендлы. OAuth — отдельный большой эпик на потом.
- Активность — из реальных данных (`profiles.createdAt`, `updatedAt` прогресса), без отдельного activity-лога. (Слайс 2.)

**Слайс 1 — соцсети ✅** (2026-06-29, `61c51db`): `profiles` +4 колонки (`account-social.sql`), `getMe`+`socials`, `PUT /api/account/social` (сессия + Drizzle owner-роль), под-вкладка «Связанные аккаунты» (`SocialView`), рендер из `me.socials`. Проверено: роут 401-гард, `/account` 307 (не 500). Ручной смоук под сессией — за V4DYA.

**Слайс 2 — реальные данные ✅** (2026-06-29, `b0582d5`): «Участник с» (`createdAt`) + «Статистика» (квестов/бартеров из progress-таблиц, SQL-агрегация `jsonb_array_length`). Фейк-даты небустроенных фич (пароль/2FA/тариф) → честные плейсхолдеры «—»/«Не настроено». (Стата из бывшего слайса 3 сделана здесь.) Проверено: даты `10.06.2026` убраны, `/account` 307, `getAccountStats` в try/catch (не 500).

**Слайс 3 — финиш ✅** (2026-06-29, `e364692`): «Сброс прогресса ЧВК» был **мёртвой кнопкой** — теперь живой: `POST /api/account/reset-progress` (сессия + Drizzle owner-роль, `DELETE` из quest/barter/player_profiles; убежище — только localStorage) + `GameResetCard` (2-кликовый confirm → route → чистит 4 localStorage-стора → reload). Проверено: route 401-гард. `GAMES` оказался no-op (мок уже = EFT, в `games` только EFT) → не трогали.

**Вне этого эпика (отдельные фичи):**
- 2FA, биллинг/подписка — построить сами фичи; тогда их статусы/даты оживут (сейчас честное «не настроено»).
