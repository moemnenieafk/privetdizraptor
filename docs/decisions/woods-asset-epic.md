# Эпик: Лес — библиотека объектов автономно

Задача V4DYA (ночная, автономно): по исходнику Леса **z6** (`D:\Games\raster\woods\woods-main_0.16-z6.png`,
16174×16384) — распознать ключевые объекты, нарезать их в библиотеку, и для верхних ~8 сделать
флэт-векторизацию в растре (Nano Banana через ProxyAPI) + трассировку vtracer. Сложить в удобное место.

## Пайплайн (3 фазы, фоновый workflow)
1. **Identify+Cut** (16 регионов z6, параллельно, БЕСПЛАТНО): агент смотрит регион-обзор
   (`.tmp-woods/regions/rXcY.png`), находит ключевые объекты (строения, лагеря, бункер, мосты,
   вышки, техника, штабеля брёвен, скальные ориентиры, чекпойнты), считает координаты в z6 по
   смещению региона (`.tmp-woods/offsets.json`), режет из z6 → `map-exports/OBJECTS-MAPS/cut/woods/{категория}/{slug}.png`,
   пишет `.tmp-woods/objects/rXcY.json`.
2. **Generate+Trace** (ТОП-N, КАП=8, ПЛАТНО): для лучших объектов — Nano Banana flat
   (`gemini-3-pro-image` через ProxyAPI, image-to-image по кропу, маджента-кей) → `gen/woods/{slug}.png`,
   затем vtracer → `gen/woods/svg/{slug}.svg`. Стоп при 402 (баланс).
3. **Assemble**: `map-exports/OBJECTS-MAPS/gen/woods/MANIFEST.md` + контакт-лист `_contact.png`.

## Рамки (осознанно)
- **Кап расхода: ≤8 платных генераций** (~320–560 ₽), стоп на 402. Бесплатная часть — полная.
- Новый чат не создаётся — прогон автономный фоновый в текущей сессии.
- Возможен обрыв на лимите сессии → манифест фиксирует сделанное, прогон идемпотентен (докрутить резюмом).

## Результат (утром)
- `cut/woods/` — нарезанная библиотека ключевых объектов Леса (то, что раньше делалось руками днями).
- `gen/woods/` — до 8 флэт-растров + SVG эталонных объектов.
- MANIFEST.md — что найдено/нарезано/сгенерировано + потраченный бюджет.

## Грилл 2026-09-02 (утро) — решения Фазы 2

Ночью Фаза 1 закрылась полностью (123/123), Фаза 2 успела 2 генерации (ангары, самолёт) на
1024px без анкера/палитры → трасса 116/834 цветов — непригодно. Сессия оборвалась. Грилл:

1. **Режим — канон, не ширина.** Оставшиеся 6 генераций идут по `CTA-MAP-OBJECTS-vector-prompts.md`
   (TYPE A, стиль-анкер вторым вложением, `{PALETTE}` триадами, vtracer palette-lock).
2. **Палитра — единый канон.** `FACTORY_PALETTE` (20 семейств × sh/def/hi = 60) перенесена
   из `feat/cta-mapper` в main → `src/lib/mapper/palette.ts`, + семейство **`gravel-sand`**
   (`#5E5A47/#928E73/#BFB99A`, от Shebuka-песка; OKLab до swamp 0.019 → в группу коллизий).
   Проверено по Figma: земля Таможни — растр (94 тыс. оттенков, не источник); зелёный грузовик
   и металл Завода уже сидят на триадах `veh-khaki`/`rust`. Цвета маркеров
   (`MARKER_TYPE_COLOR`, слой `*-overlay` = 1096 иконок) в палитре отсутствуют; риск-соседи:
   `container #9A8866 ↔ wood #A18265` (дист. 17) — оставлено, маркер лежит поверх иконкой.
   `brick` не заводим до первого кирпичного объекта.
3. **Растительность — штампы + скаттер, без биллинга.** `gen/vegetation/` уже содержит хвою
   lg/md, лиственные, 3 куста (4 цвета, 8–18 путей). Лес = скаттер 1–3 штампов по маске
   плотности из исходника. Следующий шаг после эпика, $0.
4. **Камни — вариант B.** Центральный массив (`r1c1-central-rock-massif`, 1897×1542) —
   уникальный ландмарк, генерится отдельно. Россыпь (~50 нарезок) — 2 штампа-валуна скаттером.
5. **Анкер = малый валун** (`r2c0-solitary-boulder-east`), не отдельный расход. v1 дал
   «камуфляж» мха (325 путей) → перекрут с «one flat tone, no mottling» → v2 чистый,
   полоска фото-травы снизу срезана маджентой офлайн → 43 пути. Утверждён V4DYA.
6. **Разрешение 2K** (≈$0.13/выход вместо $0.24 за 4K) — после трассы разницы нет.
7. **Материалы:** валуны `rock+soil`; массив `rock+soil+foliage+gravel-sand`;
   sawmill-main-building `rust+concrete+wood`; hilltop-settlement `cnt-green+wood+dirt`;
   large-brown-hall `wood+rust+dirt`. Нейтрали `concrete+rubber` + контур `#0D0D0E` — всегда.
8. **Ночные ангары/самолёт** не перегоняем — только бесплатная перетрасса против сабсетов.
   Трасс-пресет после замера на 2K: `filterSpeckle 24, cornerThreshold 70, lengthThreshold 6`
   (fine=364 путей → mid=68 на анкере).

Скрипт: `scripts/woods-gen.mts` (`npx tsx`, идемпотентен, стоп на 429/402, лог
`.tmp-woods/gen-log.json`).

## Итог прогона 2026-09-02 (день)

- **Сгенерировано 7/8:** boulder-sm (анкер), boulder-lg, central-rock-massif, sawmill-main-building,
  hilltop-settlement + ночные hangars/plane (перетрасса). `large-brown-hall` не влез в кап 6
  (слот съел перекрут анкера v1→v2). Все SVG palette-locked, 43–719 путей.
- **ГОЧА ProxyAPI:** `402 Insufficient balance` при живом балансе = **слишком тяжёлый payload**
  (кроп 7 МБ PNG / анкер 2 МБ → base64 ×1.33). Лечится ужатием вложений: кроп ≤1024 px JPEG q90,
  анкер ≤1024 px PNG (`ANCHOR_PX`). Проверено пробами: 1K/2K без картинок → 200, с тяжёлыми → 402.
- **ГОЧА модели:** дорисовывает снизу ленту исходного кропа (земля/трава). Авточистка `cleanStrip`:
  ряд = полоса, если >90 % ширины не-маджента (объект всегда с полями) — порог 55 % срезал объекты.
- **Промах камеры:** `hilltop-settlement` вышел в 3/4-перспективе (домики «изометрией»), массив
  тоже ближе к 3/4. Для построек в SUBJECT добавлять «seen from directly above: only roofs visible».
- Скаттер штампов (валуны + растительность) — следующий шаг, $0.
