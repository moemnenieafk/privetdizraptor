# Экономика очков ЦТА — XP-активность, Карма, уровни, штрафы, подсказки

Детализация прокачки поверх принятого каркаса (`progression-system.md`, `computeStanding`, `useBehaviorStore`,
`karma_events`). **Не изобретаем — расширяем.** Числа ниже — черновик (анкеры из существующих весов), тюнит V4DYA.

## 6 решений грила
1. **Две валюты.** `XP-активность` — КЛИЕНТ, мягкая (клики/фичи → персонализация + подсказки + XP-сигнал standing; геймится, но влияет лишь на СВОИ подсказки). `Карма` — СЕРВЕР, авторитетная (ко-оп рейды, штрафы, траст-гейты).
2. **XP — гибрид:** мелкий XP за визит-раздела (с затуханием — `behaviorStore`, ферма бессмысленна) + жирные бонусы за discovery (первое использование фичи) и завершённые флоу.
3. **Уровни:** пер-архетип под-трек (у каждого архетипа своя лестница I→V по глубине в его доменных фичах) + заголовочный ранг `STANDING_RANKS` (ширина по порталу) сверху.
4. **Ко-оп рейд:** взаимное подтверждение сессии — мэтчинг создаёт сессию (оба приняли) → после рейда оба подтверждают + оценивают → карма обоим. Соло-фарм невозможен, игровое API не нужно.
5. **Штрафы:** карма-штраф + траст-лок (мягко, без банов). Падение кармы роняет ранг и закрывает траст-функции (мэтчинг/UGC ниже тира). Ложный репорт стоит репортёру (асимметрия).
6. **Подсказки:** пробелы открытия + релевантность архетипа (`ARCHETYPE_FEATURES`) — предлагаем НЕтронутые фичи; + всплывают анлоки нового ранга при достижении.

## XP-активность (КЛИЕНТ — черновик значений; анкер: computeStanding weights)
| Действие | XP | Тип |
|---|---|---|
| Визит раздела (за домен, затухает) | +1 | активность |
| Первое использование фичи (discovery) | +15 | майлстоун, раз/фичу |
| Загрузил profile.json | +30 | флоу |
| Собрал лоадаут / решил Gunsmith | +20 | флоу |
| Добавил квест в трекер / отследил | +10 | флоу |
| Прошёл этап «Пути Новобранца» | +12 | флоу (уже: tutorialStep) |
| Побил рекорд аркады | √×1.2 | уже: arcadeRoot |
| Достижение засчитано | +8 | уже: achievement |
**Разделение потоков (архетип-множитель):**
- **База XP** (все действия, любые разделы) → заголовочный `standing` РОВНО (ширина = исследуй что угодно).
- **Множитель ×2**, когда фича ∈ `ARCHETYPE_FEATURES[активный архетип]` → бонус льётся в **под-трек архетипа** (глубина = играешь в стиль → архетип растёт вдвое быстрее). Off-архетип = ×1.
- **Расчёт M=2:** флоу on-архетип (лоадаут +20 ×2 = 40) → под-трек L5 (700) ≈ 15–20 осмысленных действий в стиле. Выше ×3 не берём — обесценит ширину; discovery (+15 плоско) держит исследование живым. v2: фичи ЧУЖИХ архетипов кормят ИХ под-треки (растишь несколько).

## Уровни
- **Заголовок = `STANDING_RANKS`** (есть): НЕОБСТРЕЛЯННЫЙ 0 / ОПЕРАТИВНИК 60 / ЗАКАЛЁННЫЙ 180 / ВЕТЕРАН 380 / ЭЛИТА 700 / ЛЕГЕНДА 1200.
- **Под-трек архетипа (новое):** уровень архетипа по XP, набранному в ЕГО доменных фичах. Черновик порогов: L1 0 · L2 50 · L3 150 · L4 350 · L5 700. Звания под-трека — на V4DYA (напр. Барыга: Лоточник→…→Магнат).

## Карма (СЕРВЕР — черновик; тиры Дикий 0/Боец 50/Ветеран 200/Легенда 500 уже есть)
| Событие | Карма |
|---|---|
| Ко-оп рейд подтверждён обоими | +5 каждому |
| Положительная оценка партнёра | +3 |
| Шерп-сессия (менторство нюба) | +8 |
| Подтверждённый UGC (метка/билд принят) | +5 (`build_liked` — мёртвое, эмитить) |
| Грифинг/ноу-шоу (минус-оценка) | −10 |
| Скам подтверждён | −50 (`scam_confirmed` — мёртвое, эмитить) |
| Ложный репорт (репортёру) | −5 |
Асимметрия: плюс дороже минуса; минус стоит и автору. `total` floor 0; вклад кармы может быть <0 (роняет ранг).

## Штрафы / траст-лок
Карма < порог тира → закрыты траст-функции этого тира (Боец: подать UGC/мэтчиться; Ветеран: модерация…).
Восстановление — положительной кармой. Без банов/сброса. Рецидив = дольше сидишь под локом (естественно).

## Подсказки фич (движок)
`score(feature) = релевантность архетипу (в ARCHETYPE_FEATURES[role]) × не_использована × смежность`.
Топ-1–3 → блок «Крутые фичи для тебя» (на главной/в Досье). При level-up ранга — всплыть новые анлоки (карта ранг→фича из progression-system.md).

## Клиент vs сервер (что где, что за гейт)
**🟢 Клиент, собираемо сейчас (localStorage, расширяет behaviorStore/gamification):** XP-активность (визит/discovery/флоу), пер-архетип под-трек, движок подсказок, surface анлоков. Геймится — не вредит (личная персонализация).
**🔴 Сервер — за `db:push` V4DYA:** karma-события (ко-оп рейды, оценки, штрафы, эмиссия `build_liked`/`scam_confirmed`), сессии мэтчинга (взаимное подтверждение), траст-гейты `can(action, karmaTier)`, апелляции. Кросс-девайс синк XP — тоже сервер (опц.).
