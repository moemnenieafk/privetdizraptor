# Контент историй — арты и скриншоты

Эпик E2 из [[additional-workout]] (пункт №2). Размер `M`, дробится по историям (🤖 фоновые агенты).

## Цель
Наполнить 10 сюжетных гайдов hero-артом и галереями скриншотов (сейчас у 9 из 10 — CSS-заглушки, см. [[quest-story-design]]).

## Контекст
- Данные: `src/data/story-walkthroughs/<slug>.ts` — поля `heroImage`, `media.poster/screenshots/posterDecor`.
- Ассеты: `public/images/quests/eft/story/<slug>/` (эталон — `boreas/`: poster + shot-01..09 + anchor).
- Компонент рендерит заглушку (иконка-маска + градиент), если арт не задан — фолбэк работает.

## Scope
- Hero-арт на каждую историю + галереи скриншотов по ключевым шагам.
- Заполнить `heroImage`/`media` в данных, разложить файлы по `public/images/quests/eft/story/<slug>/`.

## Границы / ⚠ лицензии
- **НЕ** тянуть чужие вики/скрины 1:1 (CLAUDE.md §4.9 — глобальный запрет внешних вики/баз).
- Источник: собственные скрины из игры / согласованные материалы / генерация в стиле NIGHTFALL.

## Критерий готовности
- [ ] У каждой истории задан `heroImage` + ≥1 галерея
- [ ] Пути к файлам существуют, страница рендерит без заглушек
- [ ] `tsc` чисто

## Развилки
- Источник артов (свои скрины vs генерация) → **решить до старта пачки**.
