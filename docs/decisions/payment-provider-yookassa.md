# Платёжный провайдер: ЮKassa + СБП (ИП на УСН 6%)

Закрывает открытую развилку «рельс оплаты» из [[monetization-subscriptions]] (была ПЕРЕСМАТРИВАЕТСЯ). Решение V4DYA + грилл, 2026-08-25.

## Решение
- **Юр-статус:** ИП на **УСН 6%**.
- **Рельс:** **ЮKassa** — основной эквайринг, **СБП приоритетным способом оплаты** (дешевле карт), карта — fallback (и как надёжный рекуррент). Boosty — не основной рельс (Дима: ≈13%+УСН≈20%); при желании отдельно под донаты/комьюнити, но не под подписку.
- **Подписка:** 199₽ (Оперативник) / 449₽ (Ветеран), автопродление (рекуррент).

## Факты ресёрча (2026-08-25) — источники профильные; ⚠️ панель-верификация не прошла (лимит), сверить перед контрактом

**Комиссии / НДС-2026:**
- С 01.01.2026 услуги эквайринга облагаются **НДС 22%** (льгота отменена, ФЗ №425-ФЗ). НДС начисляется **на комиссию**, не на всю сумму → эффективная ставка карт ≈ базовая ×1.22 (пример: 1.5% → 1.83%). Источник: pay.yandex.ru/blog/ekvajring-2026.
- **ИП на УСН 6% НДС к вычету НЕ принимает** → несёт полную эффективную ставку по картам. Отсюда — СБП тем выгоднее.
- Базовая карта (из валт-ресёрча июля): ~2.8–3.5% → с НДС-2026 ~3.4–4.3% эффективно. **СБП: 0.4–0.7%** (для покупателя комиссия 0).

**СБП + рекуррент:**
- СБП поддерживает **автоплатёж** (сумма/дата/частота, вкл. ежемесячную) — покрывает подписку. Источник: sbp.nspk.ru.
- В ЮKassa **СБП-рекуррент — только mandatory save** (нельзя опциональное сохранение), в отличие от карт/ЮMoney (оба режима). Зависит от банка клиента (не все банки). → **карта как надёжный fallback для автосписаний.**
- Механизм ЮKassa: первый платёж `save_payment_method:true` → `payment_method.id` → последующие автосписания без подтверждения юзера; переиспользуемость проверяется `payment.payment_method.saved==true`. Источник: YooKassa SDK docs.
- Управление/отмена автоплатежа — юзером в банк-приложении («Подписки и автоплатежи»); один договор ЮKassa покрывает карты+СБП+SberPay+T-Pay.

**⚠️ 54-ФЗ / касса (важно для ИП УСН — главный организационный пункт):**
- ИП на УСН **обязан применять ККТ** (онлайн-кассу) и выбивать чек на каждый платёж от физлица — **независимо от способа** (карта/СБП). Освобождены в основном только самозанятые (НПД). Источники: astral.ru, sberbusiness.
- **ЮKassa умеет формировать чеки через API** (ЮKassa-касса): коды НДС (1=без НДС для УСН, 2=0%, 5=20%) и код системы налогообложения «УСН доходы» (code 2). То есть кассу можно закрыть облачным решением ЮKassa, не покупая физическую. Закладывать ~0.8%/чек (по валт-ресёрчу).
- С 01.09.2025 — новые правила формата чека для онлайн-оплат; неверность/невыдача → штраф.

**Интеграция (техническая):**
- REST API, тип подтверждения **redirect** + встроенный **QR для СБП**; вебхуки-нотификации о статусе; **песочница** (`shopId 100500`, ключ с префиксом `test_`). Выплаты next-day (валт).
- Наша сторона готова: `PaymentAdapter`-интерфейс + вебхук `/api/billing/webhook/[provider]` + идемпотентность (unique provider+external_id) + леджер `billing_events`. Нужен только адаптер `yookassa` + ключи в `.env`.

## Практический вывод
**ЮKassa + СБП под ИП/УСН — подтверждается.** Закладывать: СБП 0.4–0.7% (основной), карта ~3.4–4.3% эффективно с НДС-2026 (fallback). Главный не-технический блокер — **онлайн-касса 54-ФЗ**, но закрывается ЮKassa-кассой через API (~0.8%/чек), отдельное железо не нужно.

## Чек-лист «что оформить/подключить» (перед интеграцией)
1. **ИП** оформлено, ОКВЭД под IT/контент-услуги, счёт.
2. **Договор ЮKassa** (магазин), включить методы: СБП (primary) + карты (fallback).
3. **ЮKassa-касса (54-ФЗ)** через API: система налогообложения «УСН доходы», ставка НДС «без НДС», предмет расчёта = услуга (подписка).
4. **Рекуррент** включить в тарифе; политика: первый платёж сохраняет метод (`save_payment_method`), СБП — mandatory save, карта — надёжный fallback.
5. **Ключи** (shopId + secretKey, сначала `test_`-песочница) → в `.env`/секреты сервера, НЕ в код.
6. **Вебхук** ЮKassa → наш `POST /api/billing/webhook/yookassa`, с проверкой подлинности нотификации.
7. Юридика витрины: оферта/условия подписки, автопродление, отмена, возвраты, политика ПДн.
