# Карты: координатная калибровка на ВСЕХ картах (линейка/отряд везде)

**Статус:** бэклог — большой дата-проект, вынесен из грилла по унификации тулбара карт (2026-08-19). НЕ делать в рамках UI-задач.

## Контекст
Верхний тулбар карт унифицирован (плашка по центру, единый набор слева/справа). Осталось **инхерентное** различие, которое нельзя убрать UI-средствами:
- **Линейка** (замер) требует координатной шкалы — есть на интерактивных SVG и тайловых (Завод: worldTransform), НЕТ на статик-SVG без калибровки (Лаборатория, Ледокол, Лабиринт).
- **Отряд** (шаринг позиций) требует проекции координат (`data.config.transform`) — есть не на всех.

Решение V4DYA (грилл): пока — **capability-гейт** (скрывать где не работает, не показывать мёртвые кнопки). Долгосрочно — **калибровать координаты на всех картах**, чтобы линейка/отряд работали везде и тулбар стал по-настоящему единым.

## Что нужно (эскиз)
- Задать `transform`/worldTransform (проекция игровых координат ↔ пиксели арта) для статик-карт без него: Лаборатория, Ледокол, Лабиринт и пр.
- Источник калибровки: 2+ опорные точки с известными игровыми координатами на каждой карте (как делали для тайловых) — вывести масштаб/сдвиг/поворот.
- После калибровки `hasRuler`/`hasSquad` автоматически станут true → инструменты появятся без правок тулбара (гейты уже завязаны на конфиг).

## Не входит
UI тулбара уже готов и от этого не зависит — это чисто датасет-калибровка per-map.
