# Карточка требований выхода

## Цель
Клик по выходу → read-only карточка: фракция, подвид, предмет-пропуск (+ссылка), рубильник, спец-условие.

## Решение
Клон паттерна Замок→Ключ (без грилинга — форма ясна). Данные уже в зеркале: у extract-маркера
`linkedItemId`=id пропуска, `meta.transferItem` `{id,name,count}`, `meta.switches`, `faction`, подвид
(`extractSubtype`). В page.tsx `itemSlug`+`itemBg` расширены на `extract` → slug/рарность пропуска на клиенте.

- **`ExtractCard.tsx`** (нов.): чипы фракция+подвид, рубильник-нота (meta.switches), спец-условия
  (сигнал/без рюкзака), ячейка предмета-пропуска (иконка+«N× имя»+ссылка) — покрывает платный (валюта),
  кодовое слово, Red Rebel.
- **`MapViewerClient`**: карточка замка обобщена в `infoMarker` (замок ИЛИ выход — один поповер за раз,
  без двух окон); клик по `type==='extract'` → та же инфра позиционирования/закрытия; свитч рендера.

## Границы / край
- Имя выхода = `label` из источника; у части выходов сырое (`EXFIL_*`) — качество зеркала, не код.
- Реверс/агрегации нет (у выхода нет «соседей» как у ключа).

## Проверено
tsc/eslint 0; клик по выходу → карточка (фракция/подвид/рубильник), 0 ошибок.
