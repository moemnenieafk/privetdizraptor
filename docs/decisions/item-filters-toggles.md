# Тумблеры источников цены — «Использовать бартеры / крафты / комиссию / центы торговцев»

**Статус:** 🔵 обдумываю · **блокер: спека Дмитрия** (в источнике: «если непонятно — спроси, Дмитрий распишет варианты»)
**Затрагивает:** [[bugs-triage-2026-07-19]] · [[effective-price-nesting]] · раздел `/eft/items/`

## Контекст
Пункт 7 дампа 19.07. Хотим набор переключателей в разделе предметов — по образцу фильтров
tarkov.market — которые **меняют, из каких источников считается цена/выгода**:
- «Использовать бартеры»
- «Использовать крафты»
- «Использовать комиссию» (комиссия барахолки при продаже)
- «Использовать центы торговцев» (округление/центовые цены торговцев?)

По сути тумблеры = какие ветки расчёта [[effective-price-nesting]] включены. Поэтому две заметки
проектируем вместе: тумблеры — это UI-переключатели над рекурсивным движком выгодной цены.

## Открытые вопросы (нужно от Дмитрия — до кода)
1. **«Центы торговцев»** — что именно значит? Округление до целого? Учитывать/не учитывать
   мелкую валюту? Дать точный пример.
2. **Область действия тумблера** — только карточка предмета, весь каталог (сортировка/фильтр
   списка), или и то и то?
3. **Дефолты** — какие тумблеры включены по умолчанию для нового пользователя?
4. **Персистентность** — состояние тумблеров хранить (Zustand + localStorage) или сбрасывать?
5. **Связь с гейтингом** — часть фильтров = про-фича ([[feature-gating-entitlements]]) или всё бесплатно?
6. Примеры «до/после» на конкретных предметах (Дмитрий обещал расписать).

## Предварительные варианты (без спеки — набросок)
- **A —** тумблеры только на карточке предмета, локальный стейт, влияют на подсветку «выгодно/невыгодно».
- **B —** глобальные тумблеры каталога в Zustand (`src/store/`), влияют и на список (сорт по выгоде),
  и на карточку; состояние персистентное.

## Вывод
**Ждём спеку Дмитрия** по 6 вопросам выше — без неё в код не идём (риск переделки UI и логики).
Проектировать **после/вместе** с [[effective-price-nesting]], т.к. тумблеры управляют его ветками.
