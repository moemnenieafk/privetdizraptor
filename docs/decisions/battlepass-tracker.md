# BATTLEPASS Трекер — трекер наград и документации Сезона 1 «KORD BREACH»

Исполняет **Ф4 эпика** [[seasons-battlepass-epic]] («трекер прогресса БП, дневной лимит документации»).
Данные-фундамент (8 документов в каталоге + бейдж BATTLEPASS-S1 + слой карты) уже лежат — это **чистый UI**
поверх статичного словаря, БД/схему не трогаем (§4.11: словарь как `eft-seasons.ts`, не рантайм-фетч).

## Что просили (V4DYA + бриф Дмитрия)
1. Новая страница **«BATTLEPASS Трекер»** в разделе Сезонов, кнопкой рядом с «Конструктор билдов» в карточке
   Первого сезона.
2. Источник данных наград — `docs/eft/Награды_Батлпасс_KORD_BREACH_для_трекера.md`: **12 страниц БП**, на
   каждой набор наград, у каждой награды — стоимость в **документации** (8 типов, валюта БП, лутается в рейде).
3. **Трекер:** игрок отмечает «награда получена» → её стоимость документов **вычитается** из общего остатка.
4. **Сводные таблицы:** (а) сколько всего/собрано/осталось документации по типам; (б) где какой документ
   лутается (документ × карты). Итоги внизу.
5. **Дневной лимит** добычи документов по режимам: PvP 20 · PvE 15 · Season PvP 30 (патч 14.08.2026).
6. Визуал наград — из файлов игры (иконки) / referenced escapefromtarkov.com/kordbreach.

## Решения (автономно, ночная autopilot-сессия)
1. **Маршрут `/eft/progress/seasons/tracker`** — зеркалит `…/perks` (та же структура: Server Component →
   клиент, back-link «Сезоны», без отдельного пункта в шапке). Кнопка на хабе — сиблинг «Конструктора».
2. **Данные — статичный словарь `src/data/eft-battlepass.ts`** (как `eft-seasons.ts`/`eft-season-items.ts`).
   НЕ mirror-таблица: это редакторский датасет одного сезона из MD-спеки + файлов клиента, не игровой рантайм-
   источник. §4.11 не нарушается; promote в Supabase — опция на будущее, если понадобится синк.
3. **Прогресс игрока — localStorage через Zustand `persist`** (прецеденты `useSeasonStore`, `useRoomOpensStore`).
   Ключ по slug сезона. Необратимых БД-операций нет (§5) — можно катать ночью без подтверждения.
4. **Логика вне разметки** (§4.7): все расчёты (итоги/остатки/матрица/ETA) — чистые функции `src/lib/battlepass.ts`.
5. **Иконки документов** — реальные из каталога через `itemIconUrl(id)` по `BP_SEASON_1_DOC_IDS` (8 id уже в
   `eft-season-items.ts`). **Иконки наград** — реальные там, где награда матчится на предмет каталога (пушки,
   броники, рюкзаки, нож, шлем, TarCoin — id зарезолвлены грепом по `items_database.json`); для косметики
   (позы/голоса/стили убежища/плакаты/жетоны-уровни) — глиф-категория (lucide) + `onError`-фолбэк, чтобы
   отсутствующая на R2 иконка не била битой картинкой.
6. **Две вкладки:** «Награды» (12 страниц, тоглы «Получено») и «Документы» (сводная таблица + лимиты + ETA).
   Верхняя полоса — общий прогресс (получено наград / всего) всегда видна.
7. **Разблокировки страниц — информативно, не жёстко** (как свободный выбор в конструкторе перков): показываем
   требование «получить N наград со стр. X», но тоглы не блокируем — трекер, а не симулятор гейтинга.

## Скоуп ночной сборки — что делаю / что откладываю
- ✅ **Делаю:** страница-трекер целиком (данные 53 наград × 8 документов, расчёт остатков, тоглы, сводная
   таблица «документ → нужно/собрано/осталось/где найти», панель дневных лимитов + ETA рейдо-дней, кнопка на хабе).
- ⏳ **Откладываю (документированный follow-up):** **визуальные маркеры спавнов документов на картах.** Дмитрий
   сам обозначил этот кусок как нечёткий («расставлять руками или через скриншоты, Вадим уточнит»). Материал
   есть — скрины `…/KORD BREACH/BATTLEPASS-DOCUMENTS-MAP/{factory,factorybase}/*` (23+23). Это отдельная фаза
   (совпадает с Ф2 эпика — editorial-метки `source='user'` в `markers`); трекер даёт по картам таблицу «где
   найти», а точки-маркеры — следующим заходом с V4DYA. Не блокирует ценность трекера.

## Гочи данных из MD-спеки (занёс как есть, помечено к сверке)
- **Стр. 6, Howa Type 20:** в MD «Пользовательская х2» И «Пользовательская х1» (один тип дважды) → **суммирую
   в user: 3**. Голосовой бриф Дмитрия для этой же награды называл «проектная х2» — расхождение источников на
   ОДНОЙ награде. Взял письменную MD-спеку (её прислали как канон), пометил `verify: true`. Свериться в клиенте.
- **Заголовки стр. 11/12:** в MD обе ссылаются на «страницы 10» (копипаст-опечатка). Нормализовал цепочку:
   страница N требует наград со страницы N−1. Счётчики требований взяты по тексту (p7←2 от p6, p8←3 от p7, прочие ←4).
- **QBZ-191 (стр. 12), гавайские рубашки, КНЯЗЕВ/О.КОННОР** — в каталоге нет → глиф-категория (оружие/одежда/декор).
