# Трекинг: Избранные предметы (плитки EftItemTile)

## Цель
Секция «Избранные предметы» во вкладке «Трекинг» ([[player-tracking-tab]]): предметы, отмеченные ★ в каталоге, — **в стиле плитки `EftItemTile`** (иконка, редкость-тинт, цены трейдер/барахолка, VPS) с живыми ценами из нашего зеркала. Личный «прайс-борд» игрока. Часть платного контура трекинга (PRO).

## Контекст
- Избранное УЖЕ есть: звёздочка в `EftItemTile.Header` + `FavoritesStrip.tsx` — найти стор (вероятно `useItemsStore`, localStorage; облачного синка избранного, похоже, НЕТ — проверить).
- Плитка: компаунд `EftItemTile` (`src/components/features/items/EftItemTile/`) — переиспользуется как в SimilarItems (сетка 1/2/3/4).
- Цены: `getEftPriceMapFromDb()`/`getEftPricesByIds()` (`src/db/prices.ts`) — но вкладка client-side, а избранное в localStorage → серверу неизвестно, какие предметы грузить. Развилка данных ниже.

## Развилки
- **Данные цен для избранного (ключевая):** client-fetch нашего API по ids (`/api/eft/...` — есть ли подходящий роут?) · грузить весь прайс-мап (тяжело) · синкать избранное в облако и грузить в RSC (красивее, но +таблица/поле = db:push)?
- Синк избранного между устройствами — заодно сделать (облако) или отложить?
- Сетка: сколько колонок во вкладке (там уже есть сайдбар кабинета — вероятно 1/2/3)?

## Гарды
- Если облачный синк избранного → db:push с ручным «ок». PRO-гейт — общий (см. хаб).
