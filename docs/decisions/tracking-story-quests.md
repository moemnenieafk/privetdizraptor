# Трекинг: Сюжетные задания (истории)

## Цель
Секция «Сюжетные задания» во вкладке «Трекинг» ([[player-tracking-tab]]): прогресс прохождения сюжетных цепочек/историй (главы прочитано/пройдено, текущая глава, переход к продолжению). Часть платного контура трекинга (PRO).

## Контекст
- Контент сюжеток: статика `src/data/story-quests/*.ts` (`StoryQuestChapter[]`), страницы `/eft/quests/lore-quests` + `/eft/quests/<slug>` (`StoryQuestGuide`).
- **Прогресса сюжетных, похоже, НЕТ** (проверить: useQuestStore трекает только трейдерские id) → вероятно нужен новый лёгкий стор/поле «пройденные главы» + (опц.) облачная колонка. Это отличает домен от side-quests: тут может понадобиться БД-работа (⚠️ db:push — с подтверждением).
- Сюжетки пересекаются с трейдерскими квестами (главы ссылаются на task id?) — сверить структуру StoryQuestChapter.

## Развилки
- Что считать «прогрессом» сюжетки: прочитал главу · выполнил связанные задания · ручная галочка?
- Хранение: расширить `quest_progress` (jsonb-поле) · отдельная таблица · только localStorage?
- UI: полоса прогресса по цепочке + «продолжить с главы N»?

## Гарды
- Если появится облачное хранение → db:push только с ручным «ок». PRO-гейт — общий (см. хаб).
