Фрейм `story-boreas-step01` считан из Figma напрямую (MCP: metadata + design context ×3). Токены макета совпали с NIGHTFALL 1:1. `tsc` чисто.

- **`features/quests/StoryWalkthrough/`** — страница-гайд: hero-панель истории (арт + СЛОЖНОСТЬ-черепа + «Карта квеста» + ТРЕБОВАНИЯ со станцией), лестница шагов 348px + контент (gap 28px; мобилка — чипы гориз. скроллом), медиа-блок (постер с оверлеями БОРЕЙ/якорь/Play + галерея миниатюр со сменой кадра, ‹ › и zoom), «ВЫПОЛНЕНИЕ» с буллетами, **карточки условий** (стальной бордер `--color-info-steel` + радиальное свечение): убежище (**авто-чек из useHideoutStore**), предмет (медиаконтейнер + **живая цена из зеркала** в тексте, nvg-green), история; чек → success; футер актуальности (дата/версия игры) + «Сообщить об ошибке» (заглушка-disabled).

- Интеграция: `/eft/quests/[slug]` — истории из реестра → новый гайд; остальные — прежний `StoryQuestGuide`. Ассеты скачаны из Figma → `public/images/quests/eft/story/boreas/` (постер, 9 скринов, якорь) + `difficulty-skull.svg` (+класс).

### Доработка 1 (2026-07-04) — карта сюжетных квестов (Figma node 1579-1027)
- Навигация раздела = **QuestsHubNav** (как на побочных); шкала сложности **7 слотов** (6 danger + пустые lines-hover).
- **Новый роут `/eft/quests/<slug>/map`** — интерактивный граф истории, **узлы = настоящий `<QuestNode>` с большой карты** (уточнение V4DYA: «переиспользовал ноды из карты квестов»): псевдо-TaskRaw из данных графа, статусы active/completed, счётчики предметов в целях живут в `useQuestStore.itemProgress` (синк в облако). QuestNode минимально обобщён (обратносовместимо): `headerIconClass` (иконка-маска шапки для убежища/барахолки/локаций/историй) + `hidePin`. Цвет узлов истории — псевдо-трейдер `--trader-boreas: #80ACBF` (стальной из постера) через штатный trader-механизм ноды. Вьюпорт `QuestMapViewport` + общий `makeQuestPath` (`src/lib/quest-path.ts`, QuestMapClient переведён на импорт); линии от выполненных — nvg-green. Кнопка «Карта квеста» в hero ведёт сюда.
- Данные: `src/data/story-walkthroughs/boreas-map.ts` (14 узлов, 14 рёбер). **Чеки узлов активации разделяют ключи с шагом 01 гайда** — прогресс гайд↔карта синхронен (useStoryProgressStore).
- Гоча: itemId «Набор инструментов»/«Распоряжение»/«Бронированный кейс»/«Военный фильтр» не проставлены (пустые плитки) — добить id из каталога.

### Доработка 2 (2026-07-03) — гайд по макетам step01/02/03 (nodes 1579-843, 1599-2064, 1608-2705)
Суть от V4DYA: «на каждом этапе есть картинка и галерея + прожав все выполнено — этап закрывается и автоматически переходишь к следующему».
- **Условия шагов = настоящие `<QuestNode>` по центру контента** (как на карте истории): `conditionToTask()` — псевдо-TaskRaw из условия (убежище → Basic «Постройка…» + `icon-eft-prog-hideout`; предмет → TaskObjectiveItem с иконкой из зеркала + FIR; история → Basic-заметка + своя иконка), цвет — псевдо-трейдер истории, пин скрыт. Старые ConditionCard/DoneToggle удалены, токен `--color-info-steel` вычищен из globals.css (осиротел).
- **Медиа у КАЖДОГО шага**: свой постер+галерея, фолбэк — арт истории (`heroImage` + подпись «ИСТОРИЯ»); Play-оверлей только при `media.video` (пока шаг 01).
- **Автопереход**: все условия шага чекнуты (или авто из useHideoutStore) → плашка «Этап выполнен — переходим к следующему…» → через 0.7с открывается следующий шаг с контентом (guard от повторного срабатывания).
- **Лестница трёхфазная**: пройденный — success-бордер + зелёный текст с зачёркиванием; активный — primary + стрелка-маркер слева (lg); будущий — muted (без контента — opacity 25).
- **⚠-предупреждения**: `WalkthroughBlock.warning` — оранжевая строка с AlertTriangle (шаг 03 — «если не прочитали документы в рейде…»).

### Доработка 3 (2026-07-03) — новый дизайн для ВСЕХ 10 историй
Решение V4DYA: «подобный дизайн для всех историй, если нет изображений — придумай заглушку». Вариант «руками» (не рантайм-адаптер).
- **Общая модель** — `src/data/story-walkthroughs/types.ts`: `heroImage`/`requirement`/`station` опциональны, `hasMap` (кнопка «Карта квеста» только у Борея), `posterDecor` (декор постера: у Борея якорь+сталь, у остальных иконка-маска истории), `media.videoUrl` (Play теперь кликабельная ссылка на видеогайд). Реестр — `index.ts` (10 историй), `iconUrl`/`iconClass` в данных (имена svg НЕ совпадают со слагами).
- **9 историй переведены руками** из `story-quests/*` в шаговый walkthrough (агенты ×3): Тур 7 шагов, Небеса в огне 9, Билет 4, Свидетель 8, Батя 8, Синий Огонь 6, Они уже здесь 7, Неизвестные 6, Лабиринт 5. Каждый шаг — чекаемая story-нода QuestNode; развилки/таблицы → subList + ⚠ warning («выбор необратим», «60 секунд», «серия за одну жизнь»); видеогайды → `videoUrl` шага 01; весь текст исходников перенесён без потерь.
- **NIGHTFALL-заглушки** (артов у 9 историй нет): hero — большая иконка-маска истории на darkbase (opacity 10); постер — иконка по центру + декор-иконка у тайтла + градиентный тайтл (белый → цвет из `posterDecor.gradientTo`, дефолт text-secondary).
- **Снесено**: `StoryQuestGuide`, `src/data/story-quests/*`, `src/types/story-quest.ts` — все истории идут через новый гайд (`/eft/quests/[slug]`). `tsc` чисто.

### Доработка 3 (2026-07-03) — вложенная лестница: под-шаги и развилки (выбор пути)
Запрос V4DYA: у mrsouer шаги имеют вложенные под-шаги/ветвления — «если игрок выбрал этот путь, они раскрываются и выполняются».
- **Модель** (`types.ts`): `WalkthroughStep.substeps` (простая вложенность) и `.branches` ({id,title,note,substeps} — развилка). Лестница максимум 2 уровня; глубже — text/subList внутри под-шага.
- **Стор**: `branchChoice` (`${slug}|${step}` → branchId, персист) + `storyConditionKey(..., subId)` — ключи под-шагов `slug|step|subId|blockIdx` (старые ключи шагов не тронуты — синк с картой Борея цел).
- **UI**: под активным шагом раскрываются под-шаги (нумерация 04.1…); развилка — ветки с GitBranch-иконкой, раскрыт ТОЛЬКО выбранный путь (невыбранные приглушены, выбор можно сменить), на уровне шага — карточки «Выберите свой путь»; автопереход: под-шаг → следующий незакрытый под-шаг пути → следующий шаг.
- **Контент** (research mrsouer → [[../research/mrsouer-branches-ticket-boreas]], 41+20 узлов, RSC-парсинг + T-чанки): «Билет» пересобран полностью — развилка «Судьба кейса» (отдан Прапору / оставлен себе), развилка «Путь к финалу» из 4 веток-концовок (Керман №1 / отказ №2 / Смотритель №3 / без Кермана №4), Терминал под-шагами; «Борей» — шаг 04 под-шаги Прапор(выход)/БТР(вход), шаг 08 — 4 квеста мехвода, шаг 14 — 4 цепочки побочек.
- Попутно: `mapIcon`/`trader` в условиях всех 10 историй (шапка ноды = иконка локации или фото торговца), градация черепов по сложности, гоча icon-mask bg-* (см. память).
- **UX автоперехода (правка V4DYA «геймер-френдли»)**: автопереход срабатывает ТОЛЬКО при свежем закрытии этапа (возврат на пройденный шаг никуда не перекидывает); пауза 4с с кнопкой «Остаться» (случайный клик отменяем); на закрытом этапе — ручная кнопка «К следующему этапу →»; снятие чека отменяет переход; при заходе на страницу — резюме на первом незакрытом шаге.
