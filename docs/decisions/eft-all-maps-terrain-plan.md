# Все карты EFT: что можно извлечь прямо сейчас

Просканированы **все 714 `sharedassets`** клиента на `TerrainData`. Найдено **34 террейна**
в 10 файлах. Соответствие `sharedassetsN` ↔ карта — через `docs/registry/eft-scenes.json`
(`levelN` ↔ имя сцены).

📋 **Машиночитаемо это теперь лежит в git: `docs/registry/eft-terrain.json`** — карта ↔
`sharedassetsN` ↔ слайсы ↔ мировые позиции ↔ имена слоёв ↔ счётчики прогона. Позиции и имена
слоёв заполнены фактом у Таможни и Маяка; у остальных четырёх карт стоит `positionsRead: false`
и только инвентаризация (имя / `res` / число слоёв) — их позиции ещё не читались.

## Карты БЕЗ террейна

Завод, Лаборатория, Лабиринт, Терминал, Ледокол, Ноль (Sandbox), Улицы (City) — Unity-террейна
нет: интерьеры и городская застройка целиком на мешах. Для них:
- **высоты** — ортографический depth-рендер геометрии (`scripts/eft-terrain/HeightRenderer.cs`),
- **материал** — Gemini по плиткам (готовый промт и нарезка: `gen/customs/ground/gemini-input/`).

## 🚀 Боевой конвейер: без Unity и без 14-ГБ экспорта

`UnityPy` читает `TerrainData` **прямо из `sharedassetsN.assets`**:
- `m_Heightmap.m_Heights` — 1025² нормализованных значений;
- `m_Heightmap.m_Scale` — `{x: 0.684, y: 180, z: 0.684}`, мировая высота = `posY + h * scale.y`;
- `m_SplatDatabase.m_TerrainLayers` (12 имён) + `m_AlphaTextures` (3 RGBA = 12 каналов весов).

Мировые позиции слайсов — из иерархии сцены `levelN`: корень `terrain` → дети `Slice_<ряд>_<кол>`
на сетке 700 м (`Slice_R_C` → `x = (C-1)*700`, `z = (R-1)*700` плюс позиция корня).

> **Уточнение по факту прогона.** Позиции берутся **из иерархии**, а формула на сетке 700 м
> служит только контролем. Сетка при этом **общая на все карты EFT**, поэтому сцена карты видит
> соседние слайсы, физически лежащие в чужих `sharedassetsN` (`level200` Маяка держит шесть нод,
> три из них — из `sharedassets140`/`sharedassets25`). Нода с внешней ссылкой — норма, а не
> недостача входа. И контрольная формула сходится не везде: у Берега и Резерва она промахивается
> опорной точкой — см. «Мины» в чекпоинте.

Итог: **минуты на карту, чистый Python**, вместо «экспорт 14 ГБ + импорт Unity 40 минут».
Путь через AssetRipper/Unity остаётся для разведки и для карт без террейна.
