# Тайм-гейт кармы (расчёт) + чекпойнт-награды по архетипу «Кто ты в Таркове»

Задача V4DYA: (1) точно рассчитать «стопер» набивания репутации — чтобы даже «безумный фанат премиума» тратил ~месяц, а нормальный человек — в разумных пределах; (2) на чекпойнтах вознаграждать полезной фичей, привязанной к архетипу игрока (Барыга → прибыль/бартер/тренды).

## Часть 1 — расчёт тайм-гейта («сколько человек высидит»)

**Вводные (оценки):**
- Каталог 5044 предмета; флиа-релевантных «ценных» (worklist-вселенная) ~**1500–2500**.
- Эффорт на предмет: в общем списке 1 скрин ≈ **12 предметов** (амортизировано ~2–5 сек/предмет); в поиске одного предмета (ключи/дорогое) ~**15 сек**.
- Выносливость на монотонной задаче: нормальный вовлечённый — **20–40 мин/сессия**; обсессивный «фанат премиума» (девиация) — **2–4 часа** за присест.

**Ключ: тайм-гейтит ДНЕВНОЙ потолок, а не выносливость.**
При текущей экономике (устарело `0.001`, нет данных `0.002`, дневной потолок `0.05`):
- потолок 0.05 достигается за **25–50 обновлённых предметов** = ~**10–15 мин** работы;
- дальше в этот день карма НЕ капает, сколько ни сиди → обсессивный фанат **остановлен потолком за 15 мин**;
- «сидеть весь день на PrintScreen» бессмысленно by design.

**Пейсинг до премиума:**
| Порог премиума (реп) | Дней при максе (0.05/день) | Реально* |
|---|---|---|
| 1.0 | 20 | ~3–4 недели |
| **1.5** | **30** | **~месяц** ✅ |
| 2.0 | 40 | ~6–8 недель |
*реально дольше: не каждый день найдётся 25–50 устаревших предметов (worklist истощается, обновляется по мере протухания).

**Вывод:** дневной потолок `0.05` + порог премиума `~1.5` = **~месяц, несжимаемо** (даже фанат не обойдёт дневной потолок). Совпадает с «за месяц помощи — премиум». **Тайм-гейт не нужен отдельный — им УЖЕ служит дневной потолок**; «стопер» = чекпойнты (ниже). Левелы тюнинга: `KARMA_DAILY_CAP`, порог премиума, per-item суммы.

**Здоровье механики:** 10–15 мин/день × месяц = привычка, а не грайнд; ретеншн (нужно возвращаться ежедневно), не выгорание.

## Часть 2 — чекпойнт-награды по архетипу

Вместо линейного «1.5 = премиум» — **чекпойнты** (ранги лояльности, Скупщик-стайл): на каждом «стоп + награда». Награда = **полезная фича под АРХЕТИП** игрока («Кто ты в Таркове», 11 ролей в `role-inference.ts`: Новобранец, Прогрессор, **Барыга**, Оружейник, Инженер базы, Рейдер, Зритель, Крыса, Шерп, Лорник, Сокланы).

**Виртуозная петля:** companion даёт ЖИВЫЕ цены → награды Барыги ПИТАЮТСЯ этими ценами. Вкладываешь цены → открываешь ценами-powered инструменты под свой стиль.

**Примеры наград под архетип (усиливают существующие хабы `role-hubs.ts`):**
| Архетип | Награда-фича (live, на companion-данных) |
|---|---|
| **Барыга** | «Живой профит-радар»: где/как быстро ₽ прямо сейчас — бартер выгоднее покупки, ходовой тренд, флип, что взлетело |
| Оружейник | «Дешёвая сборка сейчас» по живым ценам |
| Инженер базы | «Крафт-профит live» — что окупается прямо сейчас |
| Крыса/Рейдер | «₽ за слот сейчас» — что тащить с рейда по актуальной цене |
| Новобранец | подсказки «не продешеви» на живых ценах |

**Структура:** чекпойнт = ранг + разблокировка. Косметика/статус на ранних, ощутимые архетип-фичи — на поздних (реп ~1.0+). Премиум-развилка ([[companion-gamification]]) при таком медленном рейте безопаснее для подписок.

## Открытые решения (V4DYA)
1. **Порог премиума** (реп) и **дневной потолок** — финализировать по таблице (дефолт: 1.5 / 0.05 = ~месяц).
2. **Уровни чекпойнтов** (0.25/0.5/1.0/1.5?) и что даёт каждый.
3. **Маппинг архетип → награда** — по одной killer-фиче на роль (Барыга — профит-радар как якорный пример).
4. Часть наград — премиум или чистая косметика (пересечение с развилкой премиум-за-вклад).
