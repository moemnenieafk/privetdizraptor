# Сезоны · Конструктор перков

Интерактивный конструктор **сезонных модификаторов (перков)** Escape from Tarkov в разделе «Прогресс». По мотивам tarkov-market/season-1/perks, но переработан в инструмент под нашу дизайн-систему NIGHTFALL: с бюджетом очков, живой валидацией, взаимоисключениями, каскадным снятием, каталогом билдов и шарингом по ссылке.

> Решение-первоисточник: [[decisions/done/seasons-perks-builder.md]]

---

## Механика сезона (Season 1 «Kord Breach», патч 1.1.0)

- **Сезонный персонаж — отдельный и добровольный**: уровень 1, пустой схрон, только PvP. Основной профиль (стаж, схрон, убежище, «Каппа») **не трогается вообще**.
- **Сезонные модификаторы** (6 шт.) навязаны всем — их не выбирают.
- **Личные модификаторы — бюджет очков**: старт **0 очков**, негативные перки **дают** очки, позитивные **тратят**. Баланс обязан остаться **≥ 0**. Хочешь «Каппу» (−12) — набери +12 болью.
- Старт с события **Blackout**. Окно — июль 2026 (конкретный день BSG не назвала). Минимум **74 дня**, заявлено два сезона в год, бесплатно.
- ✔ Цифры и формулировки **сверены с релизом 1.1.0.0** (экран «Личные модификаторы» в игре).

## Отличия от конкурента (зачем строили)

tarkov-market по сути — список + счётчик. У нас — инструмент:

| Фича | Суть |
|------|------|
| **Взаимоисключения** | Взаимно гасящие пары (тромбофилия ↔ гемофилия) блокируются. Логика наша, не запрет BSG: два противоположных эффекта вычитаются, очки впустую. |
| **Свободный выбор** | Позитивы берутся когда угодно; баланс может уйти в минус — панель показывает «добери N». Валиден = баланс ≥ 0 И ≥ 1 негатив. |
| **Без «магии»** | Снятие негатива просто убирает его (баланс краснеет), ничего не удаляется молча. Каскад убран как непрозрачный. |
| **Каталог билдов** | «Генератор вызова»: барабан курируемых архетипов + режим «Хаос» (случайный валидный билд). |
| **Шаринг по коду** | Весь билд лежит в URL (`/seasons/[slug]/b/[code]`), БД не нужна. |

## Архитектура (FSD-lite)

**Данные**
- `src/data/eft-seasons.ts` — сезон + **39 перков** (6 сезонных + 19 позитивных + 14 негативных, свои формулировки эффектов), маппинг SVG-иконок `S1_PERK_ICON`, хелпер `withIcons`. Экспорт: `EFT_SEASONS`, `getSeason()`, `CURRENT_SEASON`.
- `src/data/season-builds.ts` — редакционный каталог **21 курируемого билда** (`CuratedBuild`, `VIBE_META`, `getSeasonBuilds()`). Инвариант: каждый билд валиден математикой бюджета.

**Логика (чистые функции, вне UI)**
- `src/lib/season-points.ts` — `computeBudget`, `perkStates`, `dropCascade`, `encodeBuild`/`decodeBuild`, `personalPerks`/`seasonPerks`.

**Состояние**
- `src/store/useSeasonStore.ts` — Zustand + `persist` (ключ `cta-seasons`). Выбор хранится по сезонам (`slug → id[]`), есть `undo` (история до 20), `applyPreset`, `reset`, `toggle`.

**UI (features)**
- `src/components/features/seasons/SeasonPerkBuilder.tsx` — липкая панель бюджета, три группы карточек (позитивные / негативные / сезонные), undo/сброс/шаринг, тултипы эффектов.
- `src/components/features/seasons/SeasonBuildGallery.tsx` — «Генератор вызова»: барабан архетипов + «Хаос» (`useSfx`, `MAX_PAIN = 50`, `MAX_COMFORT = 29`).
- `src/components/features/seasons/SeasonLogo.tsx` — цветной SVG-вордмарк сезона (как `<img>`).
- `src/components/features/seasons/perkVisual.ts` — визуальный словарь: цвет иконки-маски по типу перка + `perkMaskStyle`.

## Типы перков и раскраска

| Тип (`PerkKind`) | Очки | Цвет иконки (CSS-маска) |
|------------------|------|--------------------------|
| `season` | 0 (навязан всем) | `--color-lightkeeper` |
| `positive` (баф) | `< 0` — тратит | `--color-nvg-green` |
| `negative` (дебаф) | `> 0` — даёт | `--color-danger` |

Иконки — монохромные SVG сезона 1 (отрисованы V4DYA), красятся CSS-маской по типу. Имена файлов не равны `id` → явный маппинг `S1_PERK_ICON`. Путь: `/icons/eft/04-progression/seasons/season01/perks/{buffs|debuff|global}/`.

## Ключевые перки (экономика бюджета)

**Дорогие позитивные (тратят):** Kappa Protocol / Середнячок −12 · Молодость / Геркулес / Вундеркинд / Кусторождённый / Медвежатник −5 · Спринтер / Марафонец / Крепкие кости −3.

**Жирные негативные (дают):** Необучаемый / Неработающая барахолка +10 · Сломанный контейнер +6 · Истощение +5 · Остеопороз / Аллергик +3.

Сумма всех негативных (14 шт.) = потолок «боли» **50 очков**. Тяжёлый позитивный стек (Каппа + Середнячок + Геркулес) = потолок трат ~29.

---

## Каталог билдов (21 архетип)

Вайбы (`BuildVibe`): `meta` (Мета) · `speed` (Спидран) · `comfort` (Комфорт) · `pain` (Боль) · `meme` (Мем) · `loot` (Лут).

Примеры: «Каппа с порога» (meta), «Всё и сразу» (meta), «Медвежатник на смене» (speed), «Середнячок с работой» (comfort), «Отдел страданий» (pain, 0 позитивных), «Мосинбоярин» (meme), «Из кустов по лут» (loot). Все комбинации — наш редакционный слой, но `id` перков настоящие и валидность гарантирована скриптом.

## Гочи и решения

- **Zustand v5:** нельзя возвращать `?? []` прямо в селекторе — новый массив каждый рендер ломает `Object.is` → бесконечный ре-рендер. Использованы стабильные пустышки `EMPTY_SELECTION`/`EMPTY_HISTORY`.
- **Шаринг без БД:** билд целиком в URL (паттерн `loadouts/b`), открывший видит расклад и сразу правит как свой (`initialSelection` применяется один раз через `applyPreset`).
- **Конфликт важнее нехватки очков:** в `perkStates` сначала объясняем «гасится перком X», потом «не хватает очков».
- **Каскад снимает самые дорогие позитивные** первыми (дешёвые игрок ценит меньше).
- **Пресеты всё равно проверяются** `computeBudget().valid` — данные могут разъехаться с ценами.
- Конструктор **бесплатный** (это данные, которые игрок и так видит в клиенте). Гейтить планируется только мульти-билды и облачный синк.
