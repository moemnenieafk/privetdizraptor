# Сверка API vs Документы — Расхождения

> tarkov.dev API использует данные SPT (устаревшие). Документы docs/quests-origin/ = актуальный источник.

## Обнаружены ошибки в данных API:

### 1. ПРАПОР — Ад на земле. Часть 1
- **Docs:** дочерний квест Стрельба по баночкам (открывается сразу)
- **API (SPT):** требует Как в старые добрые. Часть 1 (лишняя зависимость)
- **Патч:** prereqs = ["Стрельба по баночкам"]

### 2. МЕХАНИК — Оружейник. Часть 4
- **Docs:** требует только Оружейник. Часть 3; Часть 2 ведёт к ветке Сигнал
- **API (SPT):** требует Часть 2 + Часть 3 (неправильная конвергентная зависимость)
- **Патч:** prereqs = ["Оружейник. Часть 3"]

### 3. ТЕРАПЕВТ — Коллеги. Часть 3
- **Docs:** последовательная цепь Сельпо → Ч.1 → Ч.2 → Ч.3
- **API (SPT):** требует только Путь охотника. Садист (Егерь) — неправильный трейдер
- **Патч:** prereqs = ["Коллеги. Часть 2"]

### 4. ЕГЕРЬ — Путь охотника. Стиратель. Часть 2
- **Docs:** последовательная цепь Борьба с вредителями → Ч.1 → Ч.2
- **API (SPT):** требует Охранка + Стиратель. Часть 1 (лишняя зависимость от Охранка)
- **Патч:** prereqs = ["Путь охотника. Стиратель. Часть 1"]

## Не ошибки (кросс-трейдерные цепи, отражены правильно в карте):

- Серьёзные обвинения (Лыжник), Камера. Мотор! (Механик), Ответочка (Лыжник), Ключ от города (Барахольщик) — документы перечисляют их в разделе Прапора как "сюжетную цепь", но в карте они отображаются у своих торговцев ✓
- Стандарт Качества (Терапевт), Авиапочта (Механик), Минута славы (Лыжник) — аналогично ✓
- Рыболовные снасти (Миротворец) требует Друг с Запада Ч.2 (Лыжник) — кросс-трейдер, корректно ✓

## Новые квесты в API, не задокументированные (добавлены в игре позже):

- Прапор: Замена масла (корневой, нет пред.)
- Терапевт: Война... Война никогда не меняется, Биохимия
- Скупщик: 5x серия Возмещение ущерба
- Барахольщик: Обновление ассортимента, 4x Новое начало
