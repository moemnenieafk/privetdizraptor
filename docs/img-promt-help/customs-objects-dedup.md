# Customs · objects — дедуп-таблица (канон → варианты)

Цель: гнать **минимум генераций**. Один КАНОН генерим Gemini-Pro (дорогой шаг), остальные
получаем дёшево — recolor / rotate / mirror / вмятины / переиспользование части.
По каноническому пайплайну: «дедуп строго ДО генерации, иначе платим за копии».

**Итог: 59 объектов → ~33 канона (генераций). Экономия ≈ 44%.**
Крупные выигрыши: седаны 10→2, вагоны/цистерны 9→4, валуны 4→1.

Обозначения деривации: **[color]** перекрас · **[rot]** поворот `<use>` · **[mir]** зеркало ·
**[dmg]** добавить вмятины/скос · **[part]** собрать из уже готовых частей · **[load]** сменить груз в кузове.

## Порядок генерации (дёшево → дорого, парами)
1. Сначала **самые переиспускаемые каноны**: CAR-SEDAN, TREE-CANOPY, BARREL, TYRE-PILE, DUMPSTER, CRATE-WOOD.
2. Пары «целый/битый» подряд в одной сессии: CAR-SEDAN → CAR-WRECK.
3. Семейства с [color]: RAIL-BOX (3), RAIL-TANK (2), TRUCK-MIL (2) — один канон, потом перекрас.
4. Уники (1:1) — последними.
5. ⚠️ Перед генерацией **перекропить/решить**: stelage-02, ploshadka-01, improvised-road-block01, stop-train, каменные кропы (срезать фон).
