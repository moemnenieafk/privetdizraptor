# СЕЗОНЫ в Escape from Tarkov

Живой сборник по сезонной системе EFT: что вносят разработчики каждый сезон (цвет, стиль, механики, предметы, обновлённые файлы) и как это отражено у нас. Пополняется по мере выхода сезонов.

Связано: [[Сезоны и Боевой Пропуск.md]] (задел-решение) · [[BSG 1.1.0.0 — влияние на портал.md]] (релиз-хаб) · код-реестр `src/data/eft-season-items.ts` · перки `src/data/eft-seasons.ts`.

## Сезон 1 — KORD BREACH (патч 1.1.0.0, старт 03.08.2026)

### Айдентика
- **Цвет сезона:** `#5FD5C0` (мятно-бирюзовый). Токен — `--color-season-01` в `globals.css` (@theme) → утилиты `bg-season-01` / `text-season-01` + `var(--color-season-01)`.
- **Фракция сезона:** **Black Division** (новые боты-противники, айдентика, кастомизация убежища).
- **Стиль:** пиксель-вордмарки (лого/«BATTLE PASS» — пиксельный шрифт), бирюзовый акцент на тёмной базе NIGHTFALL.

### Механики (кратко; подробно — [[Сезоны и Боевой Пропуск.md]])
- **Сезонный персонаж** — отдельные сервера, добровольный, сброс каждые 4–6 мес.
- **Модификаторы:** Общие (навязаны всем) + Личные (бюджет очков, баланс ≥ 0).
- **Боевой пропуск (бесплатный):** прогресс — находить и сдавать **документацию TerraGroup**; «Секретные данные» — универсальная замена; дневной лимит документов.

### Предметы Боевого пропуска / сезона (наш реестр)
Серверный конфиг тиров/наград у нас пока нет — состав выведен из имён бандлов клиента + патчноут. Две категории (`eft-season-items.ts`):
- **🎫 Боевой пропуск (13):** 9 документов TerraGroup (finance/medicine/operating/personal/project/scheme/testing/user + Секретные данные) + 3 флаера `tbattlepass_s1` + контейнер БП.
- **🖤 KORD BREACH / Black Division (7):** жетоны Black Division (4), Black Division SSD «KORD RAW», квест-предметы `bdtoughbook` (2).
- **Косметика-награды** (вне товарных категорий): одежда `_bp_bd_*`, скины рук, кастомизация убежища Black Division (стены/пол/потолок).
