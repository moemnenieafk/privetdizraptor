# Механика распознавания инвентаря

Игрок загружает скриншот инвентаря из рейда — портал отдаёт список предметов с ценами.

## Ключевое решение: Gemini здесь не основной механизм

Иконки предметов Tarkov — **статичные канонические ассеты** с tarkov.dev. Сетка инвентаря детерминирована по геометрии. LLM избыточен и ненадёжен там, где хватает детерминированного матчинга.

> [!important] Два уровня
> Уровень 1 закрывает большинство ячеек за ноль токенов. Уровень 2 добирает остаток. Без первого уровня квота выгорает на десятке сканов, а точность падает.

### Уровень 1 — perceptual hash

1. Предзагрузить иконки с tarkov.dev, посчитать dHash каждой → таблица `item_icon_hashes`
2. Найти геометрию сетки на скриншоте, нарезать по ячейкам
3. dHash каждой ячейки → ближайший сосед по расстоянию Хэмминга
4. Ниже порога уверенности — передать на уровень 2

Работает офлайн, детерминирован, не тратит токены.

Фильтр по габаритам режет пространство поиска на порядок: предмет 2×3 сравнивается только с предметами 2×3. См. [[Код - item-index]].

### Уровень 2 — Gemini vision как fallback

- модель flash-класса, ID сверять по актуальному списку `/v1beta/models` — строки меняются между релизами
- батчить неопознанные ячейки **в один запрос**, не по одной
- structured output через `responseSchema`, не свободный текст
- в промпт передавать **список кандидатов** из pHash-топа

> [!tip] Почему кандидаты, а не свободное называние
> Задача «выбери из пяти» решается в разы точнее, чем «назови что видишь». Плюс ответ валидируется: всё, чего нет в списке кандидатов для этого слота, отбрасывается на клиенте API. Модель физически не может выдумать `itemId`.

## Сегментация

Занятые ячейки склеиваются в прямоугольники предметов. Разделители режут склейку — без этого два соседних 1×1 читаются как один 2×1. Пустой слот определяется по стандартному отклонению яркости во внутренней области ячейки.

Детали и пороги — [[Калибровка и пороги]], реализация — [[Код - grid]].

## Нормализация и цены

Совпадения матчатся по `normalizedName` из tarkov.dev GraphQL. Цены и `avg24hPrice` тянутся оттуда же — см. команду `/tarkov-api`.
