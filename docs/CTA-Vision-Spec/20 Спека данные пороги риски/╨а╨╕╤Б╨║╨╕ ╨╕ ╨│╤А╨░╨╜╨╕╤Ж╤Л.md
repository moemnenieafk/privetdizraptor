# Риски и границы

## Где сломается распознавание

> [!danger] Сегментация — самое хрупкое место
> Предметы с полосой прочности и счётчиком патронов дают лишние рёбра. Полностью тёмные иконки на тёмном фоне могут читаться как пустой слот.

Именно поэтому `unknown` со списком кандидатов возвращается наружу, а не отбрасывается. На UI это ручной выбор из пяти вариантов, и он же источник данных для [[Калибровка и пороги|калибровки]].

Дальше по списку:

- **Вайпы и патчи** меняют иконки → нужна переиндексация `item_icon_hashes` по расписанию
- **Нестандартное разрешение или UI-скейл** ломает `minPitch`/`maxPitch`
- **Наложенные тултипы** на скриншоте перекрывают ячейки — их не отфильтровать, только ловить как `unknown`
- **Пресеты оружия** отображаются как один предмет, но в базе это сборка — pHash даст низкую уверенность

## Инфраструктура и ключи

- Ключ Gemini только в server-side env. Утечка в клиентский бандл = чужой биллинг
- Open WebUI без авторизации выкачают за сутки — см. [[Свой веб-интерфейс]]
- Rate limit in-memory работает, пока Node-процесс один. Горизонтальное масштабирование → Redis
- Квоты API конечны; уровень 1 существует ровно для того, чтобы они не кончались

## Доступ к Gemini

- Не гонять обход региональных ограничений на основном аккаунте, к которому привязана рабочая инфраструктура. Формально это нарушение TOS; в худшем сценарии подвешивают аккаунт целиком, а не отдельный сервис
- Прыжки между странами exit-нод сами по себе сигнал. Одна страна, один exit, надолго — ассоциация пересчитывается лениво, неделями
- Gemini AI Pro (подписка) и API — разные продукты. Подписка на API-доступ не влияет. При недоступности сервиса в регионе имеет смысл запросить возврат неиспользованной части через поддержку Google One, но гарантий нет

## Что осознанно не делается

- Не пытаемся распознавать предметы вне сетки инвентаря (слоты экипировки, карманы) — другая геометрия, отдельная задача
- Не считаем стоимость рейда на сервере: цены тянутся на клиенте из tarkov.dev, чтобы не кэшировать протухающие числа в `inventory_scans`
