# Архитектура пайплайна

FSD-lite, всё тяжёлое на сервере. Ключ Gemini не покидает VPS.

## Поток

```
POST /api/vision/inventory  (multipart, поле screenshot)
  │
  ├─ rate-limit по x-forwarded-for            → 429
  ├─ валидация mime + размер (8 МБ)           → 415 / 413
  ├─ sha256 → кэш inventory_scans             → hit: отдать, cached: true
  │
  ├─ detectGeometry        автокорреляция профиля рёбер → pitch, origin
  │                                            → null: 422 grid_not_found
  ├─ segmentItems          занятые ячейки → прямоугольники
  │
  ├─ для каждого прямоугольника:
  │     cropSlot → dhash → findCandidates
  │     distance ≤ accept → slot.kind = 'phash'
  │     иначе             → slot.kind = 'unknown', в очередь vision
  │
  ├─ resolveSlots(pending)  ОДИН батч-запрос к Gemini
  │     вердикт валиден только если itemId ∈ кандидатов слота
  │     ошибка → лог, pHash-результаты всё равно отдаются
  │
  └─ записать в кэш, вернуть ScanResponse
```

## Модули

| Файл | Ответственность |
|---|---|
| `lib/vision/types.ts` | дискриминированные объединения, единый контракт |
| `lib/vision/phash.ts` | dHash 64 бита + расстояние Хэмминга |
| `lib/vision/grid.ts` | геометрия сетки, сегментация, кроп |
| `lib/vision/item-index.ts` | индекс иконок в памяти, поиск кандидатов |
| `lib/vision/gemini.ts` | батч-запрос, responseSchema, валидация вердиктов |
| `lib/vision/rate-limit.ts` | token bucket in-memory |
| `app/api/vision/inventory/route.ts` | оркестрация |
| `store/raid-scan-store.ts` | состояние сессии на клиенте |

## Инварианты

- `runtime = 'nodejs'` — sharp нативный, edge не подойдёт
- `any` нигде; результат распознавания — дискриминированное объединение `phash | vision | unknown`
- `unknown` со списком кандидатов **возвращается наружу**, а не отбрасывается: на UI это ручной выбор из пяти вариантов и источник данных для калибровки
- отказ Gemini не роняет скан — pHash-результаты уже собраны
- `GEMINI_API_KEY` только server-side, никогда не `NEXT_PUBLIC_`
- загрузка → `animate-pulse` скелетон сетки, спиннеров нет
