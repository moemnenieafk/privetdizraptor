# Как открыть

Папка `CTA-Vision-Spec` — самодостаточный набор заметок Obsidian. Два способа:

**Как подпапку существующего хранилища.** Скопировать `CTA-Vision-Spec` внутрь своего vault. Wikilinks разрешатся сами, если в настройках стоит `Настройки → Файлы и ссылки → Формат новой ссылки: Короткий путь`.

**Как отдельное хранилище.** `Открыть папку как хранилище` → выбрать `CTA-Vision-Spec`.

Точка входа — [[00 Индекс]].

## Структура

```
00 Индекс.md            MOC, начинать отсюда
10 Доступ/              разбор блокировки Gemini
20 Спека/               механика, архитектура, данные, пороги, риски
30 Реализация/          порядок запуска, реестр файлов, код в .md
_src/                   сырые .ts — копировать в репозиторий
```

`_src/` начинается с подчёркивания, чтобы Obsidian не тащил `.ts` в граф. Файлы там — не копии для чтения, а рабочие исходники: структура папок один в один совпадает с `moemnenieafk/privetdizraptor`.

## Claudian

Заметки писались под передачу через плагин Claudian. Frontmatter у каждой — `tags`, `status`, где уместно `depends`. Ссылки только wikilink-формата, без markdown-ссылок на внутренние заметки.
