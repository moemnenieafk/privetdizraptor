# Порядок запуска

VPS Амстердам — релей не нужен, API доступен с сервера напрямую.

1. **`npm i sharp`** — нативный модуль, на VPS собирается под linux-x64 из коробки
2. **Миграция Drizzle** для двух таблиц из [[Схема данных]]
3. **`tsx scripts/seed-item-hashes.ts`** — около 2800 иконок, несколько минут при `CONCURRENCY = 8`
4. **`GET /v1beta/models`** с ключом → подставить реальный ID flash-модели в `GEMINI_VISION_MODEL`
5. **Прогнать реальный скриншот**, залогировать `geometry.pitch` и долю `unknown`
6. **Откалибровать** `emptyStdDev` и `separatorDarkRatio` — см. [[Калибровка и пороги]]
7. **UI раздела** в NIGHTFALL: дропзона, оверлей сетки поверх скриншота, скелетон на время скана, цены с tarkov.dev по `normalizedName`

## Проверка перед коммитом

`npx tsc --noEmit` должен проходить — единственное жёсткое правило для коммитов в main. Файлы группируются семантически, кросс-файловая фича коммитится атомарно.

> [!note] Env
> ```bash
> GEMINI_API_KEY=
> GEMINI_VISION_MODEL=
> ```
> Оба server-side. `NEXT_PUBLIC_` — никогда.
