> Аккаунт Google — страна Великобритания, API работает, веб-клиент `gemini.google.com` отдаёт заглушку. VPS Timeweb в **Амстердаме**, домен `cta.quest`, Next.js 16 + SSL. Релей не нужен — `generativelanguage.googleapis.com` доступен с сервера напрямую.
