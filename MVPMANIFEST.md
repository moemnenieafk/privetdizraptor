## Незыблемые принципы (кратко — детали в источниках выше)

- Стек: Next.js 16 (App Router, RSC по умолчанию, react-compiler), Tailwind v4, Zustand, TS strict (⛔ `any`).
- ⛔ Произвольные HEX — только токены. ⛔ `font-mono`. Спиннеров нет — только skeleton (`animate-pulse`).
- Адаптив **компонентов** — контейнер-запросы (§9 `DESIGN_SYSTEM.md`); вьюпорт (`sm:`/`md:`/`lg:`) — только для каркаса страницы.
- Предметы: **только карточки** (`EftItemTile`) + сортировка; табличный вид удалён (см. `docs/decisions/`).
