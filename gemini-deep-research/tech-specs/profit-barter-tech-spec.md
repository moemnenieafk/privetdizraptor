# Техническая спецификация: Модуль «Прибыль бартера» (v2.0)

**Статус:** Активная разработка  
**Цель:** Создание интерактивной торговой площадки (Trading Desk) для максимизации экономической выгоды бартерных сделок и вовлечения пользователей через механики геймификации.

---

## 1. Концептуальная архитектура (Trading Desk)
Модуль представляет собой интерактивное рабочее пространство, имитирующее интерфейс внутриигрового инвентаря.

*   **Рабочая сетка (StashGrid):** Динамический контейнер с ячейками 53x53px. Каждая ячейка имеет легкий отступ (gap) для имитации структуры схрона ЧВК.
*   **Логика упаковки:** Каждый предмет — это объект с `width` и `height`. Система должна использовать CSS Grid с правилами `grid-column: span W` / `grid-row: span H` для правильного размещения предметов.
*   **Интерактивность:** 
    *   *Слой 1 (Input):* Поиск предметов и добавление их в первую свободную область сетки.
    *   *Слой 2 (Info):* Всплывающий интерактивный поповер (тултип) с расчетами.
    *   *Слой 3 (Dashboard):* Нижняя панель для отслеживания общего прогресса и ценности стола.

---

## 2. Экономический движок (Calculations)
Основа модуля — интеграция с `tarkov-api`. Система оперирует следующими метриками:

| Параметр | Описание / Формула |
| :--- | :--- |
| **Total Cost** | $\sum (Quantity_i \times Price_i)$ (минимум между ценой Flea и Trader для каждого компонента). |
| **Revenue** | `SellFor` цена целевого предмета (максимум между ценой Flea и лучшей ценой Trader). |
| **Net Profit** | `Revenue - Total Cost`. |
| **ROI (%)** | $(Net Profit / Total Cost) \times 100$. |
| **Savings** | `TargetItemFleaPrice - TotalCost` (экономия относительно покупки готового). |

**UI-индикация цен:**
*   `--color-text-secondary` (по умолчанию).
*   `--color-success` (#739964) — если `Net Profit > 0` и ROI выше среднего по категории.
*   `--color-danger` (#B34439) — если сделка убыточна.

---

## 3. Система геймификации («Торговый путь»)
Механики удержания (Retention) встроены непосредственно в рабочий процесс.

### А. Уровни Трейдера (Trader Tier)
*   **Статистика сессии:** Отображение профита за текущую сессию (рубли) и сэкономленных средств.
*   **Система опыта:** 1 ₽ профита = 1 XP опыта трейдера.
*   **Достижения (Badges):**
    *   *«Оптовик»:* Собрал бартер с 5+ компонентами.
    *   *«Спекулянт»:* ROI > 200%.
    *   *«Мастер Маяка»:* Выполнил все бартеры для Смотрителя.

### Б. Twitch-интеграция
*   Вывод дашборда "Виртуального схрона" на стрим.
*   Зрители могут влиять на состав стола (голосование/баллы канала).
*   Автоматические алерты в Twitch при совершении выгодной сделки на сайте.

### В. Прогресс к PRO-подписке
*   Шкала «Мета-Прогресс» в нижней части страницы. Выполнение экономических челленджей начисляет опыт профиля, открывая временный доступ к премиум-функциям.

---

## 4. UI-компоненты (Дизайн-система)
Использовать следующие ключевые компоненты:

1.  **`<StashGrid/>`**: Главный контейнер (CSS Grid). Автоматическое расширение сетки вниз при заполнении.
2.  **`<InventoryItem/>`**: Рендер предмета (иконка, `GridSize`, счетчик количества).
3.  **`<TradeTooltip/>`**: Интерактивный popover с расчетами прибыли и списком компонентов.
4.  **`<StatsDashboard/>`**: Нижняя панель с живым счетчиком профита, шкалой прогресса и кнопками управления.
