# Проверки

Сшивку и проекцию нельзя принимать на глаз: ошибка позиционирования выглядит
правдоподобно, а обесцвеченная карта отличается от нормальной только оттенком.
Ниже — проверки, дающие число, а не впечатление.

## Побайтная сверка блока тайлов

Самая сильная проверка сшивки. Собираем блок 2×2 из сырых тайлов независимо и
сравниваем с тем же местом в результате.

```python
from PIL import Image
import pyvips, numpy as np

x0, y0 = 2, 4          # левый верхний угол занятой сетки
CX, CY = 35, 215       # смещение финального кропа внутри мозаики
TX, TY = 29, 29        # проверяемый блок

blk = Image.new('RGBA', (512, 512), (0, 0, 0, 0))
for i, cx in enumerate(range(TX, TX + 2)):
    for j, cy in enumerate(range(TY, TY + 2)):
        blk.paste(Image.open(f'tiles/{cx}_{cy}.png').convert('RGBA'), (i * 256, j * 256))
A = np.array(blk).astype(int)

big = pyvips.Image.new_from_file('out.webp', access='random')
px, py = (TX - x0) * 256 - CX, (TY - y0) * 256 - CY
B = np.ndarray(buffer=big.crop(px, py, 512, 512).write_to_memory(),
               dtype=np.uint8, shape=[512, 512, 4]).astype(int)

print('Δalpha:', np.abs(A[:, :, 3] - B[:, :, 3]).max())
vis = A[:, :, 3] > 200
print('ΔRGB на плотных пикселях:', np.abs(A[:, :, :3] - B[:, :, :3])[vis].max())
```

**Как читать.**

- `Δalpha == 0` — позиционирование точное. Альфа в WebP хранится без потерь,
  поэтому расхождение здесь означает именно смещение.
- `ΔRGB` на плотных пикселях 20–60 при среднем 2–3 — нормальные потери WebP Q90.
- Если разбить по прозрачности, выбросы под 200 окажутся только там, где альфа
  ниже 64: кодек не хранит цвет невидимых пикселей. Это не ошибка.

**Ловушка.** Пустые области совпадают тривиально. Если проверять блоки наугад,
можно получить «совпало 4 из 6» на пустоте и решить, что всё хорошо. Бери блоки
с содержимым: `A[:, :, 3].max() > 0`.

## Сверка силуэта через IoU

Когда нет сырых тайлов, но есть второй источник той же карты (вектор против
растра, другой зум) — сравниваем силуэты по альфе.

```python
def iou(a, b):
    b = b.resize(a.size)
    A, B = np.array(a) > 0, np.array(b) > 0
    return (A & B).sum() / (A | B).sum()
```

Прогоняй по восьми вариантам ориентации (четыре поворота × зеркало). Правильный
должен выигрывать с отрывом. Пример на Заводе: поворот 0 дал 0.815, следующий
вариант 0.638 — отрыв убедительный, ориентация совпадает.

Если лучший результат отличается от второго на проценты — метрика ничего не
доказывает, картинка слишком однородная, ищи другую проверку.

## Признак сломанной проекции

Спроецируй маркеры (выходы, двери) на холст и посчитай, какую долю площади они
занимают.

- **68–99% по ширине и высоте** — проекция исправна. Это диапазон по всем десяти
  картам на реальных данных.
- **меньше половины** или **больше 100%** — проекция сломана.

Считается так:

```python
xs = [p[0] for p in projected]; ys = [p[1] for p in projected]
spread = ((max(xs) - min(xs)) / W * 100, (max(ys) - min(ys)) / H * 100)
```

**Важно.** Эта проверка осмысленна только если маркеры и холст в одном
пространстве. Результат `transform` из `maps.json` в пространстве viewBox мерить
нельзя — он отображает в CRS Leaflet, там свои единицы. Подробности в
`projection.md`.

## Проверка цвета после сшивки

```python
sm = pyvips.Image.new_from_file(out, access='sequential').resize(0.02)
a = np.ndarray(buffer=sm.write_to_memory(), dtype=np.uint8,
               shape=[sm.height, sm.width, 4])
print('каналы RGB:', a[:, :, :3].mean(axis=(0, 1)).round(1))
print('alpha max:', a[:, :, 3].max())
```

Каналы обязаны различаться, `alpha max` обязана быть 255. Равные каналы —
мозаика ушла в градации серого, см. `failure-modes.md` §1.

## Проверка целостности после локальной сшивки

Число фигур до и после обязано совпасть:

```bash
grep -o '<path' исходники/*.svg | wc -l
grep -o '<path' результат.svg | wc -l
```

Плюс: ноль остатков `class="st\d"`, ровно один `id="style_common"`, все ожидаемые
группы-этажи на месте.
